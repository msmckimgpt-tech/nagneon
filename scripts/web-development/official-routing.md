## 공식 Chat 위임 범위 (2026-09-22 정리)

- 이전의 전면·우선 위임 방침은 폐기한다. 로컬을 기본으로, 범위가 명확하고 이점이 있는 작업만 선택적으로 공식 Chat + RDC에 위임한다. WEB-DEVELOPMENT-COMPANION 및 web-development/references/official-chat-delegation.md를 따른다.
- 공식 전송/읽기 도구의 지원 범위만 사용한다. UI/DOM/CDP 자동화·비공식 Chat 호출·출력 추출·쿠키 복사·제한 우회는 사용하지 않는다. 도구 제공이나 과거 성공을 포괄 승인으로 해석하지 않는다.
- xhigh 기본값과 2026-09-21 특정 기존 일반 Chat의 High 예외는 유지하되, 현재 대상과 실제 설정을 확인한다. 다른 Chat/프로젝트/기기로 예외와 권한을 확대하지 않는다.
- 읽기 전용을 우선하고 작업별 쓰기/실행 권한·경로·수용 기준을 확인한다. 안전 거부를 다른 도구·셸·에이전트로 우회하지 않는다. 외부 전송 권한·제3자 데이터 처리·원본 검증과 로컬 통합 책임을 유지한다. 전면 위임을 위한 재귀 호출이나 상시 폴링을 구성하지 않는다.
