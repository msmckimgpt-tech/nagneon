# 관객 부재와 복귀의 청취 경계

판매 준비 목표 중 실제 스트리머와 관객의 소통·개인 목격 기억을 개선하는 작업이다. 기준은 main `1dd28f57c1e8d9fd20e7a838f0effa19514d4a07`, 작업은 `G:/dev/ai/00_game_backseat-worktrees/audience-return-continuity`, 브랜치는 `codex/audience-return-continuity`다. 이전 개성 개선은 완료·통합된 진전으로 분류한다. 이번에는 그 시험 중 드러난 입장 상태 문제를 실제 제품 경로에서 재현했다.

## 원인과 변경

- 이전에는 이름을 부르면 `away` 관객도 활성화되고 인지·친밀도가 올랐다. 이제 실제 시청 중인 active/lurking 관객만 호명에 반응한다. 조용히 보던 사람이 말을 시작하는 것은 허용한다.
- 자연 복귀와 차단 해제에서 이전 `joinedAt`가 유지됐다. 복귀 시 새 시청 구간을 열고, 같은 방송에서 잠깐 자리를 비운 횟수를 방송 방문 수로 중복 계산하지 않는다. 방송 시작 때 안 온 기존 관객이 나중에 자연 유입하면 그 방송의 방문과 목격자가 된다.
- 자리 변화만 있을 때 화면에 전달되는 state가 갱신되지 않을 수 있었다. 채팅 공지를 도배하지 않고도 실제 상태 변경을 publish한다.
- 이전 입장에서 만들어진 대기 채팅은 부재·재입장 후 내보내지 않는다. 모델 처리 중 자리를 떠났거나 복귀한 관객의 채팅·후원 제안·클립 선택·성향 변경도 취소한다. 계속 보던 다른 관객의 반응과 실제 캡처 당시 목격한 장면의 기억은 보존한다.
- 키보드 발언도 받았던 관객을 기록한다. 입장 경계를 넘는 여러 발언은 청취자가 같은 연속 묶음으로 나누어 순서대로 답한다. 복귀 전에 나온 질문을 뒤늦게 온 사람이 들은 것으로 만들지 않으며, 그 사람을 향한 새 질문을 함께 버리지 않는다.
- 마이크 전사가 늦게 완료되더라도 녹음 구간을 들은 관객만 대화 저널의 목격자로 남긴다. 현재 채팅 문맥도 그 저널의 청취 기록을 확인한다. 전사가 채팅창에 표시된 시각만으로 부재중 발언을 들었다고 처리하지 않는다. 돌아오기 전에 실제로 들었던 과거 대화는 기존 개인 회상으로 유지한다.

외부 화면·입력·장치 캡처·사용자 앱 재시작은 하지 않는다. 테스트는 작업별 합성 상태, 자체 서버, 자체 `artifacts/` 프로필로만 수행한다. 기존 사용자 데이터와 관객 성격을 다시 쓰지 않는다.

## 검증과 실패 보존

`test/audience-return.test.js`의 첫 10개 사례는 수정 전 모두 실패했다. `artifacts/return-before.log`에서 실제 오류를 확인했다. 첫 수정 후 9개가 통과했고, 마지막 실패는 회상 결과가 완전히 비어야 한다고 기대한 시험 조건이었다. 원래 회상 기능은 관련 원문이 없으면 최근에 들은 질문을 제한적으로 참고할 수 있으므로, 못 들은 암호가 포함되지 않는지로 수정했다. 제품의 기억 검증을 완화한 것이 아니다. 이 중간 기록은 `artifacts/return-first.log`, 전체 459개 중 같은 시험 하나만 실패한 기록은 `artifacts/check-first.log`다.

후속 검증에는 이전 채팅의 취소, 복귀 후 다른 관객 반응 유지, 발언 묶음 분리·재시도, 시스템 소리 구간의 청취자, 실제 HTTP 차단 해제·늦은 전사·디스크 재시작을 추가했다. 집중 16개는 `artifacts/return-verified.log`에서 통과했다. 실제 모델 검증은 `scripts/verify-audience-return.mjs`로 수행하고 각 요청의 전체 문맥·응답·시간·소스 해시·최종 표시 상태를 보존한다.

## 한계

이 동작은 앱이 시뮬레이션한 입장 상태의 일관성이다. 실제 사람의 시선·AFK 여부를 인식한 것이 아니다. 공유된 하나의 모델 호출에서 여러 관객의 개인 문맥은 함께 제공되므로 암호적 비밀 격리가 아니다. 한 발언 묶음은 같은 청취자에게만 전달하며, 경계가 바뀌면 다음 묶음에 추가 모델 호출이 필요할 수 있다.

기존 저장소에 잘못 기록된 과거 목격 여부를 증거 없이 재구성하지 않는다. 실제 사용자 음성·장치·게임의 검증과 장기 관계·말투 평가는 별도로 남는다. 설치·정책·서명·상점 심사 등 Steam 판매 준비 전체는 아직 미완료다.

## 최종 결과와 통합

병행 음성 인식 개선이 main에 먼저 추가됐으므로 그 변경을 보존한 통합 상태에서 필수 검사와 최종 모델 검증을 수행한다. 완료 후 커밋과 원본 증거 경로를 기록한다.
