# 관객 체류·퇴장·재방문

Nagneon의 관객은 한 번 입장했다고 방송이 끝날 때까지 고정되어 있지 않는다.
실제 AI 방송에서는 같은 관객이 적극적으로 채팅하거나 조용히 지켜보다가 자리를 비울 수 있고,
같은 방송 또는 다음 방송에서 다시 만날 수 있다.

## 상태 의미

- `active`: 현재 시청 중이며 일반적인 대화 후보가 될 수 있다.
- `lurking`: 현재 시청 중이지만 주로 조용히 지켜보는 상태다. 부재나 관계 악화를 뜻하지 않는다.
- `away`: 현재 방송 구간을 보고 있지 않다.
- 방송 도우미와 현재 매니저의 운영 역할은 일반 관객의 자연 퇴장 규칙과 분리한다.

`active ↔ lurking` 전환은 같은 시청 구간을 유지한다.
`away → active/lurking`으로 돌아오면 새 시청 구간이 시작되지만,
같은 방송에서 잠시 나갔다 돌아온 일을 방송 참여 횟수 두 번으로 세지 않는다.

## 자연 퇴장 모델

관객마다 고정 ID와 첫 유입 맥락을 바탕으로 서로 다른 체류 성향을 갖는다.
닉네임이나 AI 모델이 바뀌었다고 이 성향을 다시 추첨하지 않는다.

퇴장 판단은 한 번의 임의 추첨을 UI tick마다 반복하지 않고,
실제 시청 시간에 누적되는 경쟁 위험(competing hazards)으로 계산한다.
현재 구현은 다음 요인을 제한적으로 사용한다.

- 개인적으로 사용할 수 있는 시간
- 누적 시청에 따른 휴식 필요
- 이번 방문의 목적을 충분히 충족한 정도
- 다른 활동을 둘러볼 가능성
- 최근 실제로 목격한 장면의 자극도
- 기존 관계와 현재 같이 보고 있는 익숙한 관객

관계가 좋거나 익숙한 사람이 함께 있다는 이유만으로 개인 일정을 없애지는 않는다.
또한 침묵, 스트리머의 말투 교정 요청, 이름을 부른 행위만으로 불만이나 퇴장 동기를 만들지 않는다.

퇴장 후 내부적으로는 잠시 자리 비움과 이번 방송 시청 종료를 구분한다.
일부 자리 비움은 대기 구간 뒤 같은 방송으로 돌아올 수 있고,
시청 종료는 같은 방송에서 자동 복귀하지 않는다.
다음 방송에서는 기존 사람으로 다시 만날 수 있다.

이 모델의 시간·확률 상수는 **제품 시뮬레이션 기본값**이다.
실제 방송 시청자의 체류율이나 이탈률을 측정·추정한 수치로 설명하지 않는다.

## 기억·관계·포인트

자연 퇴장은 관객 삭제가 아니다.

퇴장해도 다음 항목은 유지된다.

- 안정적인 관객 ID와 페르소나
- 함께한 방송 횟수와 누적 시청 시간
- 관계도와 기존 관객 간 연결 기록
- 대화 기억과 사용자의 개인 메모
- 이전 닉네임 이력
- 첫 유입 출처
- 프로필·관계 잠금 해제와 포인트 관련 기록

재방문에는 첫 만남 비용을 다시 청구하지 않는다.
신규 유료/자연 유입의 기존 hold/commit/refund 계약도 변경하지 않는다.

## 직접 목격과 늦은 반응

관객이 자리를 비우면 그 시청 구간의 늦은 채팅·후원·클립 선택 같은 사회적 행동은 폐기한다.
그 사이 같은 사람이 다시 들어왔더라도 이전 방문의 반응을 새 방문 반응으로 되살리지 않는다.

화면·음성에 따른 체류 신호도 다음 조건을 만족한 경우에만 사용한다.

- 현재 방문에 실제로 포함된 목격자
- 수용된 최근 관측
- 해당 관객의 입장 이후에 캡처된 입력
- 중복 처리되지 않은 입력

부재 중 내용이나 다른 관객이 본 장면을 개인 경험으로 승격하지 않는다.

## 저장과 비공개 상태

관객별 `presenceMemory`는 버전이 있는 선택 필드로 저장한다.
기존 프로필에 이 필드가 없어도 로드할 수 있고, 실제 체류 동작이 발생하면서 점진적으로 생성된다.

퇴장 원인과 복귀 대기시간 같은 내부 상태는 공개 관객 DTO나 모델의 일반 관객 컨텍스트에 넣지 않는다.
따라서 내부 시뮬레이션이 “왜 나갔는지”를 스트리머나 다른 관객의 확정된 속마음처럼 전달하지 않는다.

presence 전환을 저장해야 하는 경우에는 저장 성공 뒤에 상태를 공개한다.
저장 실패 시 관계 데이터나 퇴장 상태가 부분 확정되지 않아야 한다.
시스템 절전·장시간 event-loop 정지 후 경과 시간을 한꺼번에 시청 시간이나 퇴장 확률로 계산하지 않는다.

## UI 안내

`나의 관객` 화면은 다음 원칙을 안내한다.

- 눈팅과 부재는 다르다.
- 관객은 쉬거나 오늘 시청을 마칠 수 있다.
- 다시 만나도 같은 사람의 기억과 관계가 이어진다.
- 첫 만남은 계속 시청한다는 약속이 아니다.
- 재방문에는 첫 만남 포인트가 다시 들지 않는다.

## 검증 범위

이 기능 변경에서 다음을 합성 데이터와 격리 worktree로 확인했다.

- 관객 체류/퇴장/재방문 집중 회귀 37개 통과
- 전체 `npm run check`의 919개 테스트 통과 및 TypeScript/Vite production build 통과
- `npm audit --audit-level=high` 취약점 0건
- 격리 in-memory world를 사용하는 Electron renderer 검증 통과
- 좁은/세로 화면을 포함한 일반 페이지 렌더링과 renderer console error 없음

기존 `scripts/verify-audience-autonomy.cjs`는 현재 테스트 하네스의
`storage:status` IPC 핸들러가 등록되지 않아 설정 탭 진입 전에 실패하므로
이번 기능의 성공 증거로 사용하지 않는다.
실계정, 물리 장치, 사용자 설치본 검증도 이 로컬 변경 검증에 포함하지 않는다.
