# 커뮤니티 문화 참고자료

방송 설정의 **분위기·훈수**에서 밈 사용과 참고할 공개 커뮤니티 도메인을 설정한다. 밈 사용은 기본 켜짐이며 도메인은 기본 비어 있다. 도메인 없이도 글로벌·한국·현재 게임의 일반 문화 지식을 드물게 참고한다. 특정 사이트를 자동으로 등록하지 않는다.

도메인은 최대 5개다. HTTPS 공개 호스트만 허용하며 로그인·쿠키·JavaScript 실행·주소 이동·쿼리 링크를 사용하지 않는다. DNS의 모든 응답을 검사하고 공개 IP에 연결을 고정하여 내부망·메타데이터 주소 접근과 DNS 재바인딩을 막는다. robots.txt의 Allow/Disallow/Crawl-delay를 적용하고 401/403/429, 서버 오류, 규칙 확인 실패 시 수집을 보류한다. robots가 없는 404는 공개 페이지 검사를 허용한다. noai/noindex/noarchive/nosnippet 표시도 보류한다. 이 보수적인 방식 때문에 로그인·동적 화면·리디렉션 위주의 사이트는 지원하지 않을 수 있다.

사이트당 12~13시간 간격으로 robots 1개와 공개 문서 최대 3개를 요청한다. 요청 사이 최소 10초, 문서당 최대 256KiB, 요청당 15초를 적용한다. 오류 시 24시간부터 최대 7일까지 지수 대기하며 Retry-After가 더 길면 최대 30일까지 기다린다. 앱이 켜져 있고 실제 AI 모드이며 방송과 다른 AI 작업이 쉬는 동안에만 실행한다. 방송 시작·새 AI 요청·중지·앱 종료 시 취소한다. 취소된 회차도 이미 예약한 사이트 요청 간격을 유지한다.

본문 변경이 확인되면 사용자가 설정한 기존 AI 연결의 방송 밖 요청 경로로 한 번 분석한다. 새 제공처나 유료 API를 추가하지 않으며 기존 연결의 사용량은 발생한다. 웹 원문은 명령으로 취급하지 않고 최대 18,000자의 제한된 표본을 전달한다. 개인 식별정보와 직접 인용을 제외한 경향·사용 상황·피할 상황을 요청하고 긴 원문 복사를 거절한다. 원문은 디스크에 보관하지 않는다. 자료가 빈약하면 밈 패턴이 없는 결과도 정상이다.

분석은 모델 가중치 학습이나 검증된 유행 통계가 아니다. `culture-learning.json`에는 사이트·문서 URL·내용 해시·요약·확인/분석 시각·다음 시도·오류·공개 사용 간격만 저장한다. 동일 본문을 다시 읽어도 분석 시각을 갱신하지 않으며 7일이 지난 요약은 응답에서 제외한다. CulturePack의 검증된 trend/생성 권리와 구분되는 추론 참고자료이고, AI 분석만으로 source 권리나 현실 유행 증거를 부여하지 않는다. 가상 게시글 수가 외부 유행도를 올리지 않는다.

관객별 성향과 참고 도메인 조합을 달리하며 한 요청에 최대 한 관객만 밈을 사용할 수 있다. 모델이 밈 사용으로 표시한 메시지에 대해 공개 사용 간격을 전체 2분·동일 관객 10분으로 제한한다. 모델이 표시하지 않은 모든 유행어를 완벽히 탐지하는 기능은 아니다. 생성·취소·대기열 단계에서는 사용 기록을 만들지 않는다. 라이브의 실제 공개 또는 커뮤니티 저장 성공 이후에만 기록한다. 저장 오류 시 추가 밈 선택을 중단한다.

스트리머의 실제 발언과 관객별 목격 문맥, 게시판의 최근 스트리머 공지를 응답에 반영한다. 진지한 상황·거부감·반복에는 사용을 줄이도록 하며, 공지는 개인 기억이나 모든 관객의 동일한 취향으로 처리하지 않는다. 기존 금칙어·스포일러·관객 기억 경계는 유지한다. 도메인을 삭제하면 해당 요약을 현재 자료에서 제거하고 뒤늦은 분석 결과를 수용하지 않는다. 저장소의 기존 복구 백업은 보존한다.

검증: `test/culture-learning.test.js`는 주소/DNS/robots/요청 예산/취소/신선도/관객 차이/사용 간격을 검사한다. `test/culture-runtime.test.js`는 인증된 설정 저장, 별도 프로필의 분석 저장·재시작·삭제·앱 종료를 검사한다. 이 자동 검사는 합성 제공처와 문서를 사용한다. 실제 사이트/계정 수용 검증은 별도이며 특정 커뮤니티의 문화 품질이나 모든 사이트 지원을 보장하지 않는다.

신규 의존성은 robots-parser 3.0.1(규칙 해석), ipaddr.js 2.5.0(IP 범위 분류), htmlparser2 12.0.0(비실행 문서 추출)로 고정했다. 잠금 파일과 의존성 보안 검사를 함께 갱신한다. 이전 버전으로 복귀해도 기존 프로필 데이터는 유지하며 새 문화 저장 파일을 삭제할 필요는 없다.
