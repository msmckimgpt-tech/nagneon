# 게임 장르 기본값

새 프로필에는 기존 자동 인식·League of Legends·VALORANT·스토리 / RPG에 더해 로그라이크·호러·소울라이크·샌드박스·리듬·시뮬레이션 관찰 지침이 제공됩니다. 처음 선택은 자동 인식입니다.

기존 사용자는 **설정 → 게임 → 장르 기본값 추가 → 저장**으로 없는 장르 항목을 추가할 수 있습니다. 기존 이름·관찰 지침·인지도·선택 게임은 유지합니다. 같은 ID가 이미 있으면 사용자 수정 내용을 그대로 둡니다. 저장하지 않고 닫으면 반영되지 않습니다. 게임 프로필 100개 제한에 걸리면 일부만 넣지 않고 추가를 막으며 이유를 표시합니다. 이는 관객 수 제한과 무관합니다.

각 장르는 화면에 보이는 근거, 스포일러 방지와 요청 시 조언을 중심으로 합니다. 자동 게임 탐지나 특정 게임의 공략 데이터베이스를 추가하지 않으며 방송의 목표나 이벤트를 강제하지 않습니다. 장르 인지도 기본값은 기존 게임과 같은 50%이고 설정에서 조정할 수 있습니다.

검증은 기본값의 설정 스키마 호환성과 기존 사용자 항목 보존·중복 방지·저장 용량 경계를 다룹니다. 실제 모델의 장르별 반응 품질을 평가한 결과는 아닙니다.

`npm run check`와 `node_modules/.bin/electron.cmd scripts/verify-genre-presets.cjs`로 검사할 수 있습니다. 합성 프로필의 실제 React 화면·HTTP 저장·서버 재시작을 사용하며 실제 계정·장치·모델 호출은 사용하지 않습니다.
