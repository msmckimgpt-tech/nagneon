# Nagneon 0.1.2

버전이 달라져도 같은 진입점과 저장 위치를 사용한다.

- 메인의 Start-Nagneon.cmd와 바탕 화면 바로가기를 고정 설치 위치에 연결한다.
- 방송 설정 → 미디어·기록에서 저장 위치를 확인하고 변경한다. 기본값은 Windows 사용자 데이터 폴더다.
- 위치 변경은 원본을 남긴 채 기록을 복사·검증하고 재시작한다. 접근할 수 없는 저장 위치를 빈 프로필로 대체하지 않는다.
- 릴리즈 적용 도구가 데이터 백업과 패키지 전체 해시 검증 후 새 버전으로 연결한다. 자동 다운로드 업데이트는 포함하지 않는다.

## 설치

두 ZIP을 같은 위치에 풀어 Nagneon 폴더를 합친다. 기존 사용자는 [고정 설치 절차](STABLE-INSTALLATION.md)에 따라 Install-NagneonRelease.ps1을 실행한다. 첫 설치에 보존할 프로필을 지정하고, 이후 업데이트는 Profile 인자를 생략한다. 새 설치에서 프로필을 지정하지 않으면 시스템 기본값을 사용한다.

Windows x64 미서명 포터블 앱이다. 공개 파일에 개인 데이터/계정 파일은 포함하지 않는다. 이전 버전 복귀 시 실행 파일만 바꾸고 기록을 자동으로 되돌리지 않는다.

검증: 679개 테스트와 빌드, 격리된 실제 Electron 설정 화면 및 저장 위치 변경, 설치/업데이트 fixture. 물리 장치·장시간 방송 품질 검증을 대신하지 않는다.
