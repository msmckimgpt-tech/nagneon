# 관객의 자기 댓글로 반복되던 핫클립 방문

댓글이 30개 이상 쌓인 핫클립에서 관객이 자기 감상을 남기면, 최근 30개 댓글에 있던 다른 사람의 오래된 댓글이 목록 밖으로 밀려났다. 관객의 방문 여부를 이 목록으로 계산해 자기 댓글만 추가돼도 새로운 내용이 생긴 것으로 판단했다. 재방문 대기 시간이 지나거나 앱을 다시 열면 같은 작성자를 다시 호출할 수 있었고, 다른 관객의 첫 감상보다 작성자의 반복 방문이 먼저 선택되기도 했다.

`communityRevision`은 방문 후보를 판단할 때 공개된 댓글 목록에서 현재 관객이 쓴 내용을 제외한다. 모델에 보내는 최근 30개 댓글과 실제 읽기 영수증은 기존 범위를 유지한다. 방문을 발견하기 위한 비교값이 오래된 댓글을 실제로 읽었다는 기억으로 바뀌지 않는다. 자기 댓글의 추가·삭제와 추천 변경은 재방문 이유가 되지 않으며, 다른 관객이나 스트리머의 새 댓글은 계속 발견한다.

읽기·댓글·추천 저장, 대기 시간과 시간당 호출 제한, 방송 응답 우선순위는 그대로다. 갤러리에서도 기존의 자기 댓글·추천 제외 동작을 유지한다. 새 설정이나 사용자가 관객을 호출하는 버튼을 추가하지 않는다.

저장 형식·댓글·추천·개인 기억은 바꾸지 않는다. 이전 버전의 최근 30개 기준으로 저장한 긴 클립의 방문 비교값은 새 기준과 다를 수 있어, 해당 관객이 조건을 충족하면 한 번 더 확인할 수 있다. 이후에는 새 공개 내용 없이 자기 댓글만으로 반복 방문하지 않는다. 기존 기록을 삭제하거나 미리 다시 쓰지 않는다.

## 확인한 범위

- 수정 전 실제 자동 방문 경로의 신규 검사 6개 중 5개에서 반복 호출·관객 선택·삭제 후 재방문·재시작 문제가 재현됐다. 갤러리 대조 검사는 기존 동작대로 통과했다.
- 수정 후 신규 6개와 클립 기억·자동 활동·갤러리 저장·취소·원자 저장 관련 검사 총 91개가 실패와 생략 없이 통과했다.
- 실제 `JsonStore` 저장과 재시작에서 댓글·추천·읽기 기록 및 클립 JSON 바이트가 보존됐고, 자기 댓글 때문에 모델이 다시 호출되지 않았다. 모델 입력에 없던 오래된 댓글은 읽기 기록과 회상에 포함되지 않았다.

초기 검사 자료의 매니저 활성 조건·독립 `Studio`의 저장 범위·JSON에서 생략되는 `undefined` 키는 현행 계약에 맞게 바로잡았다. 실패 원본은 작업 공간의 `artifacts`에 보존했다. 사용자 기록·화면·음성이나 실제 모델을 시험 자료로 사용하지 않았으며, 물리 장치·실제 대화 품질·패키지 설치를 검증한 결과는 아니다.
