# 방송 중 관객에게 전달하는 공개 갤러리 문맥

관객은 방송 중 최근 갤러리 글을 참고할 수 있다. 이 공통 입력에는 게시글·댓글·
대댓글 연결·삭제 표시·추천·공개 출처가 포함된다. 다른 관객의 비공개 읽기 기록
(`activityReads`)은 포함하지 않는다.

`Audience.context()`는 최근 8개 글을 기존 순서대로 고르고, 공개 게시글 조회와
동일한 `galleryPost` 변환을 적용한다. 종류 없는 추가 기록을 새로 만들거나 읽은
관객을 추정하지 않는다. 이전 글에 제목·분류·댓글·추천 배열이 없으면 기존 공개
조회와 같은 기본값을 사용한다.

이 변환은 저장본과 분리된 사본을 반환한다. 반환된 댓글·추천·중첩된 공개 출처를
수정해도 원본은 바뀌지 않는다. 저장된 읽기 기록의 관객 ID·revision·시각과
자동 재방문 판단은 유지되며, 문맥 준비 자체가 저장이나 AI 호출을 추가하지 않는다.
관객별 목격·대화 문맥과 공유 입력 압축은 기존 경계를 따른다.

`test/live-community-context.test.js`는 실제 Audience→관객 문맥→OpenAI/Codex
요청 본문 경로를 검사한다. 압축 OFF/ON, 실제 공유 그룹, 최근 8글의 순서,
이전 글의 기본값, 복제 분리와 원본 읽기 기록 보존을 확인한다. 격리 서버의
인증된 방송 응답 요청에서도 공개 글만 전달하고, 일반 world 저장·종료·재시작
뒤 원본 글과 비공개 기록을 유지하는지 확인한다.

서버 실행 검사는 합성 프로필과 제공처 대역을 사용한다. 실제 계정의 모델 응답,
사용자 설치본·장치·Steam 판매 수용을 대신하는 증거는 아니다.
