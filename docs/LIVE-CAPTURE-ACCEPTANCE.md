# 실제 게임 연결에서 발견한 방송 흐름 개선

2026-09-13. 이전 관객 자율성 단계는 구현과 검증 증거를 만든 **진행**이었다. 이번 단계는 실제 Steam 게임 연결에서 확인한 결함을 수정한다. 판매 목표는 계속 활성이다.

## 작업 분리

작업 중 다른 사용자 작업이 Git 저장소와 계정 연결 수정 `07421b3`을 통합했다는 통지를 받았다. 새 `AGENTS.md`와 병렬 개발 규칙을 읽고, 이후 제품 수정은 `G:/dev/ai/00_game_backseat-worktrees/live-capture-lifecycle`, `fix/live-capture-lifecycle`에서 진행했다. 기존 main의 이 작업 소유 변경 42개 파일은 해시를 확인해 복사했다(`artifacts/inherited-autonomy-changes.json`). 다른 작업의 계정 수정은 그대로 유지했다. 별도 의존성을 설치하고 236개 검사/빌드를 통과한 뒤, 이전 관객 자율성 변경 41개를 `9c10fb6`에 기록했다. 사용자 프로필·모델·Steam 세이브는 작업 트리로 옮기지 않았다.

## 발견과 수정

- **탭 이동이 캡처를 끊음:** 화면 공유 직후 관객 탭으로 이동하면 미리보기 `play()`가 DOM 제거로 거절되고, 전체 캡처 실패 처리에서 화면과 시스템 소리를 함께 끊었다. 게임을 읽는 독립 플레이어는 정상이어도 발생했다. `useMedia.ts`에서 미리보기 재생은 독립 캡처의 성공 조건으로 기다리지 않는다. 실제 캡처 플레이어 오류·방송 종료·늦은 장치 획득의 중지는 유지했다.
- **첫 만남과 자동 관찰의 경쟁:** 버튼을 눌렀을 때 자동 관찰이 먼저 실행되면, 서버가 busy를 거절해 사용자가 같은 요청을 다시 눌러야 했다. HTTP 첫 만남 요청은 진행 중인 응답 뒤에 기다린다. 대기 중에는 차감·관객 생성·추가 모델 호출이 없고, 다음 자동 관찰이 이 요청보다 먼저 실행되지 않는다. 중복 ID는 같은 대기/영수증을 확인한다. 방송 종료와 95초 대기 제한은 차감 없이 취소한다.
- **훈수 허용 오판:** 실제 멘트 `아직 훈수는 말고 …`를 요청으로 표시했고, `힌트 하나만 부탁해요. … 아는 척하지 말고 …`는 거절로 표시했다. `advice-intent.js`에서 거절·명시적 요청·인용/지난 요청·정정을 구분하는 보수적인 규칙을 적용했다. 막혔다는 혼잣말이나 ‘어떻게 지냈어?’만으로 훈수를 열지 않는다. 인터넷 공략 검색에도 같은 판단이 적용된다. 임의의 모든 한국어 의미를 완벽하게 이해하는 분류기라는 뜻은 아니다.

## 한계와 다음 수용

이 단계의 실제 게임 검증은 **지도 화면과 배경음악, 한국어 키보드 발언**이다. 물리 마이크, 퍼즐 내부의 규칙 변경, 게임 클리어 또는 여러 장르의 플레이 수용을 통과했다고 하지 않는다. Baba의 짧은 키 입력은 진행으로 확인되지 않았고, 포인터를 누르는 동작으로 메뉴 진입만 확인했다. 별도로 연 화상 키보드는 높은 Windows 무결성 수준 때문에 자동 입력/종료 권한을 얻지 못했으며, 보안 설정을 바꾸지 않고 사용자에게 X로 닫도록 알렸다. 이것은 제품의 입력 장치가 아니라 이번 개발 검증 보조 창이다.

게임도 Alt+F4 입력 후 실제 종료를 확인하지 못했다. 따라서 게임이 지도에만 머물렀고 실제 퍼즐 진행이 없음을 확인한 상태에서, 직접 시작한 PID31028/시작 시각/정확한 Steam 실행 경로를 대조해 해당 프로세스만 종료했다. `baba-game-before-close.json`, `baba-game-processes-after.json`(0개)에 남겼다. 정상적인 게임 내부 저장 후 종료라고 표현하지 않는다. 화상 키보드 PID31192는 종료 접근 거부로 남아 있으며 추가 권한을 얻거나 보안 설정을 바꾸지 않았다.

테스트 도구 첫 시도는 버튼의 활성화 검사와 클릭 사이 상태 변경, 숨김 시작 창 및 미리보기 텍스트가 붙은 선택 카드 탐색 때문에 실패하거나 멈췄다. 실제 GUI 프로세스 종료 코드를 수집하도록 `Start-Process -Wait -PassThru`를 사용하고, 창을 명시적으로 보이며, 화면 이름은 접근성 이름으로 찾고 개별 renderer 요청에 제한 시간을 적용했다. 숨김 단계 PID25376은 정확한 실행 경로·시작 시각을 확인한 뒤 이 시험만 종료했다. 초기 실패 원본을 성공 증거로 바꾸지 않는다.

장기 관객 개성·재방문·관계·포인트 균형, 실제 사람 음성의 장기 혼합, 실제 게임 조작과 새 Windows/서명/상용 연동/Steam 심사는 계속 남는다.
