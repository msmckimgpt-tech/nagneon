# 삭제한 대화의 늦은 반응 차단

방송 중 오인식된 발언을 삭제하거나 채팅을 비웠는데, 이미 생성 중인 관객 응답이 늦게 돌아와 반응·장면 기억·후원을 만들 수 있었다. 명시적으로 답변 대상을 지정한 채팅은 표시 직전에 일부 걸러졌지만, 일반 반응과 모델의 경험 저장은 같은 보호를 받지 못했다.

## 구현된 동작

- 방송 응답에 전달한 발언, 관객이 읽은 공개 채팅, 불러온 대화 원문의 ID를 요청 동안 보관한다. 해당 원문 삭제가 저장되면 그 원문을 입력으로 받은 응답을 취소한다. 제공처가 취소 뒤 결과를 반환해도 채팅·교정·관객 경험·후원·클립에 수용하지 않는다.
- 채팅 비우기도 현재 방송 응답을 취소한다. 방송 자체와 마이크·화면 연결, 별도 포인트 부탁의 실행은 이 취소 대상으로 바꾸지 않는다. 새로 들어온 발언과 같은 묶음에서 삭제하지 않은 발언은 다음 정상 요청에 남긴다.
- 응답 생성 후 표시를 기다리는 일반 반응에도 입력 원문 ID를 연결한다. 원문 삭제 시 답변 표시 여부와 관계없이 해당 대기 채팅을 버리고, 진단의 `cleared` 수에 반영한다.
- 요청이 입력으로 받지 않은 새 채팅을 삭제해도 유효한 응답은 계속한다. 삭제 저장에 실패하면 원문과 생성 중·표시 대기 중 응답을 보존한다. 전송 영수증은 유지하므로 삭제한 발언을 같은 ID로 재전송해 되살릴 수 없다.
- 원문과 저장 형식, 관객 모델·제공처를 변경하지 않으며 추가 모델 호출을 만들지 않는다. 이 수정은 이미 표시된 반응이나 확정된 후원을 소급 철회·환불하거나 모든 별도 기억 저장소를 지우는 기능이 아니다.

## 검증 범위

`test/live-message-removal.test.js`는 취소를 무시하고 늦게 완료하는 제공처와 취소 즉시 종료하는 제공처를 각각 검사한다. 발언 삭제·부분 묶음 보존·채팅 비우기·관객 채팅 및 지난 방송 원문 삭제·무관한 삭제·저장 실패·표시 대기 채팅을 합성 자료로 검증한다. 인증된 실제 루프백 HTTP 경로에서 음성 전사 발언을 삭제한 뒤 앱 서버를 재시작하여 대화와 후원이 되살아나지 않는지도 검사한다.

수정 전에는 새 회귀 11개 중 7개가 실패했다. 오래 시청한 합성 관객이 삭제된 발언의 늦은 결과를 받아 후원 한 건을 생성하는 반례도 확인했다. 관련 기존 검사에는 삭제한 답변 원문과 늦은 음성 교정이 아예 수용되지 않는 결과를 추가한다.

이 검사는 격리된 합성 제공처·프로필을 사용한다. 실제 계정 모델 호출, 물리 마이크의 인식 정확도, 게임 캡처, 사용자 설치본 적용이나 장기 방송의 자연스러움을 검증한 결과로 취급하지 않는다.
