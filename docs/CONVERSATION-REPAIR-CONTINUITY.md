# 정정된 약속과 관객 사이의 대화 기억

## 실제 모델에서 발견한 문제

AI가 작성한 한국어 잡담을 실제 Astra low와 Studio로 12회 이어갔다. 관객 두 명에게 약속, 서로 다른 야식 취향, 요리 농담, 휴식 취향을 이야기하고 저널을 파일에 저장한 뒤 다시 읽어 새 방송을 시작했다. 사용자 원본 대화나 장치를 사용하지 않았다. 채팅 전달 타이머는 제어한 시계로 진행했으므로 실제 장시간 방송 수용 검사가 아니다.

| 상황 | 처음 나눈 대화 | 재방문에서 확인한 오류 |
|---|---|---|
| 약속 정정 | 스트리머가 금요일 여덟 시를 말한 뒤 “아 아니다. 토요일 아홉 시야”라고 바로 고쳤고 모모도 받아들임 | 모모가 다시 “다음 금요일 저녁 여덟 시요!”라고 답함 |
| 서로의 취향 | 팝콘도둑은 버터팝콘, 모모는 떡볶이, 스트리머는 군만두를 고름 | 팝콘도둑은 자기 선택과 스트리머 선택만 기억하고 모모의 선택은 모른다고 답함 |

원본 저널에는 정정과 답변이 모두 있었다. 모델에 전달한 입력에는 첫 약속만 남았고, 모모의 야식을 묻는 질문은 있었지만 바로 다음의 떡볶이 답변은 빠졌다. 이를 모델 말투만의 문제로 처리하지 않았다.

처음 10회 방송에서 실제 생성된 21개 공개 발언과 합성 관객 상태를 `test/fixtures/recall-conversation.json`으로 고정했다. 이후 비교에서 과거 답변을 다시 생성하거나 원하는 답변으로 수정하지 않았다. 최초 탐색기의 `passed`는 실행·전달 완료를 의미하며 사실 정확도 합격이 아니다. 전체 원문 검토에서 위 두 실패를 확인했다.

## 변경

`server/recall-continuation.js`를 저널 검색에 연결했다. 검색된 말 뒤 같은 사람이 곧바로 한 “아 아니다”, “아냐”, “잘못 말했어”, 취소·정정 등의 원문을 함께 가져온다. 다른 관객의 채팅이 사이에 많아도 자기 다음 발언을 찾을 수 있다. 검색된 스트리머 질문에는 다음 스트리머 발언 전까지의 가까운 공개 답변도 최대 3개 함께 가져온다. 답변이 질문의 주제 단어를 반복할 필요가 없다.

검색 결과는 기존 최대 8개·원문 1,800자 안에서 구성한다. 발언과 이어진 정정의 자리를 함께 확보해 마지막에 정정만 잘리는 문제를 막는다. 2분 안의 같은 화자 정정, 90초 안의 질문 후 채팅을 후보로 삼으며, 방송·가상 이야기·목격자·최근 채팅 중복·원문 삭제·불확실한 전사의 경계를 유지한다. 전체 보존 순서를 확인하므로 듣지 못한 자기 발언을 건너뛰어 뒤의 정정을 앞선 말에 붙이지 않는다. 시각이 역전되는 연속 정정도 연결하지 않는다.

이것은 원문을 함께 제시하는 검색 보완이다. 인접한 말이 실제 답변인지, 앞선 주장이 최종적으로 참인지 확정하는 사실 DB가 아니다. 원문, 출처 ID, 화자, 시각, 가상 여부와 자동 STT 교정의 불확실성은 그대로 전달한다. 프롬프트와 모델·추론 수준을 바꾸거나 별도 생성 호출을 추가하지 않는다. 최근 검색 후보가 많으면 우선순위와 기존 예산에 따라 일부 묶음이 빠질 수 있다.

## 검증과 한계

- 추가한 6개 회귀 검사는 재방문, 12개 관객 채팅이 끼어든 연속 정정, 검색 예산, 목격/새 방송/가상/시각 경계, 최근 중복, 원문 삭제, STT 불확실성, 주제를 생략한 타인 답변을 다룬다. 제품 수정 전 6개 중 4개 실패, 수정 후 기존 기억 검사를 합친 23개가 통과했다. 첫 후보의 원문 보존 검사는 기본 30개 페이지만 읽어 실패했으므로 전체 보존 데이터를 확인하도록 검사 자체를 수정했고 그 실패 로그도 남겼다.
- 후속 검토에서 두 번째 정정의 시각이 첫 정정보다 과거인 사례를 추가해 후보의 실패를 재현하고, 시각 순서 검사를 보완했다. 최종 필수 검사 결과는 `artifacts/check-final.log`에 있다.
- `scripts/verify-recall-continuation.mjs --live`는 위 고정 기록을 실제 파일 저장소에서 복원하고 실제 Studio와 공식 CLI를 통해 두 질문을 재생한다. 출력의 단어 검사는 해당 두 누락을 찾는 보조 지표이며, 원문 전체에서 화자 귀속과 말투를 별도로 확인했다.
- 같은 기록으로 기존→수정, 수정→기존 순서의 8회 모델 비교를 했다. 기존은 두 번 모두 두 질문에서 실패했다. 수정본은 두 번 모두 약속을 토요일 아홉 시로 바로잡고, 팝콘도둑의 버터팝콘·모모의 떡볶이·스트리머의 군만두를 구분했다. 모델 지연은 약 9~11초였으며 속도 개선을 주장하지 않는다.

실제 수정본 답변 예시는 “저는 버터팝콘! 모모는 달짝지근하고 살짝 매운 떡볶이요. 군만두는 방장 픽이었죠 ㅋㅋ”다. 한 대화에서의 사실 회상 개선이며 관객 전체의 장기 관계·완전한 의미 검색·물리 음성 인식·자연스러움 전체에 대한 합격이 아니다. 물음표 없는 모든 구어체 질문이나 긴 시간이 지난 간접 정정을 인식하는 것도 보장하지 않는다.

최종 `npm run check`는 **597개 테스트, 실패·취소·건너뜀 0개와 TypeScript/Vite 빌드**를 통과했다. 최종 패키지는 `release/2026-09-13T23-22-33-304Z/app/BACKSEAT-win32-x64`, ASAR SHA-256은 `480fc45e9f456070731004e161bbde1d33cdd697f2d7e2e99d4004a6c3ad4064`다. 2,452개 파일·3,130,246,757바이트·소스 78개 일치, 전체 무결성 실패 0개다. 서명되지 않은 개발 배포본이다.

이 정확한 ASAR에서 추출한 Studio·저널·모델 연결 코드와 번들 CLI로 두 질문을 다시 실행해, 각각 한 명의 올바른 답변이 실제 서버 채팅으로 전달됐다. 모델 처리는 9,699ms와 11,092ms였다. 후원·새 관객·성향 변화·클립·전사 교정은 생성되지 않았다. 번들 Python·Whisper 한국어 전사·YAMNet·출력 대사 전사와 공식 CLI 계정 상태도 통과했다. 음성 입력은 합성 WAV이고 네이티브 창이나 물리 장치 검사와 구별한다. 시각 순서 보완 전의 `23-18-22-980Z` 패키지 및 비교 결과는 후보 증거로 따로 남겼다.
