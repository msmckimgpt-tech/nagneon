# 선택형 판단 서비스 기반

`server/decision/index.js`는 생성 모델과 분리된 판단 보조 모듈이다. 현재 앱의 Studio, 제공처 라우팅, 설정 UI에는 연결되어 있지 않다. TypeSafe HTTP 클라이언트와 수동 연결 시험은 별도로 제공하며, 키 저장이나 새로운 의존성은 없다. 이 모듈을 추가해도 설치된 앱의 판단 품질이나 기능은 달라지지 않는다.

기본 모드 `off`는 요청 ID, 어댑터 호출, 진단 이벤트를 생성하지 않는다. `shadow`는 관찰 결과만, `assist`는 제안만 반환하며 두 결과 모두 `apply: false`다. 생성된 값은 신뢰하지 않는 입력이며 소비자가 도메인 스키마와 최신 상태를 검증해야 한다. 권한, 목격 범위, 기억 정정·삭제, 포인트, 저장과 최종 수용은 기존 controller의 책임이다.

`JevAdapter({ judge })`의 주입 함수는 `{ task, input, signal }`을 받고 정의된 `value`를 포함한 객체를 반환한다. 이는 제품 내부 경계이며 실제 공급자 API 규격을 뜻하지 않는다. 공급자 연결 전에 해당 SDK의 취소·종료 보장을 검증해야 한다.

서비스는 기본 1초 제한 시간과 2개 동시 요청 한도를 사용한다. timeout과 공급자 오류는 기존 경로로 복귀할 수 있는 `abstain`을 반환하고, 호출자 취소와 서비스 종료는 호출자에게 rejection으로 전달한다. timeout 후에도 끝나지 않은 어댑터 작업은 동시 요청 수에 계속 포함되며 늦은 결과는 수용하지 않는다. 자동 큐나 재시도는 없다.

`close()`는 신규 작업을 거절하고 진행 중인 어댑터에 취소를 전달한 뒤 실제 정리가 끝날 때까지 기다린다. JavaScript Promise의 외부 작업을 강제로 종료할 수는 없으므로 취소에 응답하지 않는 어댑터가 있으면 drain도 끝나지 않는다. 이러한 어댑터는 앱 종료 경로에 연결해서는 안 된다. timeout으로 호출자를 복귀시키는 것과 외부 작업의 종료는 별개다.

진단에는 task, mode, 요청 ID, 숫자 revision, 경과 시간, 결과 종류와 제한된 오류 코드만 담는다. 입력·결과 본문, scope token과 공급자 오류 메시지는 전달하지 않는다. 결과 메타데이터는 요청의 식별자·모드·scope·revision을 덮어쓸 수 없다.

검증은 `node --test test/decision-service.test.js`와 `npm run check`로 수행한다. 테스트는 합성 어댑터를 사용하며 실제 JEV의 한국어 품질, 지연, 비용이나 데이터 처리 조건을 검증하지 않는다. 실제 연결에는 최소 입력 투영, 최신성 확인, 보호 기억 보존, 명시적 전송·비용 안내와 공급자 검증이 필요하다.

## 공식 TypeSafe 연결 시험

사용자가 PowerShell에서 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test-JevConnection.ps1`를 실행한다. 숨김 입력에 공식 TypeSafe API 키를 넣으면 자식 Node 프로세스의 표준 입력으로만 전달한다. 키를 명령 인자·환경변수·파일·시험 결과에 기록하지 않으며 프로세스 종료 후 재사용하지 않는다. 입력 과정은 사용자 터미널에서 진행하고 키를 대화에 붙여넣지 않는다.

`scripts/verify-jev-live.mjs`는 공식 `https://api.typesafe.ai/v1/models` 조회 1회 후 `jev-latest`가 있을 때만 `/v1/systemone`에 판단 요청 1회를 보낸다. 다른 모델로 자동 변경하거나 재시도하지 않는다. 각 HTTP 요청 제한 시간은 10초이며 PowerShell은 자식 시험 프로세스를 최대 45초까지 기다린다. 클라이언트 취소는 로컬 HTTP 요청의 종료이며 제공처의 계산·청구 취소를 보장하지 않는다.

전송 내용은 코드에 고정된 한국어 합성 질문과 합성 기억 3개다. 실제 프로필·방송 기록·화면·음성은 읽지 않는다. `memory-rerank` 작업을 shadow 모드로 실행하며 선택·확률 순서만 관찰한다. 결과는 앱의 기억 선택이나 생성 모델에 적용하지 않는다. 이 시험의 Choice는 세 후보 중 최상위 항목을 확인하는 작은 예제이며, 실제 보호 기억을 포함하는 제품 재정렬을 완성한 것이 아니다.

`server/decision/typesafe-client.js`는 호출 대상 호스트와 경로를 고정하고 리다이렉트를 거절한다. 입력은 질문과 후보 ID·본문만 투영하고, 2~16개 후보 및 문자열 길이를 제한한다. 응답 본문은 64KiB까지 읽고 후보 집합·확률·선택·confidence·모델명·usage를 검증한다. HTTP 오류 원문은 노출하지 않는다. 이 최소 투영은 주어진 본문의 개인정보를 지우는 기능이 아니므로 실제 데이터 연결에는 별도 전송 범위 검토가 필요하다.

결과는 `artifacts/jev-live/run-*/result.json`에 기록한다. `status`는 인증·API 구조·응답 수용 여부, `fixtureMatched`는 기대한 후보 `m1` 선택 여부다. 호출 성공과 판단 정답을 구분하며, 시험 실행 종료 코드는 둘 다 통과해야 0이다. 실제 반환 모델명, 소요 시간, 입력·출력 토큰을 보존한다. 공개 요율에 따른 입력 비용은 추정치이며 계정 잔액·청구액을 확인한 값이 아니다. 한 번의 합성 시험으로 한국어 판단 품질이나 일반적인 지연을 보장하지 않는다.
