# 선택형 JEV 판단 보조

JEV는 TypeSafe의 `https://api.typesafe.ai/v1/systemone` 또는 OpenRouter의 `https://openrouter.ai/api/v1/systemone`을 쓰는 선택형 판단 보조다. 기존 설정의 제공처는 TypeSafe로 읽으며 기본 설정은 **끄기**다. OpenRouter 경로도 System One 요청을 TypeSafe로 전달하며, 일반 채팅 모델이나 임의 주소를 사용하지 않는다. 데스크톱 앱에서 연결한 JEV 키는 운영체제 보안 저장소로 암호화해 앱 프로필에 저장하고 다음 실행에 복원한다. 브라우저 전용 서버는 키를 실행 중 메모리에만 둔다. 키가 없거나 전송 안내에 동의하지 않으면 JEV 호출은 없다. 설정의 **관찰만**은 요청과 사용량을 기록하되 방송 결과에 제안을 적용하지 않는다. **판단 보조**에서는 허용된 후보와 높은 확신을 통과한 제안만 사용한다. 응답이 불확실하거나 실패하면 기존 동작을 따른다.

연결·사용량 탭에서 제공처, 모델, 대기 시간(250~5000ms), 작업별 사용 여부, 전송 동의를 별도로 적용한다. OpenRouter를 선택하면 요청이 OpenRouter를 거쳐 TypeSafe로 가고 OpenRouter 계정에 청구된다. 제공처 변경 시 진행 중 JEV 요청을 취소하고 이전 키·캐시·연결 확인을 지우며 모드와 전송 동의를 다시 설정해야 한다. 제공처를 먼저 적용해야 새 키를 넣거나 연결 확인을 할 수 있다. 고정 모델 `jev-1.13.0`은 OpenRouter에서 `jev-1.13`으로 전송되고 `jev-latest`는 최신 JEV 별칭으로 전송된다. 연결 확인은 실제 API 요청 한 번을 쓰지만 입력은 고정된 합성 문장이다. 키를 넣거나 설정을 바꾼 직후의 상태는 **연결 확인 전**이며, 이전 키나 모델의 연결 성공을 이어 표시하지 않는다. 공식 키 페이지는 [TypeSafe 콘솔](https://console.typesafe.ai/keys)과 [OpenRouter 키 설정](https://openrouter.ai/settings/keys) 중 선택한 제공처의 고정 주소를 연다.

현재 앱 실행 동안의 호출 수, 보고된 입력 토큰, 입력 기준 예상 USD, 캐시 적중, 판단 보류, 적용 수, 마지막 지연을 표시한다. 예상액은 계정 청구서가 아니며 실제 청구액은 선택한 제공처 계정에서 확인한다. 크레딧·잔액 부족(HTTP 402)은 별도 안내하며 제공처 원문 오류를 화면에 노출하지 않는다. 키와 원문 입력·응답은 일반 설정 파일, 상태 스냅샷, 진단에 저장하지 않는다. 암호화 저장이 불가능할 때 새 키는 이번 실행에만 유지하며 화면에 그 상태를 표시한다. 저장된 키가 손상되거나 보안 저장소에서 복원할 수 없으면 연결 전 상태와 복원 오류를 표시한다. 복원 직후에도 실제 연결 성공으로 표시하지 않고 합성 연결 확인을 다시 실행해야 한다. 키 제거와 제공처 변경은 저장된 암호문과 메모리 키를 지운다. 방송/응답 중 설정과 키 변경은 잠기지만 **JEV 바로 끄기**는 현재 저장된 설정의 모드만 끄고 진행 중 요청을 취소한다.

인증된 스튜디오의 `GET/PUT /api/decision`, `POST /api/decision/key`, `POST /api/decision/probe`가 설정·키·합성 연결 확인을 제공한다. `GET /api/state`와 `/api/events`의 스튜디오 화면에는 비밀이 제거된 판단 상태만 나온다. 오버레이는 `surface=overlay`를 요청하며 서버가 최초 상태, 갱신 패치, 전송 재개, 재연결 시 판단 상태를 제거한다. 기존 오버레이 인증과 입력/투명도 동작은 유지한다.

작업별로 실제 사용되는 경로는 먼저 반응할 관객, 본인이 목격한 대화·클립·공개 글 기억의 관련도, 현재 말의 의도, 선택적인 자동 반응의 반복, 커뮤니티 관심, 수집이 허용된 문화 자료, 기존 기준에 맞는 핫클립 후보, 이미 등록된 호환 모델 경로다. 직접 건넨 말과 기존 발언 수용 규칙, 목격·정정·삭제 및 보호 기억, 게시물 읽음 기록, 기존 검색/훈수 권한, 클립 원본과 방송 포인트는 기존 코드가 최종 확인한다. 모델 경로 도움은 기존 단일 Codex/Gemini 선택을 바꾸지 않는다. 출입 시점의 별도 후보 순서 변경과 독립적인 클립/소셜 기억 조회는 현재 범위에 포함되지 않는다.

`node scripts/evaluate-jev.mjs`는 합성 한국어 사례 13개를 **오프라인**에서 요청/응답 스키마와 보수적인 선택 정책으로 확인한다. 네트워크 요청을 하지 않으며 출력의 `fixtureSelected`는 준비된 답안의 처리 결과일 뿐 모델 품질 측정이 아니다. `JEV_API_KEY=... node scripts/evaluate-jev.mjs --live`를 명시적으로 실행하면 같은 합성 사례를 고정 모델 `jev-1.13.0`에 요청하고 사례별 예상 레이블 일치, 판단 보류, 지연, 입력 토큰과 입력 기준 예상액을 보고한다. 키는 보고서에 기록하지 않는다. 오프라인 검사와 합성 연결 시험만으로 실제 서비스의 한국어 판단 품질, 지연, 요금을 검증할 수는 없다.

검증은 합성 로컬 전송을 사용한 Node 회귀 테스트와 별도 Electron 프로필의 설정 화면 스모크로 수행한다. 스모크는 키 입력 삭제, 합성 연결 확인, 실행 중 즉시 끄기와 요청 취소, 브라우저 전용 서버의 재시작 후 키 비보존, 고정 콘솔 링크를 확인한다. Electron 보안 저장소를 주입한 별도 프로필에서는 실제 프로세스 재시작 후 암호화 키 복원과 제거를 확인한다. 실제 계정·결제·TypeSafe 서비스에 접속하거나 설치된 앱을 활성화하지 않는다.
