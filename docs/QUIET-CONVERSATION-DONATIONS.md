# 조용한 교류의 응원 포인트

게임의 극적인 성공뿐 아니라 서로의 취향을 이해하거나 앞선 이야기를 기억하며 고마움을 나누는 대화도 가상 포인트 후원 대상이다. 모델은 실제로 제공된 화면·발언·목격 범위와 관객의 자발적인 의사를 근거로 판단한다. 평범한 인사·단순 칭찬·포인트 요구 자체를 후원 근거로 삼지 않는다.

후원 지급에서 `excitement >= 0.8`과 `impact >= 0.8` 조건을 제거했다. `positiveMoment.positive`와 근거 신뢰도 0.75, 비어 있지 않은 이유·동일 사건 식별자, 관객의 후원 의사를 확인한다. `impact`는 장면의 소란스러움이 아닌 긍정적 의미의 크기이며 기존 지급액 계산에 사용한다. 흥분도를 후원을 위해 높이지 않는다.

관객이 실제로 머무른 시간, 관객 지갑, 후원 간격, 동일 사건 중복 방지, 유료 요청의 보상 제외는 유지한다. 새 프로필 200P·기존 잔액·초대 가격·지급액 공식은 바꾸지 않는다. 일정 시간마다 포인트를 지급하거나 후원·친밀감을 강제하는 기능은 아니다. 실제 대화마다 후원 발생을 보장하지 않는다.

## 검증

- 경제 회귀: 낮은 흥분도 0.08·의미 크기 0.65의 자발적 후원을 수용한다. 같은 대화 재지급, 실제 입력 없음, 유료 행동, 낮은 신뢰도, 근거·식별자 없음, 후원 의사 없음, 부재·시청 시간 부족은 지급하지 않는다.
- 공식 기존 CLI 설정 `gpt-6-astra / low`로 사용자 자료 없는 합성 두 사례를 호출했다. 조용히 서로의 취향을 기억한 대화는 `positive=true`, `impact=0.65`, `excitement=0.08`과 자발적인 후원 한 건을 생성했다. 단순 포인트 요구는 `positive=false`와 후원 없음이었다.
- 최초 시험에는 `impact >= 0.8`이 남아 있어 모델의 후원 의사가 지급되지 않았다. 이를 제거한 최종 경제 코드에 **저장된 동일 모델 응답을 재생**하여 21P 지급과 포인트 요구 0건을 확인했다. 최종 코드로 새 모델 호출을 한 결과와 구분한다.

원본은 `quiet-conversation-donations-20260923/artifacts/quiet-live.json`, `quiet-replay.json`, `economy-final.log`에 보존한다. 재생 시험 첫 시도는 검증용 설정 정규화를 빠뜨려 실패했고, 실제 `Settings` 스키마 적용 후 통과했다. 실제 사용자 방송의 후원 빈도·획득 속도·장기 경제 균형은 이 두 사례로 입증하지 않았다. 모델의 개인적 판단과 응답 차이는 남는다.
