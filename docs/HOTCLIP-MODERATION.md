# 관객 핫클립과 금칙어

방송 중 관객이 선택한 핫클립의 제목과 이유에는 방송 설정의 금칙어가 적용됩니다. 방송 채팅과 같은 NFKC 문자 정규화 및 대소문자 검사 규칙을 사용하므로, 소문자나 전각 문자로 바뀐 금칙어도 차단합니다.

정규화는 검사에만 사용합니다. 허용된 제목과 이유의 저장 원문은 유지합니다. 제목과 이유 사이에는 기존 한 칸 공백을 유지하며, 공백이나 구두점을 지워서 검사하지 않습니다. 금칙어가 없으면 이 검사로 선택을 차단하지 않습니다.

차단된 선택은 클립을 저장하거나 관객의 클립 생성 쿨다운을 소모하지 않습니다. 방송 응답 자체의 일반 기록은 유지됩니다. 다음 정상 선택은 기존 목격 범위·시간·소리·중복·쿨다운 조건을 충족하면 저장됩니다.

## 검증

`test/live-clip-moderation.test.js`는 실제 Studio 방송 응답 수용과 관객 클립 선택·저장을 결정적 합성 응답으로 검사합니다.

- 제목·이유 각각의 원문, 소문자, 전각 문자와 전각 금칙어 설정
- 비슷한 정상 단어, 공백·구두점 구분, 제목과 이유의 경계, 빈 금칙어 배열
- 차단된 선택 후 정상 선택, 정상 선택 후 기존 쿨다운 경계
- 허용된 Unicode 원문과 클립 메타데이터의 정상 방송 중지·저장·새 World/Clips 인스턴스 재로딩

합성 응답과 별도 임시 데이터만 사용합니다. 실제 계정의 AI 응답, 물리 장치, 동영상 디코딩, Windows 설치본 실행을 검증하는 검사는 아닙니다.
