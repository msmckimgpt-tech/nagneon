# 비언어 전사와 방송 입력의 연속성

구독 전사에 `[laughs]`, `[clear throat]` 같은 알려진 표기만 들어오면 실제 발언과 분리한다. 이러한 표기를 수신했다는 이유로 진행 중인 화면 분석을 취소하거나, 아직 전달되지 않은 관객의 화면 반응을 지우지 않는다. 원래 전사와 수신 확인은 유지한다.

같은 요청에 새 화면, 관객이 들은 시스템 소리, 새 후원·관객 대화 또는 진행 중인 자연 활동이 있으면 기존 방송 처리 흐름을 유지한다. 비언어 표기를 소비했다는 이유로 새 화면까지 분석한 것으로 완료 처리하지 않는다. 실제로 함께 본 입력이 없을 때는 별도 모델 호출 없이 표기만 처리하며, 동일 화면 억제·재시도 간격·요청 한도·방송 종료·입장 이후 목격 범위를 그대로 적용한다.

표기를 소비한 뒤에는 그 표기의 이전 청취자 목록으로 현재 화면의 수신자를 제한하지 않는다. 이후 입장한 관객에게는 입장 이후의 화면만 전달하고 이전 비언어 전사를 새 발언으로 전달하지 않는다. 표기와 함께 실제 말이 있거나 키보드로 입력한 문자열은 기존 발언 처리와 우선순위를 유지한다.

제공처의 표기는 원음으로 검증한 감정이나 억양이 아니다. 표기를 발언처럼 인용하거나 확정된 심리로 해석하지 않는다. 합성 입력 회귀는 화면·소리·채팅 처리와 취소·개인별 목격 경계를 확인하며 실제 게임 및 음성 인식 품질의 수용 검증은 별도로 진행한다.
