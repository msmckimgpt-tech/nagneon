# 관객의 방문과 게임 시청 시간

관객이 방송을 나갔다가 같은 ID로 돌아오면, 부재 전후의 두 화면 관찰 사이를 개인 시청 시간으로 누적하던 문제를 수정했다. 예를 들어 첫 방문에서 4초를 집계한 관객이 잠시 나갔다가 다음 관찰 전에 돌아오면, 부재를 포함한 6초가 추가되어 10초로 표시될 수 있었다. 수정 후에는 앞서 집계한 4초와 실제로 목격한 장면을 유지하고, 새 방문에서 연속된 관찰을 확인한 뒤 시간을 더한다.

`Studio`는 화면 분석을 요청할 때 모든 목격자의 입장 시각을 별도로 보관한다. `Knowledge.observe`는 이전 관찰과 현재 관찰에서 같은 관객의 입장 시각이 일치할 때만 개인 시간을 누적한다. 분석이 늦게 끝나도 요청 당시의 방문을 사용하므로, 퇴장 전에 실제로 함께 본 구간은 보존되고 이후의 새 방문과 연결되지 않는다. 동일 화면에서 모델 호출을 생략하는 집계에도 이 조건을 적용한다.

목격자에는 채팅할 관객으로 선택되지 않은 잠수 관객도 포함한다. 채팅·후원·성향 변경에 쓰는 참여자 범위는 그대로 유지하며, 방문 정보는 모델 입력이나 저장 파일에 추가하지 않는다. 저장 실패 시 시간과 마지막 관찰을 확정하지 않아 재시도에서 이중 집계하지 않는다.

저장 형식과 기존 누적 시간·게임 기억은 유지된다. 이전 버전에서 과다 집계됐을 수 있는 시간은 출입 이력을 복원할 근거가 없어 소급해서 고치지 않는다. 게임의 전체 관찰 시간과 개인별 시청 시간은 별도로 집계한다. 이 값은 관찰 지점 사이의 제한된 시간 집계이며, 사용자의 눈동자나 실제 집중을 측정한 값이 아니다.

## 확인한 범위

- 수정 전 합성 관객의 4초가 부재를 포함해 10초로 늘어나는 현상과 실제 `Studio`·인증된 루프백 HTTP 경로의 과다 집계를 재현했다.
- 신규 회귀 9개와 기존 게임 지식·출입·저장 원자성 관련 검사 총 68개가 통과했다. 방문 정보가 없거나 잘못된 경우, 호출자 사본 변경, 늦은 분석, 참여하지 않은 잠수 관객, 정적인 화면, 다음 관객 모델 입력, 디스크 재시작을 검사했다.
- 첫 검사의 생략 사유 문자열과 재시작 후 장면 개수 기대는 기존 동작에 맞게 바로잡았다. 동일 장면을 중복 생성하는 대신, 이미 목격한 장면이 그대로 저장되는지 비교한다. 실패 원본도 작업 공간의 `artifacts`에 보존했다.

사용자 화면·대화·음성이나 실제 모델을 시험 자료로 사용하지 않았다. 실제 게임의 장기 대화 품질, 물리 장치, 패키지 설치 수용 검증은 이 회귀 결과에 포함되지 않는다.
