# Nagneon 사용 안내

> 이전 BACKSEAT 개발 안내를 이어받은 상세 문서입니다. 과거 테스트 수치와 배포 기록은 당시 환경의 결과이며, 현재 브랜드 변경의 검증 범위는 [Nagneon 전환 기록](NAGNEON.md)을 참고하세요.

Windows에서 게임 화면·시스템 출력 소리·한국어 발화를 함께 인식하며 반응하는 개인 AI 관객 방송실입니다. GPT-6 Astra / low, 독립적인 관객 성격과 기억, 매니저, 투명 채팅 오버레이, Just Chatting을 제공합니다. 현재 버전은 실제 계정·실제 Steam 게임에서 동작을 확인한 로컬 MVP입니다.

현재 확장에는 **마음과 포인트**, **핫클립**, **방송 놀이터**가 포함됩니다. 가상 후원으로 캐릭터의 속마음·취향·관계 수첩을 탐색하고 행동을 협상할 수 있습니다. 기념일·시상식·팬 페스티벌 등 10종 기획 방송을 자유 대화와 함께 진행하며, 14종 상황 연습도 제공합니다. 완료한 기획 방송의 대화 기록은 방송 밖 이야기의 장면 기록 게시글로 남겨 관객들과 댓글을 이어갈 수 있습니다. [사용 흐름과 검증](EXPERIENCES.md), [판매 준비 기준](RELEASE-GATES.md)을 참고하세요.

Python·음성 모델·공식 Codex를 포함한 Windows 독립 개발 배포본도 생성했습니다. 새 프로필의 실행·설정 복원·오버레이와 개발 도구 경로 없는 전사·실제 모델 응답을 확인했습니다. 아직 서명된 설치 프로그램이나 Steam 판매 완료본은 아닙니다. 실행 경로와 재현 방법은 [배포 검증](DISTRIBUTION.md)에 있습니다.

처음 사용하는 프로필에는 방송 이름·분위기·훈수 정책·계정 연결을 고르는 안내가 표시됩니다. 기존 프로필은 바로 방송실로 들어가며 설정에서 안내를 다시 열 수 있습니다. [첫 방송 안내와 인증 검증](ONBOARDING.md), [관객별 목격 지식](VIEWER-KNOWLEDGE.md)을 참고하세요.

## 설치 후 실행

`Start-Nagneon.cmd`를 실행하세요. 먼저 README의 소스 설치 절차로 의존성과 음성 모델을 준비하세요. 앱을 다시 실행하면 방송은 자동 시작하지 않습니다.

1. **방송 설정 → 연결 상태 새로고침**에서 ChatGPT 구독 연결을 확인합니다.
2. 방송 모드를 **실제 AI 관객**으로 선택하고 제목·관객·호출 한도를 설정합니다.
3. **게임 화면 연결**에서 함께 볼 게임 창 하나를 선택합니다. 전체 화면을 선택하면 그 모니터의 다른 내용도 전달될 수 있습니다.
   **소리 연결**을 누르면 배경음악·효과음·대사도 공유합니다. 소리는 다른 앱을 포함한 Windows 출력 전체이며, 화면 전달을 끄면 소리만 공유할 수 있습니다.
4. **방송 시작** 후 마이크를 켜거나 채팅 아래의 **관객에게 말하기**를 사용합니다.
5. **훈수 요청** 버튼이나 “고양이, 지금 어떻게 하면 좋을까? 훈수 부탁해” 같은 발언으로 도움을 요청합니다.
6. **오버레이 열기**로 게임 위에 채팅을 띄웁니다. 상단을 끌어 이동하고 창 크기를 조절할 수 있습니다. 방송 중에는 하단 입력창에서 Enter 또는 **보내기**로 관객에게 말할 수 있습니다. 한글 조합 중의 Enter는 전송하지 않습니다. 방송실 창이 열려 있어야 하며, 접수 실패 시 입력한 내용은 남아 있습니다. 클릭 통과 중에도 입력창을 클릭해 타이핑할 수 있습니다.

화면 없이 대화하려면 설정에서 **Just Chatting**을 선택하세요. 마이크 버튼은 실제 AI 방송이 시작된 후 작동합니다. 리허설은 예시 채팅이며 화면·음성을 AI로 인식하지 않습니다.

**Ctrl+Shift+F10**은 오버레이 클릭 통과 전환, **Ctrl+Shift+F9**는 방송·마이크·화면의 긴급 중지입니다. 방송실 왼쪽에도 클릭 통과 전환 버튼이 있습니다. 단축키가 다른 앱과 충돌하면 방송실 버튼을 사용하세요. 일반 창 모드/테두리 없는 창을 권장하며 모든 독점 전체화면 게임의 오버레이 호환성을 검증하지는 않았습니다.

## 시스템 소리

소리 종류는 로컬 YAMNet, 출력 속 대사는 별도 Whisper로 분석해 Astra/low에 전달합니다. 게임 대사와 스트리머의 마이크 발언을 분리하고, 핫클립은 두 소리를 함께 녹화합니다. 관객별 청취 구간·중지·소리 전용 모드 및 한계는 [시스템 소리 안내](SYSTEM-SOUND.md)에 있습니다. 개발 환경의 모델 준비는 `node scripts/prepare-sound-model.mjs`이며 독립 배포본에는 포함됩니다.

## ChatGPT 구독 연결

이 앱은 ChatGPT Desktop의 비공개 세션이나 인증 토큰을 추출하지 않습니다. **공식 Codex CLI의 ChatGPT 로그인**을 이용해 `codex exec`로 호출합니다. 개발 PC의 CLI 0.154.0-alpha.6.2에서 ChatGPT 로그인과 실제 Astra 이미지·텍스트 요청을 확인했습니다. 다른 계정/요금제에서도 동일하게 이용 가능하다는 보장은 없으며 Codex 접근 권한과 모델 제공 여부에 따릅니다. [공식 인증 안내](https://learn.chatgpt.com/docs/auth), [비대화형 실행 안내](https://learn.chatgpt.com/docs/non-interactive-mode)

CLI가 없다면 공식 Codex를 설치하고 터미널에서 `codex login`으로 본인 계정에 로그인한 뒤 앱에서 연결 확인을 누르세요. API 키를 입력할 필요는 없습니다. CLI 위치를 자동으로 찾지 못하면 `.env.example`을 `.env`로 복사하고 `CODEX_BIN`에 실행 파일의 전체 경로를 지정합니다. 앱이 사용하는 모델은 `gpt-6-astra`, 추론은 `low`입니다. [공식 모델 안내](https://developers.openai.com/api/docs/models/gpt-6-astra)

기본 제공처 `AI_PROVIDER=codex`는 별도 API 결제를 사용하지 않고 **계정의 Codex/ChatGPT 구독 사용량**을 소비합니다. 구독이 무제한이라는 뜻은 아닙니다. 다른 Codex 작업과 한도를 공유합니다. `AI_PROVIDER=openai`로 직접 변경한 경우에만 별도의 API 제공처 경로를 사용하며 그 경로의 실계정 검증은 수행하지 않았습니다.

## Codex와 Gemini 선택하기

방송을 멈춘 뒤 **설정 → 연결·사용량 → AI 제공처·관객 모델 선택**에서 **ChatGPT 구독 · Codex** 또는 **Antigravity · Gemini**를 고르고 **선택한 설정 적용**을 누르세요. 다음 관객 요청부터 선택한 제공처가 사용되며, 관객·대화 기록과 로컬 음성 인식은 유지됩니다. 선택은 앱을 다시 실행해도 복원됩니다.

Gemini는 공식 Antigravity CLI `agy`의 Google 계정 인증을 사용합니다. 별도 Gemini API 키를 입력하지 않습니다. CLI가 없다면 [공식 설치·인증 안내](https://antigravity.google/docs/cli/install/)에 따라 설치하고 한 번 로그인하세요. 실행 파일 위치를 자동으로 찾지 못하면 `ANTIGRAVITY_BIN`에 `agy`의 전체 경로를 지정합니다. 모델 목록 확인은 연결 준비 상태이며, 실제 계정 응답은 **모델 응답 확인 · 1회 사용**으로 확인합니다.

Gemini의 기본 선택은 `gemini-3.8-flash-low`이며 연결 후 CLI가 알려주는 Gemini 모델을 고를 수 있습니다. 선택한 화면과 대화가 Antigravity에 전달되고, 해당 계정의 사용량·한도가 적용됩니다. 요청마다 독립적인 CLI 대화를 사용하며, CLI 자체의 대화 보관 정책이 적용됩니다. 전송을 마친 임시 화면 파일은 Nagneon에서 삭제합니다. 연결 오류·사용량 제한이 생기면 같은 설정에서 Codex로 다시 바꿀 수 있습니다.

## 응답 속도와 사용량

- 화면 관찰 간격은 기본 12초, 설정 가능 범위는 5~120초입니다. 실제 모델 요청은 동시에 하나만 실행합니다.
- 발언은 대화를 위해 화면 주기보다 먼저 처리하며 최소 요청 간격은 2초입니다. 따라서 화면 관찰 간격이 60초여도 말하는 동안에는 더 자주 호출됩니다.
- 마이크는 6초 단위로 구간을 나누며 로컬 음성 인식이 처리 중이면 다음 구간을 건너뛸 수 있습니다. 지속 발화에서 문장이 잘리거나 누락될 수 있습니다.
- 검증에서 9.4초 한국어 합성 음성의 로컬 전사는 약 2.8초, 해당 전사를 받은 Astra 반응은 약 14초 걸렸습니다. 관객 채팅은 이후 수 초에 걸쳐 표시합니다. **초저지연 연속 영상·음성 스트리밍 엔진은 아닙니다.**
- 모델 호출 한도는 세션별 시도 횟수입니다. 실패한 요청도 포함하며 실패 재시도는 점차 늦춥니다. 로컬 STT는 모델 호출 한도를 사용하지 않습니다. 방송 후 후기 생성은 모델 호출 1회를 사용합니다.
- 한도에 도달하면 추가 모델 응답이 중단됩니다. 방송 종료 후 한도를 확인하고 다시 시작하세요. UI의 시도 횟수는 계정의 실제 잔여 토큰/사용량과 다릅니다.

## 관객과 게임 기억

관객 이름, 성격, 가치관, 사교성, 게임 숙련도, 참여 여부를 편집할 수 있습니다. 활성 관객 중 매니저를 지정하고 금칙어·스포일러 표식 필터·슬로우 모드·운영 지침을 설정합니다. 관객별 활동/잠수/이탈 상태, 함께한 시간, 호명, 최근 발언과 관객 사이 언급을 기억합니다. 같은 모델이 선택된 여러 페르소나를 생성하는 방식이며 페르소나별 독립 모델 프로세스는 아닙니다.

새 게임은 자동 인식하거나 게임 프로필을 추가합니다. 지식은 게임별 관찰과 사용자 메모로 축적합니다. ‘학습’은 로컬 기억을 다음 요청에 제공하는 방식이고 모델 가중치 학습은 아닙니다. 인지도는 사용자 조절값이고 실제 판매량/스트리머 인기도를 자동 수집하지 않습니다. 낮은 익숙함에서는 모르는 것을 질문하도록 지시합니다.

틀린 게임 훈수/관심 끌기 슬라이더는 모델에 전달하는 연출 목표값이며 정확한 발생 확률 보장은 아닙니다. 인터넷 공략 검색은 기본 꺼짐이며 설정을 켠 상태에서 훈수를 요청했을 때만 허용합니다. 실제 온라인 검색 결과의 정확도는 이번 Steam 테스트 범위에 포함하지 않았습니다.

**방송 밖 이야기**는 로컬 가상 커뮤니티입니다. 글, 방송 후기, 유효기간이 있는 밈·내부 농담을 저장합니다. 실제 Discord/Reddit 게시나 외부 사람과의 통신 기능은 없습니다. 관련 설계와 출처는 [관객 연구 보고서](AUDIENCE-RESEARCH.md)에 있습니다.

**관객 유입**은 방송 설정에서 켤 수 있습니다. 클립·공략·팬 활동·방송 토론·우연한 탐색의 비중과 입장 간격을 조절하고 **새 관객 후보 6명 추가**로 후보를 늘리세요(매니저 포함 최대 40명). 실제 방송에서 후보가 순차 입장하며 첫 유입 동기, 방문 횟수와 기억을 유지합니다. `나의 관객`에서 누적 유입 분포와 입장 대기를 확인합니다. 실제 사이트 이용자를 데려오거나 특정 사이트의 모든 사람을 같은 성격으로 복제하는 기능은 아닙니다. 기존 설정에서는 꺼져 있으며 리허설에서는 관계를 갱신하지 않습니다.

## 데이터와 장치

화면 원본과 원시 마이크 음성을 상시 녹화하지 않습니다. 선택한 화면의 JPEG, 발화 전사, 음성 특성, 최근 대화와 관련 기억은 AI 요청에 전달됩니다. 원시 마이크 음성은 기본 경로에서 로컬 Python으로만 처리합니다. 음량·음높이·속도는 낮은 확신의 단서이며 학습된 감정 판정기나 정신상태 진단 기능이 아닙니다.

Codex 호출 시 임시 화면 파일을 OS 임시 폴더에 만들고 프로세스 종료 후 삭제를 재시도합니다. OS 잠금 등으로 삭제에 실패하면 오류 로그에 임시 경로가 남습니다. 앱이 강제 종료되면 임시 파일이 남을 수 있습니다. 영구 저장은 아래와 같습니다.

| 경로 | 내용 |
|---|---|
| `data/settings.json` | 방송 설정·페르소나·차단 상태 |
| `data/knowledge.json` | 게임별 관찰·사용자 메모·시청 시간 |
| `data/audience.json` | 관객 기억·관계·가상 커뮤니티 글 |
| `.models/`, `.venv/` | 로컬 음성 모델·Python 환경 |
| `artifacts/` | 개발 테스트의 화면·합성 음성·결과·게임 저장 백업 |

현재 방송의 전체 채팅은 메모리에 있으며 앱 종료 전 **매니저 → 기록 내보내기**로 저장할 수 있습니다. 개인별 일부 기억과 후기는 별도로 영구 저장됩니다. 게임 기억은 앱에서 삭제할 수 있고 전체 로컬 데이터를 초기화하려면 앱을 닫고 `data`를 별도 위치에 백업한 뒤 원하는 파일을 관리하세요.

서버는 루프백 주소만 사용하며 모든 화면·기록·클립·이벤트 요청에 실행별 인증을 요구합니다. 데스크톱의 비영구 세션이 인증 헤더를 붙이며 토큰은 페이지 코드나 내보내기에 포함되지 않습니다. 외부 Origin·잘못된 Host·비정상 변경 요청도 거부합니다. 이는 같은 OS 권한으로 프로세스 메모리나 저장 파일을 읽는 악성 프로그램까지 격리하는 장치는 아닙니다. 오버레이에는 캡처 보호가 적용되어 OS 화면 캡처에서 빠질 수 있습니다.

개발 브라우저는 `npm start`가 터미널에 표시한 일회용 `/connect#...` 주소로 먼저 연결합니다. 주소는 공유하지 마세요. 개발용 로그인만 HttpOnly 세션 쿠키를 사용합니다. Vite를 함께 사용할 경우 `127.0.0.1` 주소를 사용하세요. 배포 앱에서는 이 브라우저 연결 경로를 열지 않습니다.

## 다른 PC에서 개발 설치

Windows, Node.js 22 이상, Python 3.13, ChatGPT 로그인 가능한 공식 Codex CLI를 준비합니다.

```powershell
npm ci
.\Setup-LocalSpeech.ps1 -Python 'python'
npm run desktop
```

음성 설치는 프로젝트 전용 가상환경과 모델 다운로드를 만듭니다. 현재 CPU/int8, 4스레드 설정입니다. GPU 최적화, 서명된 설치 프로그램, 자동 업데이트는 포함하지 않았습니다.

```powershell
npm run check
# Electron 렌더러 검사: 합성 장치만 사용
.\node_modules\electron\dist\electron.exe scripts/verify-desktop.cjs
# 아래 두 검사는 실제 구독 사용량을 소비합니다.
node scripts/verify-live.js
node scripts/verify-conversation.js
node scripts/verify-discovery.js
```

실제 검사에는 `artifacts`의 개발용 이미지/음성 fixture가 필요합니다. 실행 결과는 [검증 기록](VALIDATION.md)을 참고하세요. 브라우저 개발은 `npm run server`와 `npm run dev`를 각각 실행하며 Windows 투명 오버레이는 Electron에서만 동작합니다.

## 현재 한계

모든 게임에서 정확한 규칙·승패를 이해하는 완성형 서비스는 아닙니다. 단일 프레임 누락, 화면 오독, 잘못된 훈수, 한국어 STT 오류, 모델 지연이 가능합니다. 페르소나/감정/관계 연출의 자연스러움은 실제 사용자 평가가 더 필요합니다. 실제 후원 결제, 관객 음성 TTS, 아바타, 공개 방송 송출, 외부 커뮤니티 자동 운영은 구현하지 않았습니다. 장기 로드맵은 [인계 문서](../HANDOFF.md)에 구분했습니다.

## 핫클립과 게시글 첨부

핫클립에는 영상·음성 파일이 저장된 항목을 표시합니다. 사진·대화만 남은 항목은 **방송 밖 이야기 → 방송 커뮤니티 → 장면 기록**에서 게시글 첨부와 당시 채팅으로 볼 수 있습니다. 기존 제목·작성 관객·댓글·답글·추천과 원본 파일은 같은 기록으로 유지합니다. 파일을 복제하거나 기존 기록을 삭제하는 변환은 하지 않습니다.

방송 설정의 클립 버퍼와 관객 장면 기록을 모두 켜면, 직접 연결한 화면·소리·마이크에서 약 15초 녹화 구간을 저장합니다. 녹화가 완성되어 연결된 기록은 핫클립에 표시됩니다. 분리 저장한 마이크 음성은 재생 중 켜고 끌 수 있습니다. 녹화 실패나 해당 순간의 버퍼가 없는 경우 오류를 알리며, 사진·대화 기록은 커뮤니티에 보존합니다. 과거에 녹화되지 않은 영상·음성을 사진이나 전사문으로 복원할 수는 없습니다.
