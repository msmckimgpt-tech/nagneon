# Nagneon 사용 안내

Nagneon은 게임과 Just Chatting을 AI 관객과 함께 즐기는 개인 방송실입니다. 관객은 함께 본 화면·들은 소리·나눈 대화를 기억하고, 채팅을 읽으며 서로 이야기합니다. 방송 밖에는 가상 갤러리와 관객이 고른 핫클립이 이어집니다. 관객 채팅은 텍스트로 표시하며, 후원 포인트에는 현금 가치·구매·환전 기능이 없습니다.

## 설치한 앱 열기

설치 후 등록된 **Nagneon 바로가기**나 **Start-Nagneon.cmd**를 실행하세요. 저장소의 같은 이름 실행기도 설치된 앱을 여는 용도입니다. 소스에서 개발 실행하려면 [README의 개발 절차](../README.md)를 따릅니다.

앱을 열거나 다시 실행해도 방송·화면·마이크는 자동 시작하지 않습니다. 새 프로필에는 처음 시작 안내와 200P가 제공됩니다. 기존 프로필의 관객·잔액·대화·설정은 유지하며 처음 시작 안내를 강제로 다시 띄우지 않습니다. 안내는 **방송 설정 → 방송 → 처음 시작 안내 다시 보기**에서 열 수 있습니다.

관객이 아직 없다면 **나의 관객 → 첫 관객 초대**로 첫 체험 포인트를 사용해 한 명을 만나보세요. 이름과 성향을 미리 고르지 않고, 생성이 끝나면 관객이 입장합니다. 실패한 만남의 포인트는 반환됩니다. 기본 방송 도우미는 관객 수에 포함하지 않습니다. [첫 방송 안내](ONBOARDING.md)

## 방송 설정 찾기

설정은 다음 탭으로 나뉩니다. 제목·모델 등 방송 준비 설정은 방송과 응답 생성이 끝난 뒤 저장하세요. 내 발언 표시처럼 방송 중 바꿀 수 있는 항목은 방송실에도 별도 조작부가 있습니다.

| 탭 | 주요 설정 |
|---|---|
| 방송 | 방송 제목·스트리머 이름·게임/Just Chatting·리허설/관객 연결·오버레이 사용 방식 |
| 분위기·훈수 | 방송 분위기·스트리머 성향·훈수 정책·게임 공략 검색 |
| 연결·사용량 | 계정 연결·모델과 추론 수준·음성 전달 방식·마이크 선택·추가 구성 다운로드 |
| 매니저·채팅 | 매니저 임명·운영 지침·금칙어·스포일러 필터·슬로우 모드·채팅 수·내 발언 표시 |
| 미디어·기록 | 로컬 음성 인식 장치·음성 교정·클립 버퍼·관객 장면 기록·커뮤니티 활동·포인트·저장 위치 |
| 게임 | 게임 프로필 추가·장르별 기본 설정·게임 정보 |
| 디버그 | 고급 프롬프트와 설정 JSON 편집. 일반 방송 준비에는 필요하지 않습니다. |

## ChatGPT 구독 연결

**방송 설정 → 연결·사용량**에서 연결 상태를 확인하고, 로그인이 필요하면 앱의 **ChatGPT 계정 연결**을 사용하세요. 배포본은 공식 Codex CLI를 포함하며, 인증과 자격 증명 갱신은 CLI가 처리합니다. 앱은 ChatGPT Desktop을 조작하거나 로그인 토큰·쿠키를 추출하지 않습니다. 공식 Codex는 ChatGPT 로그인과 API 키 로그인을 구분하며, ChatGPT 로그인은 해당 계정의 구독 사용량을 이용합니다. [OpenAI 공식 인증 안내](https://learn.chatgpt.com/docs/auth)

**AI 제공처·관객 모델 선택**에서 모델과 추론 수준을 저장합니다. 기존 선택은 자동으로 다른 모델로 바뀌지 않습니다. 모델별 제공 여부와 계정 한도는 계정에 따라 다르며, 로그인 확인만으로 모델 접근이나 남은 사용량을 보장하지 않습니다.

**모델 응답 확인 · 1회 사용**은 화면·음성·기존 대화 없이 짧은 인사 요청 하나를 보냅니다. 실제 모델 사용량을 소비하며 방송 채팅이나 포인트에는 들어오지 않습니다. 취소해도 이미 전송한 요청의 사용량은 되돌아오지 않을 수 있습니다.

일반 관객 응답은 공식 CLI의 비대화형 실행을 사용합니다. 구독 음성은 별도 음성 연결을 사용하며 아래 전송 범위를 먼저 확인하세요. [OpenAI 비대화형 실행 안내](https://learn.chatgpt.com/docs/non-interactive-mode), [구독 음성 안내](NATIVE-AUDIO.md)

다른 제공처나 역할별 모델을 직접 지정하려면 [사용자 지정 모델과 역할별 라우팅](PROVIDER-ROUTING.md)을 참고하세요. API 연결은 별도 요금이 발생할 수 있습니다. 연결 실패 때 지정하지 않은 유료 API나 로컬 모델로 자동 전환하지 않습니다.

## 게임 방송과 Just Chatting 시작

1. **방송 설정 → 방송**에서 **관객 연결 · ChatGPT**와 게임 방송 또는 Just Chatting을 선택하고 제목을 저장합니다. 리허설은 준비된 예시 채팅이며 실제 모델 반응과 구분합니다.
2. **연결·사용량**에서 음성 전달 방식과 마이크를 선택합니다. 구독 음성을 쓴다면 마이크와 Windows 출력 전체의 전송 안내를 확인하고 동의를 적용합니다.
3. 게임을 함께 보려면 방송실의 **게임 화면 연결**에서 게임 창을 선택합니다. 전체 화면을 선택하면 같은 모니터의 다른 내용도 전달될 수 있습니다. Just Chatting에서는 화면 없이 이야기할 수 있습니다.
4. **방송 시작**을 누릅니다. 게임·시스템 소리 연결이 준비되지 않았다면 연결 절차가 먼저 열립니다. 구독 음성은 방송 시작과 함께 마이크 연결을 준비하며, 로컬 음성 인식은 방송 중 마이크 연결 버튼으로 켭니다.
5. 말하거나 채팅 입력란의 **관객에게 말하기**로 인사합니다. 막히면 **훈수 요청**을 누르거나 “지금 훈수 부탁해”처럼 요청하세요. 분위기·훈수 탭에서 평소 훈수 정책을 정할 수 있습니다.
6. **오버레이 열기**로 게임 위에 채팅을 띄웁니다. 방송을 마칠 때는 **방송 종료**를 누릅니다.

방송 종료는 해당 방송의 입력과 응답을 멈춥니다. 앱이 켜져 있고 커뮤니티 활동이 허용되어 있으면 방송 밖 활동은 이어질 수 있습니다. 앱을 닫으면 앱의 작업을 정리하며, 다음 실행 때 방송을 자동 재개하지 않습니다.

## 화면과 소리는 어떻게 전달되나요?

선택한 화면은 모델 응답을 기다리는 동안에도 0.5초 간격으로 수집합니다. 요청에는 최근 16초에서 최대 8장을 시간순으로 골라 소리·발언과 함께 전달합니다. **AI 반응 최소 간격**은 자동 화면 반응을 요청하는 간격이며, 실제 응답이 끝나는 시간이나 영상 프레임 속도를 뜻하지 않습니다. 모델이 늦으면 장면 일부를 놓치거나 이미 지난 상황에 답할 수 있습니다. [연속 장면 인식](TEMPORAL-VIEWING.md)

게임·시스템 소리는 방송과 함께 공유하며 별도의 ON/OFF 전환은 없습니다. **Windows 출력 전체**이므로 선택한 게임 외에도 다른 앱의 알림·음악·통화가 포함됩니다. 선택하지 않은 다른 창의 화면까지 함께 보내는 기능은 아닙니다.

| 음성 전달 방식 | 처리와 준비 |
|---|---|
| ChatGPT 구독 음성 | 동의한 마이크 원음과 Windows 출력 소리를 구독 음성 연결로 전송합니다. 마이크 발언과 시스템 출력의 전사를 구분합니다. GPT 답변 소리는 재생하지 않습니다. 연결·한도 문제로 중지되면 로컬 인식이나 유료 API로 자동 전환하지 않습니다. |
| 기존 로컬 음성 인식 | 마이크는 로컬 한국어 인식기를 사용하고, 시스템 소리는 로컬 분석 결과와 전사를 관객 응답에 전달합니다. 필요한 Python·모델·GPU 구성은 **연결·사용량 → 추가 구성**에서 준비합니다. 최초 다운로드와 CPU/GPU 사용이 발생합니다. |

로컬 모드의 음성 인식 처리 장치는 **미디어·기록**에서 고릅니다. GPU를 사용할 수 없으면 CPU로 전환할 수 있으며, 게임과 인식기가 자원을 함께 쓰면 성능에 영향을 줄 수 있습니다. [추가 구성 안내](RUNTIME-COMPONENTS.md), [시스템 소리 안내](SYSTEM-SOUND.md)

목소리·억양·어투는 발언 문맥과 음성에서 얻은 단서를 통해 반응에 참고합니다. 확실한 감정 판정이나 심리 진단은 아닙니다. **게임과 대화 맥락으로 음성 오인식 교정**은 미디어·기록에서 켜고 끌 수 있습니다. 인식 원문을 먼저 전달하며, 채팅의 **음성 교정** 표시에서 원문을 확인할 수 있습니다.

음성이 끊기면 방송실의 마이크 상태와 **마이크 재연결**을 확인하세요. 로컬 인식기 준비에 실패했다면 연결·사용량의 **음성 인식 다시 준비**를 사용합니다. 다시 연결하지 않고 키보드로 관객에게 말하는 방법도 있습니다.

## 채팅, 매니저, 오버레이

**매니저·채팅**에서 이미 만난 관객을 매니저로 임명하고 운영 지침·금칙어·스포일러 필터·슬로우 모드를 설정합니다. 한 번에 표시할 채팅 수는 반응의 기준이며 관객 수를 제한하거나 매번 정해진 수만큼 말하게 하지는 않습니다. 관객은 채팅도 읽지만, 주된 관심은 방송입니다.

**내 발언 표시**는 방송실의 채팅창 위나 매니저·채팅 설정에서 바꿉니다. 끄면 내 발언을 채팅창과 오버레이에서 숨깁니다. 관객에게 말을 전달하고 기억하는 기능은 유지됩니다.

Windows의 **Ctrl+Shift+F10**은 오버레이 클릭 통과를 전환합니다. 방송실에도 전환 버튼이 있습니다. 단축키가 충돌하면 버튼을 사용하세요. 창 모드·테두리 없는 창을 권장하며 독점 전체화면 게임마다 호환성이 다를 수 있습니다.

개인용 오버레이는 캡처 제외를 요청합니다. 공개용은 캡처를 허용하고 **AI 관객·가상 포인트** 표시를 유지합니다. 실제 방송에 사용한다면 OBS 미리보기에서 확인하세요. 개인용으로 전환해도 OBS 창 캡처에 마지막 공개 화면이 남을 수 있으므로 즉시 가리려면 OBS에서 해당 소스를 숨깁니다. [오버레이 캡처 안내](OBS-OVERLAY-ACCEPTANCE.md)

외부 플랫폼의 실제 채팅 연결은 선택 기능입니다. 연결하면 새 채팅 본문이 선택한 AI 제공처에 전달되며, 기본적으로 작성자 이름은 연결별 별칭으로 바뀝니다. 실제 시청자에게 AI가 채팅을 읽는다는 사실을 안내하세요. AI 관객의 답변은 외부 채팅에 자동 게시되지 않습니다. [외부 방송 사용 안내](../README.md#실제-시청자가-있는-방송에서-사용하기)

## 관객과 게임 기억

관객은 방송 중 낮은 확률의 자연 유입, 핫클립·커뮤니티를 통한 만남, 포인트로 연 한 명과의 첫 만남에서 생성됩니다. 일반 방송 설정에서 아직 만나지 않은 사람의 이름·성격을 미리 정하거나 후보 목록을 직접 추가하지 않습니다. 관객은 쉬거나 시청을 마치고 다시 방문할 수 있으며, 돌아와도 같은 사람의 기억을 이어갑니다.

성향과 닉네임은 함께한 대화에 따라 달라질 수 있습니다. **나의 관객**에서 이전 이름과 메모를 확인하고, 관객마다 메모를 저장할 수 있습니다. 일반 관객 정보에는 공개된 이력이 보이며, 숨겨진 성격·가치관·유입 정보는 포인트로 수첩을 열어 알아갑니다. 여러 관객은 서로 다른 페르소나이며 관객마다 별도 모델 프로세스가 실행되지는 않습니다. [관객 유입과 변화](AUDIENCE-AUTONOMY.md)

게임 프로필은 설정의 **게임** 탭에서 추가하고 다듬습니다. **게임 라이브러리**에는 관찰·시청 시간·사용자 메모가 쌓입니다. 관객의 게임 지식에는 각자가 목격한 시각과 함께한 시간의 차이를 반영합니다. 여기서 학습은 저장한 기억을 이후 요청에 참고하는 방식이며 모델 가중치 학습은 아닙니다. [관객별 목격 지식](VIEWER-KNOWLEDGE.md)

게임 인지도·틀린 훈수·관심 끌기 설정은 연출 방향이며 실제 판매량이나 잘못된 훈수의 정확한 발생 확률을 뜻하지 않습니다. 인터넷 공략 검색은 허용 설정과 훈수 요청에 따라 사용합니다. 화면 오독이나 잘못된 답이 생길 수 있으므로 게임의 중요한 선택은 직접 확인하세요.

기념일·복귀·도전·취향 논쟁·관계 이야기는 평소 방송과 대화에서 이어갑니다. 별도 기획 방송·시즌·상황 연습을 시작하는 흐름은 종료되었습니다. 예전 기획 기록은 보존되며 [종료된 방송 놀이터 기록](EXPERIENCES.md)에서 과거 구현과 현재 흐름을 구분할 수 있습니다.

## 마음과 포인트

관객은 마음에 든 순간에 가상 포인트로 응원할 수 있습니다. 관객 지갑에는 상한이 있고 현실 시간에 따라 재충전하므로 무제한으로 후원하지 않습니다. 포인트 후원은 일반 채팅보다 관심을 끄는 사건으로 전달되며, 관객마다 반응 여부가 다릅니다.

익명 후원은 공개 채팅에서 후원자를 숨깁니다. 스트리머는 별도 **받은 후원** 창에서 후원자를 확인할 수 있고 이 조회에는 포인트를 쓰지 않습니다. 공개 익명 표시와 스트리머 전용 조회는 구분됩니다. [채팅의 관심과 익명 후원](CHAT-ATTENTION-DONATIONS.md)

모은 포인트는 **마음과 포인트**에서 사용합니다.

- **상세 수첩·관계 지도**를 열어 취향·유입 경로·관객 사이의 관계를 탐색합니다. 한 번 연 수첩과 지도는 다시 볼 수 있습니다.
- 관객 채팅의 **속마음**이나 **취향 인터뷰**로 캐릭터의 마음을 알아갑니다. 이는 창작 대화이며 모델의 숨은 추론이나 실제 사람의 심리를 보여주는 기능은 아닙니다.
- **응원 합창·토론·역할극·자유로운 채팅 부탁**은 관객과 포인트를 협상합니다. 관객은 거절하거나 역제안할 수 있습니다.

실패하거나 취소된 만남·인터뷰 등은 해당 처리 결과와 포인트 기록을 확인하세요. 새 프로필의 200P는 첫 체험 지급이며 기존 프로필의 잔액을 같은 값으로 재설정하지 않습니다.

## 방송 밖 이야기와 핫클립

**방송 밖 이야기**는 게시글·댓글·대댓글·추천이 있는 로컬 가상 갤러리입니다. **방송 커뮤니티**에는 함께한 방송의 이야기가, **바깥 커뮤니티**에는 서로 다른 성향의 가상 공동체가 이어집니다. 실제 사이트의 사람을 데려오거나 그 사람의 계정으로 글을 게시하는 기능은 아닙니다. [바깥 커뮤니티 안내](EXTERNAL-COMMUNITIES.md), [관객 문화 조사](AUDIENCE-RESEARCH.md)

핫클립을 고르는 주체는 관객입니다. **미디어·기록**에서 **방송 중 영상·음성 클립 버퍼 사용**과 **관객의 장면 기록 허용**을 켜면 공유한 화면과 연결된 소리·마이크의 짧은 구간을 보관하다 관객이 고른 순간에 저장합니다. 화면 없이 소리만 연결해도 음성 클립을 남길 수 있습니다.

**핫클립**에는 영상·음성 파일이 연결된 기록을 표시합니다. 날짜·게임·관객으로 찾아 감상하고, 분리 저장된 스트리머 마이크 음성은 재생 중 켜고 끌 수 있습니다. 사진·대화만 남은 기록은 **방송 밖 이야기 → 방송 커뮤니티 → 장면 기록**에서 당시 채팅과 첨부를 볼 수 있습니다. 기존 댓글·답글·추천도 같은 기록에 유지됩니다.

클립 버퍼는 약 15초 구간을 저장합니다. 녹화 실패나 당시 버퍼가 없으면 사진·대화 기록으로 보존하며, 녹화되지 않은 과거 영상을 사진이나 전사문으로 복원하지는 않습니다. 버퍼를 끄거나 연결을 끊으면 해당 임시 구간을 비웁니다. 저장된 기록은 각 화면에서 삭제할 수 있습니다.

다른 관객은 앱이 켜져 있고 활동이 허용되어 있을 때 스스로 클립과 갤러리를 감상하고 댓글·추천·방송 후기를 결정합니다. 방송 응답을 우선하고 아무 말도 남기지 않을 수 있습니다. 사용자가 감상자를 지정하거나 후기를 생성하는 모델 호출 버튼을 누르는 흐름은 없습니다. **관객의 커뮤니티 활동 허용**과 AI 대시보드에서 자동 활동을 관리할 수 있습니다. [자발적인 커뮤니티 활동](AUTONOMOUS-COMMUNITY.md)

## 응답이 늦거나 채팅이 조용할 때

모델이 답하는 시간, 관객이 말할지 결정하는 것, 생성된 채팅을 순서대로 표시하는 것은 서로 다릅니다. 화면 변화가 적어도 잡담이 생길 수 있지만 일정한 주기로 반드시 채팅이 올라오지는 않습니다. **AI 대시보드**에서 요청·응답·표시 상태와 사용량을 확인하세요.

**AI 반응 최소 간격**을 늘리면 자동 화면 요청이 줄어듭니다. 새 발언은 별도로 우선 처리하며, 동시에 여러 관객 요청을 무제한 실행하지 않습니다. 연결 오류가 반복되면 재시도 간격을 늘리고, 계정 한도나 권한 문제는 화면의 안내에 따라 해결합니다. 앱의 시도 횟수·관측한 토큰은 계정의 정확한 잔여 구독량과 다릅니다.

일부 모델 요청이 실패해도 키보드 입력이나 저장된 기록을 사용할 수 있습니다. 문제를 조사할 때는 앱의 진단 내보내기와 표시된 오류를 확인하세요. 실제 화면·마이크 정확도와 장기적인 대화 품질은 기기·게임·모델에 따라 차이가 있습니다.

## 저장 위치와 개인정보

**방송 설정 → 미디어·기록 → 저장 위치**에서 현재 프로필을 확인합니다. 시스템 기본 위치는 `%APPDATA%\backseat-studio`이며, 사용자 선택 위치가 있으면 그 위치를 사용합니다. 아래 경로는 해당 프로필의 `data` 폴더 기준입니다.

| 파일·폴더 | 내용 |
|---|---|
| `world.json` | 현재 방송 설정·관객·관계·유입·포인트·해금 상태 |
| `knowledge.json` | 게임별 관찰·사용자 메모·시청 시간 |
| `conversation-journal-index.json`, `conversation-journal-chunks/` | 공개 대화 기억과 원문. 최근 4,000개를 보관하며 최대 100개를 고정할 수 있습니다. |
| `clips.json`, `clip-media/` | 관객의 장면 기록·댓글·추천과 저장된 영상·음성 |
| `social-media/` 등 | 커뮤니티 첨부 파일과 기능별 저장 자료 |

과거 `settings.json`·`audience.json`·`economy.json`은 이전 형식에서 가져온 원본으로 남을 수 있습니다. 현재 설정·관객·포인트를 바꾸려고 이 파일들을 직접 편집하지 마세요.

저장 위치 변경은 빈 폴더로 기록을 복사하고 해시를 확인한 뒤 앱을 재시작합니다. 원래 기록은 남깁니다. 업데이트나 구버전 복귀 전에는 앱을 정상 종료하고 백업·저장 형식 호환성을 확인하세요. 구버전 복귀가 필요하면 업데이트 전 백업을 **별도 프로필**에 복사해 연결하며 현재 기록을 덮어쓰지 않습니다. [설치·데이터 보존 안내](STABLE-INSTALLATION.md)

로컬 음성 구성은 앱의 추가 구성 저장 위치에서 관리하며 `%LOCALAPPDATA%\Nagneon\runtime` 또는 검증용 프로필의 `runtime`을 사용합니다. 설치와 기록 이동은 별도 기능입니다.

선택한 화면 이미지·발언·전사·관련 대화와 기억은 선택한 AI 제공처에 전달됩니다. 구독 음성에서는 마이크 원음과 Windows 출력 소리도 전송됩니다. 클립 버퍼와 음성 보관 설정에 따라 원음이 이 PC에 저장될 수 있습니다. 완전한 오프라인 앱이 아니며, 보관 범위는 **연결·사용량**과 **미디어·기록**에서 확인하세요.

서버는 `127.0.0.1`에서 실행하며 실행별 인증을 사용합니다. 연결 주소나 인증 정보를 외부에 공유하지 마세요. 앱의 로컬 저장·인증 경계는 같은 Windows 계정 권한으로 파일을 읽는 다른 프로그램까지 격리하는 기능은 아닙니다.

## 지원 범위

화면 오독·한국어 음성 오인식·잘못된 훈수·응답 지연이 생길 수 있습니다. 모든 게임·장치의 호환성이나 대화의 자연스러움이 검증된 상태는 아닙니다. 설치본 생성, 합성 입력 검사, 실제 기기 검증, Steam 판매 준비는 별도로 확인합니다. 현재 검증의 범위와 남은 작업은 [판매 준비 기준](RELEASE-GATES.md), [검증 기록](VALIDATION.md)을 참고하세요.
