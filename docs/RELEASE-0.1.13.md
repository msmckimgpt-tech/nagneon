# Nagneon 0.1.13

방송실에서 현재 방송의 오래된 대화를 다시 읽을 수 있다. 채팅 위쪽의 **이전 채팅 더보기**로 보관 중인 기록을 100개씩 불러오며, 읽던 줄의 위치를 유지한다. **새 채팅 보기 ↓**를 누르면 최신 대화로 돌아간다. 지난 방송의 기록은 섞지 않고 삭제·비우기와 새 방송 전환을 반영한다. 기존 대화 보관 범위를 유지하므로 이미 보관 범위를 벗어난 메시지를 복구하지는 않는다. [채팅 기록 동작](CHAT-HISTORY.md)

공개 커뮤니티 참고 자료에서는 게시글과 댓글 본문을 더 정확하게 선택한다. 공개 조회 링크를 제한적으로 지원하고 메뉴·빈 피드·고정 공지·계정 표시·중복 댓글을 제외한다. 사이트의 수집 제한, 요청 간격, 기존 AI 연결과 모델 입력 한도는 유지한다. [문화 참고 동작](CULTURE-LEARNING.md)

응답 진단에서 **방송 흐름 진단 다운로드**를 제공한다. 입력·반응·채팅 표시·목격 범위와 앱 종료 단계를 최근 7일, 최대 16MiB의 로컬 기록으로 연결한다. 대화 원문·음성·화면·관객 이름은 복제하지 않는다. 한 종료 작업이 실패해도 나머지 정리를 이어가며, 진단 저장 실패는 방송을 막지 않는다. [방송 흐름 진단](BROADCAST-TRACE.md)

기존 대화 저장 형식, AI 제공처·모델 선택, 마이크·게임 소리 연결 방식은 바뀌지 않는다. 별도 진단 파일이 추가된다. 업데이트는 기존 기록과 설정을 보존하는 [고정 설치 절차](STABLE-INSTALLATION.md)를 따른다. 이전 실행 파일과 업데이트 전 데이터 백업은 보존하며, 복귀 시 현재 기록을 과거 백업으로 덮어쓰지 않는다.
