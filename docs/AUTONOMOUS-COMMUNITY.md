# 관객의 자발적인 커뮤니티 방문

2026-09-14. 사용자는 앱이 켜져 있을 때만 자동 감상·댓글을 진행하고 방송 응답을 우선하도록 선택했다. 아래는 해당 동작의 코드·파일·독립 HTTP 및 실제 모델 검증이다. 사용자 앱이나 실제 게임·마이크를 조작한 결과가 아니다.

## 적용한 동작

앱 서버의 기존 타이머가 이미 방송에서 만난 관객 중 한 명의 방문을 결정한다. 스트리머가 관객을 선택하거나 모델 호출 버튼을 누르지 않는다. 클립과 갤러리 게시글을 읽고 댓글·대댓글·추천을 각각 선택하며, 아무 반응 없이 읽고 가는 것도 정상 결과다. 자주 소통하는 성향, 스트리머와의 친숙도, 해당 클립 방송 참여와 게시물의 시점이 방문 확률에 영향을 준다. 긍정 반응은 강제하지 않는다.

최근 7일·25개 방송의 후기는 관객 본인이 실제로 목격한 공개 대화만 대상으로 한다. 직접 보지 않은 발언, 가상 기획, 명백한 음성 반복 이상은 입력에서 제외한다. 후기와 방문 완료 기록은 한 번에 저장한다. 글을 쓰지 않은 선택도 완료로 기록한다.

시작 후 최소 1분 대기하며 방문 사이에는 4~8분 간격, 동일 관객·게시물에는 최소 30분 간격을 둔다. 시간당 최대 6회이며 세션 호출 한도도 함께 적용한다. 호출 시도와 재시도 간격을 먼저 저장하므로 앱 재시작이나 실패가 호출 한도를 초기화하지 않는다. 같은 버전의 실패는 최대 3회 시도한다. 이미 읽은 버전이나 본인이 방금 쓴 댓글만으로 다시 방문하지 않는다. 최대 1,000개 후기 완료 기록과 최근 300개 호출 시도를 보관하며 관객별 열람 기록은 각 게시물에 남는다.

실시간 입력·응답·입장 처리·음성 처리·채팅 대기열·상황 연습이 우선한다. 방송 입력이 계속되면 커뮤니티 방문은 대기한다. 입력이 30초 이상 멈춘 틈이나 방송 종료 후에 방문할 수 있다. 방송 시작, 새 마이크 발언, 화면 응답 요청, 사용자 변경 요청은 자동 방문을 취소한다. 모델 프로세스의 취소가 끝난 뒤 다음 모델 요청을 시작하고, 늦게 도착한 댓글·추천·열람 기록은 저장하지 않는다. 앱 종료는 이 작업까지 종료한 뒤 완료한다. Windows 예약 작업이나 외부 상시 실행은 만들지 않는다.

설정의 미디어 탭에 있는 ‘관객의 커뮤니티 활동 허용’은 리소스 사용을 중단하는 설정이다. 개별 감상자나 생성 결과를 지정하는 기능은 아니다. 핫클립·갤러리의 수동 생성 버튼과 관객 선택을 제거했으며, 오래된 클라이언트가 사용하는 세 가지 POST 경로도 410으로 종료한다.

## 사용자 호출 경로 점검

| 경로 | 처리 |
|---|---|
| 클립 감상·갤러리 읽기·방송 후기 생성 | 앱 내부 관객 방문으로 전환, 수동 API 종료 |
| 직접 클립 제작·기획 방송 시작·시즌 생성/진행 | 기존에 차단된 API와 읽기 전용 보관 화면 유지 |
| 스트리머 본인의 글·댓글·추천·삭제 | 본인 발언과 관리 동작으로 유지, 모델 호출 없음 |
| 포인트를 통한 관객 유입·인터뷰·속마음·협상 | 사용자가 앞서 명시적으로 요청한 포인트 선택으로 유지 |
| AI 연결 응답 검사 | 설정 진단으로 유지 |
| 라이브 발언·화면·소리 입력 | 방송의 실제 입력으로 유지 |
| 별도 상황 연습 | 모델을 호출하지 않는 기존 연습 기능 유지 |

열람자 목록과 내부 방문 시각·해시는 공개 상태·클립·갤러리 조회에서 숨긴다. 일반 댓글 작성자와 추천은 공개 활동이다. 댓글·추천·읽은 원문 버전은 함께 저장하므로 저장 실패나 원문 삭제 시 부분적인 댓글과 기억이 남지 않는다. 모델이 자동 방문 응답에 후원·유입·새 클립·닉네임 변경을 제안해도 해당 부수 효과는 적용하지 않는다.

## 검증과 현재 한계

- `artifacts/autonomous-final-check.log`: 추가 취소 순서·부수 효과·UI 경로 검사를 포함한 최종 534개 Node 테스트와 TypeScript/Vite 빌드 통과. 건너뜀·실패 0개다.
- `scripts/verify-autonomous-community.mjs`: 별도 프로필과 실제 앱 타이머로 공식 구독 계정의 gpt-6-astra / low를 호출한다. 수동 생성 API를 우회 호출하거나 장치를 캡처하지 않는다.
- `artifacts/autonomous-astra-kAMrtM/result.json`: 클립 방문 9,628ms에 답글과 추천, 갤러리 방문 9,648ms에 댓글과 추천, 후기 방문 8,643ms에 무작성 선택. 세 경우 모두 열람/후기 완료 저장을 확인했다. 입력·출력은 합성 사례이며 실제 사용자 대화를 복제하지 않았다.
- 취소·원문 삭제·저장 실패·재시작·시간 역행·호출 한도·미목격 대화 배제·공개 정보 제한·수동 API 종료를 코드/독립 HTTP 검사로 확인한다. 초기 무조건 비동기 대기 때문에 생겼던 라이브 순서 회귀는 활성 방문이 있을 때만 기다리도록 고쳤다.

현재 클립 감상의 근거는 저장된 캡션·장면 설명·채팅이다. 영상·출력 소리·분리 마이크 파일을 관객이 직접 분석하는 연결은 **아직 미구현**이며 다음 작업으로 유지한다. 사용자에게 제공하는 영상 재생과 마이크 ON/OFF가 곧 모델의 영상·음성 감상을 의미하지 않는다. 갤러리에서 읽은 원문의 라이브 회상, 커뮤니티 대화에 따른 관계 변화도 추가 검증이 필요하다.

이 단계만으로 장시간 자연스러움이나 실제 장치 체험, 판매 준비를 합격 처리하지 않는다. 기존 배포 패키지는 이 변경 이전 파일을 포함하므로 새로운 릴리스 후보 패키지·설치 검증이 필요하다. 사용자 앱을 자동 재시작하지 않으며, 소스 실행기는 사용자의 다음 실행 시 main을 다시 빌드한다. 상위 목표의 남은 설치 복구·상용 배포 조건과 Steam 검토는 [판매 준비 기준](RELEASE-GATES.md)을 따른다.
