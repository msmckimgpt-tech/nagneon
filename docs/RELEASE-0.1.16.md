# Nagneon 0.1.16

오래된 대화를 회상할 때 질문과 관련된 정정·취소 원문을 먼저 찾는다. 예를 들어 암호를 바꿨다고 말한 뒤 다른 주제의 약속을 여러 번 취소해도 암호 정정이 최신 취소 발언들에 밀려나지 않도록 했다.

관객이 실제로 들은 발언만 제공하며 최근 채팅과의 중복 제외, 원문 삭제, 최대 기억 개수와 길이 제한을 유지한다. 원래 발언을 덮어쓰거나 관객이 듣지 못한 정정을 새로 알게 만들지는 않는다. 어휘를 바탕으로 찾으므로 모든 의미·동의어·암시를 이해하는 검색은 아니다. [대화 기억과 검색](CONVERSATION-MEMORY.md)

기존의 짧은 라이브 채팅 반응, 현재 방송 채팅 더보기, 후원 중복 방지와 정상 정책을 사용하는 고정 실행 경로를 포함한다. 모델 선택·저장 형식·음성 연결 방식은 유지한다. 업데이트와 복귀는 [고정 설치 절차](STABLE-INSTALLATION.md)를 따르며 현재 기록을 과거 백업으로 덮어쓰지 않는다.
