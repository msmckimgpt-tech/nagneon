# 포인트 상태 조회의 복사 비용

`Economy.snapshot()`은 저장된 지갑을 바꾸지 않고 현재 시각의 충전 상태를 계산한다. 공개 결과의 중첩 배열·객체도 원본과 분리하여, 상태 소비자가 반환값을 바꾸더라도 저장 기록을 수정하지 못하게 한다.

이 과정에서 화면에 전달하지 않는 보상 중복 방지 기록(`moments`)과 구매 내부 식별자·배분 정보를 먼저 복사하던 비용을 줄였다. 계산에 필요한 지갑만 분리한 뒤, 익명 후원·협상·구매의 공개 필드를 선택하고 그 결과를 복사한다. 읽기 시 캐시를 도입하지 않아 환불·충전·협상 만료를 다음 조회에 반영한다.

잔액·보상·가격 정책, 저장 형식, 구매 처리의 원자적 저장을 위한 `change()` 복사는 변경하지 않는다. `rules`는 기존과 동일한 공통 규칙 참조다.
