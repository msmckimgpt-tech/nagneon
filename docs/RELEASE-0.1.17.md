# Nagneon 0.1.17

한국 게임 방송 채팅의 축약·붙여쓰기·느슨한 표기와 게임 속 허세·실수를 가볍게 놀리는 반응을 자연스러운 선택으로 허용한다. 이런 일상적인 말결을 특별한 유행 밈으로 취급하거나 공손한 해설·위로로 다듬지 않도록 했다. 게시판 글과 댓글에도 같은 기준을 적용한다.

말투·욕설·오타·조롱의 비율을 관객마다 배정하지 않으며 차분한 사람의 기존 화법도 유지한다. 질문의 답과 이름·수치는 정확하게 전달하고 실제 중단 요청·개인 경계·금칙어·목격 범위를 지킨다. 출력 뒤 문장을 바꾸거나 저장된 원문을 교정하지 않는다.

GPT-6.1 Sol을 관객 모델 선택에 추가하고 동봉 공식 Codex CLI를 0.159.2로 갱신했다. 지원 추론 수준은 low/medium/high/xhigh/max이며 none은 지원하지 않는다. 기존 선택값과 기본 모델은 자동 변경하지 않는다. 구독 모델의 이용 가능 여부는 계정과 클라이언트에 따라 다르며 다른 모델이나 유료 API로 자동 전환하지 않는다. [관객 모델 선택](AUDIENCE-MODELS.md)

저장 형식·채팅 더보기·대화 기억 검색·음성 연결 방식은 유지한다. 업데이트와 복귀는 [고정 설치 절차](STABLE-INSTALLATION.md)를 따르며 현재 기록을 과거 백업으로 덮어쓰지 않는다.
