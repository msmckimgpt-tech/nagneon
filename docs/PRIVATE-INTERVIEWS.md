# 취향 인터뷰 기록 조회

관객 수첩의 취향 목록과 다음 취향 인터뷰는 완료된 구매 기록에서 해당 관객의 읽을 수 있는 답변을 가져온다. 관객의 고유 ID와 구매 키, 결과의 관객 ID를 함께 확인하며, 답변에 적힌 다른 관객의 ID나 닉네임을 현재 관객의 취향으로 연결하지 않는다. 닉네임이 바뀌어도 고유 ID가 같은 관객의 인터뷰는 이어진다.

이전 저장 파일의 구매 결과는 일부 필드가 없거나 다른 형태로 남아 있을 수 있다. 답변 목록이 없거나 읽을 수 없는 항목은 취향 목록에서 제외한다. 읽을 수 있는 본인 답변은 같은 기록에서 계속 사용하고, 사용할 수 있는 최신 네 인터뷰를 가져온다. 질문과 답변은 현재 인터뷰의 길이 범위 안에서 읽으며 인터뷰당 답변은 최대 여덟 개다. 결과에 날짜가 없는 이전 기록은 구매 시각을 사용한다.

이 조회는 원본 구매 기록을 삭제·교정하거나 잔액과 원장을 변경하지 않는다. 이미 해금한 수첩의 재조회는 AI를 호출하지 않는다. 새로운 취향 인터뷰는 기존 가격으로 한 번 실행하며 본인 인터뷰 기록만 전달한다. 비공개 답변은 일반 방송 채팅에 추가하지 않는다. 해금·방송 설정·포인트 기능의 이용 조건은 기존 규칙을 따른다.

검증 명령은 `node --test test/private-interviews.test.js test/economy.test.js`다. 합성 프로필을 저장하고 서버를 재시작한 뒤 인증된 로컬 API로 수첩을 재조회하고 후속 인터뷰를 실행한다. 불완전한 원본 기록 보존, 조회 시 포인트·파일·AI 호출의 변화 없음, 본인 답변만 전달, 비공개 채팅 유지, 후속 구매의 저장과 재시작을 확인한다. 실제 계정이나 화면·마이크 장치는 이 검사에 사용하지 않는다.
