# 관객의 시청 흐름과 반응 시점

2026-09-13. `codex/viewing-continuity`, 기준 `7bc366bfea9314887038216d83c703aba9a25bc7`. [1차 어투 개선](FIRST-TEST-CHAT-CULTURE.md), [후속 기록 진단](SECOND-TEST-DIAGNOSTICS.md)에 이어 진행했다. 화면·입력 조작, 게임 실행, 실제 장치 캡처, 사용자 앱 재시작은 하지 않았다.

## 문제와 변경

후속 기록에는 마지막 스트리머 발언보다 상당히 늦게 나온 완료 축하가 있었다. 당시 실제 화면과 소리를 조사하지 않았으므로 같은 사건의 재방송인지는 미확인이다. 코드에서는 같은 입력을 계속 분석하고, 최근35개 메시지 밖으로 밀려난 짧은 반응을 이후 판단에서 놓칠 수 있음을 확인했다.

- 일반 라이브 요청에서 같은 이미지 바이트·시청자/입장 시각·게임 분류가 이어지고 새 발언, 들은 소리, 관객 간 호명, 진행 중 대화/기획이 없으면 `unchanged-input`으로 쉰다. 세션 안의 해시와 한정된 이벤트 ID만 유지하며 이미지 복사본이나 추가 대화 저장소를 만들지 않는다. 변경된 픽셀은 새 사건의 증거로 취급하지 않는다.
- 관객별 `watchTiming`은 서버가 받은 표본 시각, 같은 이미지가 이어진 시간, 이전 분석 이후 경과 초를 전달한다. 신규·재입장 관객에게 이전 시청 시간을 넘기지 않는다. 원래 게임 시청 시간은 정지 화면을 실제 계속 받은 동안 유지하며, 화면이 끊기거나 기억을 삭제하면 해당 기록을 되살리지 않는다. 저장 실패에는 기존 오류 표시·재시도 대기를 적용한다.
- 현재 남아 있는500개 대화 중 각 관객이 입장 후 목격한 자기 반응3개와 다른 관객 반응3개를 최대120자와 경과 초로 전달한다. 최근35줄 밖 축하도 과거 반응임을 알 수 있다. 질문·가상 기획·삭제된 원문을 이 기록으로 복제하지 않는다.
- 화면에만 근거한 일반 채팅은 서버 입력 수신 후45초가 지나면 출력하지 않는다. 모델 응답 지연과 슬로 모드 대기열 모두에서 적용한다. 음성/직접 발언의 답변, 합의한 특수 행동 및 기획 응답에는 이 만료 규칙을 적용하지 않는다. 오래된 결과의 관찰 기록·핫클립 자체를 전부 폐기하는 정책은 아니다.
- 새 발언과 소리, 새 입장, 요청한 대화, 기획은 계속 판단한다. 정지 화면에서도 관객이 다른 관객을 새로 호명하면 응답할 기회를 준다. 기존 질문의 유효 시간이 끝난 것만으로 재호출하지 않는다. 실패·음성에 의해 취소된 분석은 처리 완료로 기억하지 않는다.

어투 지침은 이전 결과창 때문에 다시 축하하거나 인사를 반복하지 않고, 새 판의 성공과 과거에 대한 현재 질문은 구분하도록 했다. 기존의 짧은 구어체·침묵·요청 시 도움·개인별 말버릇 원칙을 유지한다.
