## 2026-09-28 관객 행동과 응답 수용 개선

관객은 자기 취향과 관심으로 참여하며, 항상 동의·평가·설명으로 마무리하지 않는다. 짧은 웃음, 취향 차이, 조용히 보기와 댓글 없이 지나가기도 허용한다. 기존 말높임·관계·목격 범위는 유지하고 욕설·반대·유행어의 비율을 강제하지 않는다. 명확한 중단 요청은 계속 우선한다. 이 지침은 한 번의 기존 요청에 포함하며 관객별 모델 호출이나 추가 제공처를 만들지 않는다.

### 구현 동작

- `broadcast-chat.js`와 `community-writing.js`: 대화에서 하고 싶은 행동을 먼저 고르고 그 사람의 말로 표현한다. 짧은 실제 발화 형태를 예시로 제공하되 고정 대사를 할당하지 않는다. 일반 라이브 행동 지침을 공통 설명 뒤에 배치했다.
- `live-response-policy.js`와 `Studio.accept/pump`: 장면 반응의 기존 유효시간을 음성과 화면이 함께 입력된 요청에도 적용한다. 실제로 목격한 질문·요청에 연결된 답변은 보존하지만, 농담에 답글 표시만 붙였다고 시간 제한을 피할 수 없다. 일반 후속 발언은 대기 중 답변을 지우지 않으며 취소·상황 정정·질문 삭제·퇴장·방송 종료는 해당 대기를 해제한다. 실제 전달 직전에도 중복을 확인한다.
- 매니저의 일반 라이브 발언은 직접 호명된 질문에 대한 답변이나 실제 관객 채팅에 연결된 운영 안내로 제한한다. 관객 없는 방을 감상문으로 채우는 발언은 `manager-role` 사유로 기록한다. 특수 기능의 합의된 대화 형식은 유지한다.
- 후원이 실제 승인·공개된 뒤 같은 관객의 같은 요청 채팅을 검사한다. 별도 내용인 `donationFollowup=true`를 제외한 반복은 제거하며, 추가 내용으로 표시했어도 기존 문자열 중복 검사를 적용한다. 실패한 후원·무언 후원은 일반 채팅을 소모하지 않는다. 익명 후원자의 내부 영수증 연결은 공개 메시지나 모델 입력에 노출하지 않는다. 늦은 장면 반응에 새 포인트를 지급하지 않는다.
- 체류의 과부하 신호는 장면의 `excitement` 대신 실제 전달된 최근 채팅량에서 계산한다. 긍정적인 공동 경험은 별도의 참여 신호로 다루고, 목적 충족으로 나갔던 관객도 기존 대기 후 재방문할 수 있다. 개인 일정에 따른 종료는 유지한다. 이 상수들은 제품 시뮬레이션 값이며 실제 사람의 체류율 측정값이 아니다.

- 문화 자료 수집은 메뉴 링크 위주의 화면과 짧은 접근 차단 안내를 분석 소재에서 제외하고 허용된 문서 링크를 계속 확인한다. 상태에 실제 패턴 수와 미수집·패턴 없음·오류·만료를 구분한다. 빈 분석 결과나 실패한 자료를 사용 가능한 학습 결과로 모델에 전달하지 않는다. 기존 도메인·robots·요청 예산·인용 제한은 유지한다.
