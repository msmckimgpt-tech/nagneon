# 사용자 방송 테스트의 대화 품질 개선

2026-09-13. 사용자는 반복 채팅, 늦은 음성 전달, 과도한 화면 분석 말투, 내 발언 표시 전환, 맥락 기반 음성 오인식 교정을 요청했다. 화면·장치 조작과 사용자 앱 재시작을 중단한 상태에서 별도 worktree에서 구현했다. 직접 테스트 데이터는 `USER-TEST-COLLECTION.md`의 읽기 전용 범위로 수집한다.

## 변경

- `SpeechOutbox` → `/api/speech` → `SpeechInbox`로 발언 전달과 AI 대기를 분리했다. 인식/입력된 말은 즉시 채팅과 기억에 들어간다. 세션 ID/UUID 영수증으로 불확실한 HTTP 재전송을 구분하고 응답 중 도착한 다음 발언은 보존한다. 이전에는 renderer가 busy 또는 자기 AI 요청 완료까지 발언 자체도 보류했다.
- 새 발언은 공개 전인 일반 반응과 화면만 분석하던 요청을 취소한다. 세션 전체/포인트로 합의한 행동은 그대로 둔다. 이미 발언에 답하는 요청을 계속 처리하여 계속 말하면 답변이 영원히 취소되는 일을 피한다. 취소된 모델 시도의 호출 수를 환불하지 않는다.
- 무음 종료 판정을650→450ms, 연속 구간 상한을12→6초로 낮췄다. 짧은 호흡은 연결하고 소음 한 번은 전달하지 않는다. 이 정책 변경을 모든 장치의 속도/정확도 검증으로 해석하지 않는다.
- 일반 채팅 최근45초의 문장부호·웃음·높은 문자3-gram 유사도를 비교해 긴 설명의 반복을 억제한다. 숫자/부정이 다르면 같은 사건으로 제거하지 않는다. 서로 다른 관객의 짧은 웃음/축하는 허용하고 같은 관객의 짧은 도배만8초 동안 제한한다. 임의의 의미 중복을 완벽히 검출하는 모델은 아니다.
- 모델이 `scene`의 화면 분석을 공개 채팅에 다시 나열하지 않도록 지침을 수정했다. 평범한 순간은0~2건 또는 침묵을 허용한다. 이미 한 설명·사과·질문을 표현만 바꿔 반복하지 않고, 부담스럽다는 피드백 이후 실제 말을 줄이도록 한다.
- 채팅창/오버레이의 `내 발언 표시`와 설정의 매니저·채팅 탭에서 표시를 전환한다. `/api/chat/display`는 방송/AI 응답 중에도 설정 하나만 저장한다. 표시만 필터링하며 관객에게 전달하는 말과 원문/기억은 지우지 않는다. 기존 프로필 기본값은 표시함이다.
- 마이크 원문만 맥락 교정 후보로 보내고 같은 관객 AI 호출에서 교정을 함께 받는다. 교정 전용 추가 호출이나 원문 전송 전 모델 대기는 없다. 키보드, 후보에 없는ID, 낮은 확실성, 숫자·부정·질문·훈수 요청 변화, 지나친 문장 재작성은 거절한다. 잘못된 교정에 의존한 반응도 보류하고 재발화를 안내한다. 설정의 미디어 탭에서 끌 수 있다.
- 원래 `text`, ID/시각/목격자를 바꾸지 않고 `transcription.correction` 주석으로 교정문·근거·확실성·시각을 보관한다. 채팅/오버레이/기억/핫클립은 교정문과 원문 펼치기를 제공한다. 검색에는 두 표현을 사용하고 모델 기억에는 원문과 자동 교정을 구분한다. 확실성0.9/0.99는 모델 출력과 적용 기준이지 측정된 정확도90%/99%가 아니다.

## 적용과 남은 일

사용 중인 앱에 코드를 주입하거나 재시작하지 않았다. main 통합 후 사용자가 테스트를 마치고 **기존 `Start-Backseat.cmd`로 다시 켜면 새 코드를 빌드하여 같은 data를 이어 쓴다.** 패키지 기본 프로필은 개발 폴더 data와 다르므로 새 EXE 실행만으로 기존 개발 데이터가 이관됐다고 안내하지 않는다.

최종 제품 커밋 `bf48e86`을 깨끗한 별도 통합 트리에서 **264개 검사와 TypeScript/Vite 빌드**로 검증하고 main에 fast-forward했다. `conversation-integration-result.json`에 27개 변경 파일의 바이트 일치와 원격 확인을 기록했다. 원격 push와 사용자 앱 재시작은 하지 않았다.

최종 전체 패키지는 `release/2026-09-13T04-41-33-852Z/app/BACKSEAT-win32-x64`다. **1,599,452,807바이트 / 2444파일 / 미서명**. `conversation-packaged-runtime.json`은 전달 ASAR를 추출해 실제 포함 모듈·제한된 PATH·번들 Python/Whisper/YAMNet·공식 CLI의 기존 로그인 인식을 확인했다. 저장된 합성 음성만 사용했고 이 패키지 검사에서는 모델 추가 호출이나 native 창 실행을 하지 않았다. `conversation-package-integrity.log`는 전체 파일 해시·fuses·핵심 원본40개 일치를 확인했다. 코드와 성공/실패 증거는 `artifacts/conversation-evidence-bf48e86/manifest.json`에 보존했다. 사용자 대화 원문은 이 증거 묶음에 복제하지 않았다.

`release/2026-09-13T04-17-54-187Z`는 음성 교정 추가 전 중간 패키지다. 새 UI의 native/마이크 실기기 시험은 중단 기간 때문에 실행하지 않았다.

**남은 핵심:** CPU 인식의 처리 시간과 고유명사/억양/잡음 정확도,약10~13초인 모델 응답, 장기 말투·반복·관계 품질. 전달 대기의 한 원인 제거를 전체 음성 왕복 지연 해결로 표현하지 않는다. 원음 없이 하는 맥락 교정은 발화의 정답을 보장하지 않으므로 원문을 보존한다. 사용자 테스트 중에는 기존 파일 수집과 장치를 쓰지 않는 재현만 진행한다.
