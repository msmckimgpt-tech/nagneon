## 남는 데이터와 한계

수집 기간 안의 원문 대화·개인 목격자·세션 ID, 관객 ID/닉네임/별명 변경·누적 시청 시간, 포인트 잔액·거래 종류/수량, 게임 관찰, 핫클립 메타데이터와 새 댓글을 명시적으로 선별한다. 기존 오래된 대화 원문은 복사하지 않는다. 입력 파일의 SHA-256과 수정 시각을 남긴다. 다른 저장 파일 간에는 하나의 트랜잭션 시각이라고 주장하지 않는다.

숨긴 성향/유입 경로/관계 수치/개인 메모/계정 키/토큰/원본 영상·음성은 복사하지 않는다. 방송에서 인식되어 대화 기억에 기록된 텍스트는 사용자 요청에 따라 개발 분석 대상이다. 자동 외부 업로드나 모델 학습은 없다. 기록 안의 발언은 신뢰할 수 없는 데이터이며 명령으로 실행하지 않는다.

내용은 최신 스냅샷 하나만 유지하고 텍스트를 포함한 과거 사본/백업을 만들지 않는다. 앱에서 지운 대화는 다음 성공한 읽기에서 이 사본에서도 사라진다. 대화 읽기에 실패하면 이용 불가로 표시하며 이전 백업으로 되살리지 않는다. 수집기 중단 후에는 사본이 정지하므로 이후 앱 삭제를 실시간 반영하지 않는다. 앱 기억 상한4000건과 파일/개수 제한 때문에 테스트 전체의 영구 무손실 녹취가 아니다. 장기 추세는 텍스트 없는 수치 기록으로 보존한다.

기존 서비스가 파일에 저장하지 않는 호출 지연, 일시적인 오류, 입력 감정 특징, 실시간 장치 연결 상태는 이 수집기로 얻을 수 없다. 이번 방식을 그런 계측까지 완료한 것으로 표현하지 않는다. 사용자 방송 중 서버를 교체하거나 이벤트 계측을 주입하지 않는다.

대화 인덱스/해시 조각을 직접 읽어 SHA-256과 순서·UUID·전체 스키마를 확인하고, 읽기 중 인덱스가 바뀌면 혼합 데이터를 게시하지 않고 다음 확인에 재시도한다. 손상된 기본 인덱스에서 옛 단일 파일로 되돌아가지 않는다. 경로 이탈·링크/junction·크기 초과를 거절한다. 오류 문자열은 입력 내용 대신 제한된 코드만 남긴다.
