# ChatGPT 구독 음성 연결

실제 마이크·선택 게임 창·Sol 채팅을 함께 연결한 원클릭 시험에서 후속 발언과 화면 반응을 확인했다. 배포 패키지·설치 검증은 소스 실행 시험과 별도로 확인한다.

## 시작과 중지

기존 ChatGPT 계정을 연결하고 관객 모델을 `gpt-6-sol`로 선택한다. 연결 설정의 **ChatGPT 구독 음성**에서 원음 전송 안내를 확인하고 적용한다. 함께 볼 게임 창을 선택한 다음 **방송 시작**을 누르면 마이크와 전용 음성 연결을 준비한다. 방송 중에는 **마이크 연결**로 다시 연결할 수 있다. Desktop 앱 직접 조작이나 별도의 전달 명령은 필요하지 않다.

마이크·방송을 중지하거나 AI 대시보드에서 원음 이해를 차단하면 전송과 새 관객 반영을 중지한다. 구독 연결 실패와 한도 부족을 유료 API 또는 로컬 STT로 자동 대체하지 않는다. 기존 API·로컬 설정은 시작 시 임의로 변경하지 않는다. 구독 방식으로 전환할 때는 화면에서 전송 안내를 다시 확인해야 한다.

## 연결·출력·권한

- 번들 공식 Codex CLI `0.156.1`의 공개 실험 App Server `thread/realtime/start`를 `v3/audio/webrtc`로 사용한다. CLI가 기존 구독 인증을 처리한다. 토큰·쿠키·인증 파일을 추출하거나 비공개 주소를 구성하지 않는다. Desktop 설치/업데이트는 필요하지 않다.
- 계정이 ChatGPT 구독이고 구매 크레딧이 없으며 포함량 한도를 소진하지 않은 상태인지 공식 인터페이스로 확인한다. 확인할 수 없으면 연결하지 않는다. 새 API 키·추가 결제·자동 충전은 사용하지 않는다.
- Voice 세션은 임시 읽기 전용이며 셸·앱·MCP·브라우저·컴퓨터 조작·에이전트 도구를 차단한다. 발언을 실행 명령으로 사용하지 않는다. 수신된 도구 실행 요청도 거절한다.
- 제공처와 양방향 RTP로 연결하되 수신 오디오 트랙은 즉시 비활성화하고 중지한다. 오디오 출력 요소나 스피커 목적지를 만들지 않는다. GPT 답변 텍스트는 생성될 수 있다. 다른 앱·게임·방송의 소리를 전체 음소거하지 않는다.
- 음성 모델의 도구 호출 판단 없이 사용자 전사 이벤트만 자동 접수한다. 관객은 전사와 선택한 게임 화면을 받는다. 관객 모델이 원음을 직접 듣거나 억양을 확인했다고 표시하지 않는다.

이 경로는 **공개 실험 인터페이스**이며 운영 지원을 보장하는 API와 구분한다. 제공처 변경으로 연결이 실패하면 오류를 표시하고 중지한다. 이전 WebSocket 방식에서의 API 키 요구를 WebRTC 방식에도 적용되는 제한이라고 해석하지 않는다. 시작 RPC 접수만으로 성공을 판정하지 않고 SDP·피어·데이터 채널·사용자 입력을 구분해 확인한다.

공식 참고: [Voice](https://learn.chatgpt.com/docs/features/voice), [App Server](https://learn.chatgpt.com/docs/app-server), [Live conversations](https://developers.openai.com/api/docs/guides/live-conversations).

## 시각·순서·화면

연속 캡처의 로컬 시작 시각과 16 kHz PCM 프레임 위치, 제공처의 항목·발언 ID 및 근사 시간 구간, 전사 관측 시각을 별도로 보존한다. 제공처 시간은 단어 경계나 샘플 단위 정렬을 보장하지 않는다. 수신 시각을 발화 시작 시각으로 바꾸지 않는다. 로컬 입력 연결 UUID는 앱이 부여한 ID이며 제공처 원음 ID라고 주장하지 않는다.

원음의 디스크 보존을 확인한 범위만 관객 입력으로 전달한다. 같은 제공처 항목이나 전송 순번의 재시도는 중복으로 처리하되, 별도 원음 구간에서 반복한 같은 말은 유지한다. 최종 발언에서 부정·정정 등 실질적인 내용이 달라지면 앞선 접수를 참조하는 정정으로 전달한다. 긴 정정이나 확인할 수 없는 구간은 검토 대상으로 남긴다.

관객 요청은 같은 마이크 입력·복구 여부·선택 창·청취 관객에 속하는 연속 전사 조각을 최대 4개씩 처리한다. 각 조각의 원래 화면과 시각은 개별 항목에 남긴다. 정정, 겹치는 구간, 입력이나 창의 교체, 관객 입장 경계는 묶지 않는다. 이를 통해 원음 접수보다 느린 관객 요청이 문장 중간 조각 하나씩만 처리하며 밀리는 것을 줄인다. 모든 발언에 채팅을 강제하지는 않는다.

화면은 해당 음성 구간에 저장한 선택 창의 프레임을 사용하고 당시 관객 목격 범위도 유지한다. 화면 근거는 최대 120초 보관하며 만료된 화면을 현재 화면으로 바꾸지 않는다. 화면이 없으면 없는 상태로 전달한다. 원음 동의로 다른 창·전체 화면·시스템 소리를 추가 공유하지 않는다.

## 복구와 자원 정리

원음은 기존 로컬 원음 저장소에, 전사·구간·전달 계획·접수·미확인 상태는 `data/native-audio/subscription/voice-*.jsonl`에 기록한다. 원음과 저널은 앱 실행 중 24시간 기준으로 정리한다. 앱이 꺼져 있는 동안에는 정리하지 않는다. 화면 파일은 더 짧은 120초 정책을 따른다. 실제 음성·화면·전사·원본 진단은 사용자 데이터이며 Git·PR·릴리즈에 포함하지 않는다.

같은 방송에서 마이크를 다시 연결하면 보존된 최근 원음의 미확인 구간을 원본 해시와 대조해 RTP로 다시 보낸다. 한 번에 최대 12초, 한 마이크 연결에서 최대 2구간, 동일 구간의 자동 시도는 최대 2회다. 현재 음성과 복구 연결은 각각 하나로 제한한다. 새 방송에는 이전 방송 원음을 자동 제출하지 않는다. 복구 전사에는 원래 입력·프레임·발화 시각·화면 근거와 복구 표시를 유지한다.

전사가 오지 않았다는 사실을 무음 판정으로 바꾸지 않는다. 확인되지 않은 구간은 원음을 보존하고 미확인으로 표시한다. 앱 중단 시 전달 여부가 불확실한 구간은 자동 중복 제출하지 않고 검토 대상으로 남긴다. 저널 재로딩은 장치나 연결을 자동 활성화하지 않는다.

시작·연결·상태 확인에는 시간 한도를 두고 큐·재시도 수를 제한한다. 중지하면 소유한 미디어 트랙·피어·호스트를 정리한다. 렌더러가 멈춰 트랙 중지 코드를 실행할 수 없으면 해당 나그네온 창을 종료해 장치를 해제한다. 다른 앱의 창이나 프로세스를 종료하지 않는다. 호스트 종료 또는 디스크 기록을 확인하지 못하면 새 연결을 차단한다.

## 검증 범위

2026-09-27 실제 구독 계정에서 번들 CLI의 WebRTC 연결과 정상 종료를 확인했다. 제품 서버·캡처·구독 클라이언트를 연결한 보존 음성 재생 시험에서는 반복 발언 5건이 종료 전에 자동 접수됐고 원음 저장과 트랙 해제를 확인했다. 송신 전용 협상의 연결 성공만으로 실제 발언 전달을 확인할 수 없어, 원음 접수가 확인된 양방향 협상과 수신 오디오 차단을 사용한다. 별도 물리 마이크 시험에서는 사용자 전사가 Voice 종료 전에도 도착했고 자동 종료 후 입력 트랙이 해제됐다. 사용자는 GPT 답변 소리가 들리지 않았다고 확인했다. 별도 보존 원음 재생 시험에서는 반복 발언의 전사와 원래 재생 구간의 시간 관계를 확인했다. 이 시험들은 설치된 나그네온의 화면·관객 통합 수용 시험을 대신하지 않는다.

UI 검사는 합성 계정·관객과 격리 프로필을 사용하며 실제 장치 권한을 차단한다.

별도 3분 제품 시험에서는 방송 시작 한 번으로 연결하고 청취 중 37개 전사 구간을 자동 접수했다. 초기 시험에서 발견한 한 조각씩 처리되는 적체는 위의 연속 조각 묶음으로 수정했다. 일반 시청자를 포함한 수정본 시험은 실제 Baba Is You 조작과 발언으로 진행했다. 37개 구간 모두 종료 전에 선택 창 근거와 함께 전달됐으며 Sol 요청 17건이 성공하고 관객 채팅 10건이 시험 끝까지 표시됐다. 종료 시 발언 처리 대기는 0건이고 소유한 미디어 트랙은 모두 해제됐다. 사용자는 첫 발언 이후의 채팅과 화면에 맞는 반응을 확인했다. 이전 실제 조작 시험에서는 GPT 답변 소리가 없고 게임 소리·입력이 정상이라고 확인했다. 자연스러운 시청자 말투는 별도 개선 항목으로 남아 있다.

수정본 시험의 전사 관측부터 접수까지 중앙값은 3.464초, 제공처 근사 원음 구간 끝부터 접수까지 중앙값은 1.591초였다. 두 측정은 기준 시각이 다르며 정확한 단어 경계 지연이 아니다. Sol 요청 중앙값은 9.020초였다. 시험은 관객 요청을 18회로 제한했고 새로운 물리 장치·고부하 게임·설치 수용을 이 결과만으로 완료 처리하지 않는다.

제품 복구 경로의 별도 원음 재생 시험에서는 초기 전사 전달을 의도적으로 차단한 뒤 같은 방송에서 다시 연결했다. 실제 RTP 재전송으로 원래 입력을 참조하는 복구 전사 4건을 접수했고 현재 캡처와 복구를 함께 종료했다. 이 시험은 보존 음성을 사용하며 새 물리 마이크 시험과 구분한다.

```powershell
npm ci
npm run check
npm audit --audit-level=high
node --test test/subscription-voice*.test.js test/native-audio*.test.js
node_modules\.bin\electron.cmd scripts/verify-native-audio-ui.cjs
```

발화부터 접수까지의 지연과 전사 관측 이후 전달 지연은 구분해 측정한다. 합성 검사, 원음 재생, 실제 물리 마이크, 게임 동시 조작, 패키지·설치 검증은 각각 기록하며 무손실·즉시 전달·성능 개선을 미측정 상태에서 주장하지 않는다.
