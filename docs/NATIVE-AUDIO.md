# 원격 원음 이해

원격 원음 이해는 아직 정식 배포하지 않은 개발 기능이다. 실제 제공처 연결, 물리 마이크, 게임 동시 실행 및 설치 검증을 통과하기 전에는 릴리즈하지 않는다.

## 연결과 비용

마이크 원음은 공식 OpenAI Realtime API의 `gpt-realtime-2.1`에 전달하고, 청취 해석을 기존 관객 반응 경로에 넣는다. 관객 모델 선택은 그대로 유지한다. GPT-6 Sol을 사용하려면 관객 모델 설정에서 선택한다.

ChatGPT 구독 로그인과 원음 API 인증은 별개다. API 키와 원음 전송·사용량 동의가 모두 있어야 연결한다. 키는 앱 메모리에만 두며 설정 파일에 저장하지 않는다. 기존 OpenAI 환경 키도 같은 동의 조건을 적용한다. 동의를 해제하거나 로컬 모드로 바꾸면 보유 키를 지운다. 유료 API 연결을 원하지 않는 경우 키 발급이나 결제 설정을 진행할 필요가 없다.

공식 Codex CLI 0.156.1과 별도 폴더의 0.157.1에서 계정·모델·실험 원음 인터페이스를 확인한 결과, GPT-6 Sol의 입력은 텍스트와 이미지이며 해당 원음 세션은 API 키 인증을 요구했다. 시작 RPC의 접수 응답 뒤 오류 알림이 발생할 수 있으므로 RPC 성공만으로 연결 성공을 판정하지 않는다. 구독 토큰을 추출하거나 비공개 음성 주소를 호출하는 대체 경로는 구현하지 않는다.

데스크톱 ChatGPT Voice의 구독 이용 범위는 외부 앱의 음성 API 이용 권한과 구분한다. App Server는 실험 인터페이스이며 운영용 지원 대상이 아니다.

## 구현 동작

- 기존 프로필은 로컬 음성 설정을 유지한다. 새 프로필은 원격 모드를 표시하되 동의는 꺼져 있다. 원격 모드에서는 마이크용 로컬 음성 모델 준비를 건너뛰고 이미 실행 중인 해당 워커를 종료한다. 원격 실패 시 로컬 추론으로 자동 전환하지 않는다.
- 시스템 소리와 저장된 클립의 기존 로컬 분석은 별도 경로다. 마이크 원음 동의는 그 소리를 외부로 보내는 동의가 아니다.
- 16 kHz PCM을 기존 연속 캡처에서 보존한다. 2초 단위의 원음 구간을 100 ms 패킷으로 나누고 실제 24 kHz로 변환해 전송한다. 별도 ASR 완료, 음량 임계값 또는 전사문 필터를 원격 이해의 전제 조건으로 삼지 않는다.
- 시간·구간 순서·입력 연결 식별자·발언 당시 화면·관객 목격 범위는 앱이 관리한다. 청취 모델의 문구 후보와 의미 해석은 정확한 전사문이나 관객이 직접 들은 원음으로 취급하지 않는다.
- 원격 접수, 이해, 관객 입력 전달, 디스크 저장은 별도로 집계한다. 불확실한 구간은 무음 성공으로 바꾸지 않는다. 긴 해석은 발언 경계로 나누고 부분 전달 실패를 재시도할 때 이미 전달된 부분이나 모델 호출을 반복하지 않는다.
- 한 입력 연결의 원격 처리는 순차적이다. 구간별 모델 시도는 최대 3회, 이미 이해한 결과의 전달 시도는 최대 12회로 제한한다. 미해결 앞 구간이 뒤의 새 입력을 영구히 막지 않으며 결과에 앞 구간의 미해결 여부를 남긴다.
- 방송·마이크·AI 정책의 중지는 새 송신과 늦은 결과 수용을 차단한다. 같은 방송에서 마이크를 다시 켜면 남은 시도 범위의 미처리 원음을 처리한다. 새 방송에는 이전 방송 원음을 자동 재전송하지 않는다.
- 원격 연결은 55분에 교체한다. 저장이 확인된 원음은 메모리 압박 시 디스크에서 다시 읽고, 미저장 메모리의 과도한 증가나 처리 기록 저장 실패는 원격 처리를 중단한다.
- 원음은 기존 로컬 원음 저장소, 청취 상태와 해석은 `data/native-audio/listening-*.jsonl`에 보관한다. 앱 실행 중 24시간 기준으로 정리하며 청취 기록 정리는 분 단위다. 앱이 꺼져 있는 동안에는 정리 작업도 실행되지 않는다. 이 파일들은 사용자 데이터이며 Git·릴리즈 첨부 대상이 아니다.
- 사용량은 제공처가 보고한 음성·텍스트·캐시 토큰을 구분한다. 정보가 없거나 취소 뒤 실제 사용량을 확인하지 못한 경우 0원으로 단정하지 않는다.

## 현재 검증 범위와 남은 작업

합성 프로토콜·HTTP·상태 검사는 실제 모델의 의미 이해 품질이나 지연을 증명하지 않는다. 초당 네 번의 짧은 발언, 이름·부정·정정 보존, 장시간 송신 처리량, 실제 게임의 자원 영향은 실측이 필요하다. 현재 캡처의 디스크 저장 전송은 1초 묶음을 사용하며 원격 이해는 2초 묶음 이후 실행되므로 100 ms의 실제 송신 지연을 보장하지 않는다.

앱을 완전히 재시작하면 원음·청취 파일은 보존 정책에 따라 남지만 미처리 작업을 저널에서 자동 복원해 재전송하는 기능은 아직 없다. 이 범위는 같은 실행 내 마이크 재연결 복구와 구분한다. 제공처의 실제 응답 형식, 장치 중지, 게임 동시 실행, 패키지 업데이트·기록 보존까지 확인한 뒤 통합·정식 배포를 판단한다.

로컬 검증 명령:

```powershell
npm ci
npm run check
npm audit --audit-level=high
node --test test/native-audio-provider.test.js test/native-audio.test.js test/native-audio-http.test.js test/native-audio-pricing.test.js
node_modules\.bin\electron.cmd scripts/verify-native-audio-ui.cjs
```

UI 검사는 격리 프로필과 합성 관객을 사용하며 물리 마이크를 열거나 API를 호출하지 않는다. 결과와 화면은 `artifacts/remote-native-audio/ui/`에 생성된다. 변경된 기본 프로필·캡처 경로를 실제로 검증하기 전에는 개발 검사 통과를 설치 완료로 보고하지 않는다.
