# 선택적 공식 Chat 개발 보조

## 현재 운영 원칙 — 2026-09-22

기본 작업 경로는 로컬 Codex/Claude다. 전면·상시·가능한 모든 작업의 Chat 우선
위임은 폐기한다. 독립 관점이 도움이 되는 조사·설계·리뷰 등 명확한 범위의 작업만
공식 기능의 지원, 외부 전송 권한, 실행 권한과 왕복 비용을 확인해 선택한다.

- 공식 기존 Chat 전송/읽기 + 승인된 RDC 기능만 사용한다. 비공식 웹쫀쿠 호출,
  Chat UI/DOM/CDP 자동화, 출력 스크래핑, 쿠키/세션 추출, 제한 우회는 사용하지 않는다.
- xhigh 기본값은 유지하되 2026-09-21 승인된 특정 기존 일반 Chat만 High 예외다.
  현재 설정을 확인할 수 없으면 그 위임은 보류한다. 로컬 모델/추론은 바꾸지 않는다.
- 읽기 전용을 우선한다. 파일 변경·셸·빌드는 해당 작업의 실제 권한과 정확한
  기기·소유 worktree·명령/파일 범위·수용 기준이 있을 때만 위임한다.
- 자료는 필요한 부분만 보내고 비밀·개인정보·회사 자료의 외부 전송 권한을 확인한다.
  RDC는 제3자이며 파일 allowlist나 worktree는 셸 샌드박스가 아니다.
- 안전 거부를 다른 도구/셸/에이전트로 우회하지 않는다. 제출·원문 해시·파일 생성은
  작업 합격이 아니며 Codex가 원본 대조·실제 테스트·최종 통합을 담당한다.
- 별도 Chat 병렬 검토와 별도 웹 종합은 실제 지원/승인이 있을 때만 선택한다.
  같은 Chat의 순차 검토를 독립 병렬로 표시하지 않는다.

상세 계약은 [공식 위임 지침](../scripts/web-development/skill/references/official-chat-delegation.md),
연결 경계는 [연결 안내](../scripts/web-development/skill/references/connections.md)에 있다.

## 전역 설치와 재적용

`python scripts/web-development/install.py` 및 `--check`로 현재 사용자 Codex/Claude
지침·스킬을 설치한다. WSL은 해당 사용자로 python3를 실행한다. 기존 전역 문서의
다른 관리 블록은 유지하며, 이전 OFFICIAL-CHAT-DELEGATION 블록이 있으면 함께 갱신한다.
계정 인증과 권한은 설치와 별개다. 기존 스킬의 사용자 수정은 충돌로 중단한다.
새 설치는 비공식 모델 호출 실행기를 배포하지 않는다. 기존 앱/인증/프로세스를
이 문서 수정으로 삭제·중지하지 않으며 과거 실행기는 현재 지침에서 사용하지 않는다.

## 이전 검증 기록의 해석

2026-09-14~15의 웹쫀쿠 로그인/High 응답, RDC 파일 왕복, 전역 설치 및 로컬 테스트
성공은 당시의 기술적 검증이다. 전체 위임의 정책 적합성·무제한 사용·임의 저장소
쓰기 권한을 보증하지 않는다. 과거 설치·브라우저 자동화 안내는 이 문서로 대체한다.
실제 xhigh 수행은 별도 확인이 필요하며 비용 절감은 NOT_MEASURED다.

## 이번 변경과 검증

전면 위임 문구와 실행 권장 예시를 제거하고 전역/프로젝트/배포 문서를 같은 범위로
맞춘다. 설치기의 기존 공식 위임 블록 갱신·원문 보존·재적용을 검사하고, 최신
통합 코드에서 프로젝트 필수 검사를 수행한다. 문서·설치기 변경으로 제품 버전을
올리거나 정책 적합성을 포괄 선언하지 않는다.

RDC 오프라인·재인증 복구는 [RDC 복구 안내](RDC-RECOVERY.md)를 따른다.
