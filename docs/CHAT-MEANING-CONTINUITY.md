# 서로 다른 질문과 상대를 보존하는 채팅 중복 검사

관객의 질문과 확인을 같은 채팅으로 지우지 않는다. 기존 한국어 질문 단서를 함께 확인하므로 “해결한 거야?” 뒤의 “해결한 거야!”처럼 글자는 비슷해도 질문 여부가 달라진 말은 남는다. 저장된 문장이나 문장부호를 교정하지 않는다.

다른 관객에게 건넨 질문도 남는다. 현재 이름과 이전 이름을 전체 명단에서 같은 관객 ID로 해석하고, 이름을 언급한 대상의 집합이 바뀌면 반복으로 처리하지 않는다. 부재·비활성 관객의 현재 이름 소유권, 긴 이름의 우선순위와 모호한 이전 이름의 배제는 기존 호칭 규칙을 따른다. 호칭 단서는 실제 의도나 친밀도를 확정하지 않는다.

“싫지는 않아요”와 “싫어요”처럼 명시적 부정 표현의 수가 다른 문장을 단순 유사도로 지우지 않는다. 이는 문장을 이해하거나 감정을 판정하는 기능이 아니라, 의미가 바뀔 수 있는 말을 보수적으로 남기는 검사다. 반복 질문, 같은 상대에 대한 유사 문장, 숫자·긍정/부정 차이, 짧은 응원과 8초·45초 중복 경계는 기존 정책을 유지한다. 순수한 ㅋ·ㅎ 웃음이나 기호에 붙은 물음표로 짧은 도배 차단을 우회할 수 없다.

검사는 응답을 채팅 대기열에 넣을 때와 실제 표시 직전에 모두 적용한다. `test/chat-meaning-continuity.test.js`는 합성 문장과 실제 Studio의 요청 준비·수용·표시·기억 경로를 확인한다. 새 AI 호출·설정·저장 형식은 없다. 전체 한국어 의미 이해, 실제 생성 대화의 자연스러움이나 물리 장치 인식 품질을 입증하는 검사는 아니다.
