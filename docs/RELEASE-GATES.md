# 판매 준비 기준

2026-09-13. 이 문서는 현재 제품을 판매 가능하다고 선언하는 문서가 아니다. 목표는 기능 수를 늘리는 데 그치지 않고 설치·운영·복구·몰입을 실제로 검증하는 것이다.

최근 사용자 실사용 반영은 [1차 대화·말투 분석](FIRST-TEST-CHAT-CULTURE.md)과 [음성 교정·전달](LIVE-CONVERSATION-QUALITY.md)을 기준으로 확인한다. 약55분278발언을 읽었고 수정 코드는 장치 없는 검사와 실제 모델 합성 사례로 확인했다. 수정본을 사용한 새 실사용의 개선 폭, 물리 마이크 정확도, 여러 게임의 장기 몰입, 설치/업데이트/판매 조건은 아직 합격이 아니다. 아래 과거 속도/검사 숫자와 새 결과를 혼동하지 않는다.

최근 후속 증거는 [공개 방송 채팅 조사와 익명 후원](CHAT-ATTENTION-DONATIONS.md), [후원 기억 보존과 배포 검사](DONATION-MEMORY-RELEASE.md)에 있다. 후원 종류·금액이 회상에서 사라지던 결함을 고쳤고, 사실 회상 검사와 남아 있는 보고서 같은 말투를 구분했다. 패키지의 Node 서버·파일 검사는 네이티브 설치/창/장치 검증을 대신하지 않는다.

[함께한 대화를 떠올리는 관객 말투](RECALL-SPEAKING-STANCE.md)는 재입장 시각과 과거 목격 기억의 지시 충돌, 자기 말/목격한 말의 구분, 생략형 질문의 제한된 최근 대화 참고를 다룬다. 수정 전·중간 실패·최종 실제 모델 입력과 응답을 구분해 보존한다. 소수 합성 사례와 전체 코드 검사만으로 장기 대화 품질을 합격 처리하지 않는다.

[클립 대화의 라이브 기억 연결](CLIP-CONVERSATION-MEMORY.md)은 읽은 원문 버전·자기 댓글·타인 댓글을 구분해 재시작 후 대화에 전달한다. 읽지 않은 새 댓글·삭제·익명 후원·가상 기획·저장 실패를 검사했다. 대용량 반복 조회 캐시와 첫 조회 비용, 클립 댓글 말투, 유입/일반 커뮤니티 전달·전체 저장소 트랜잭션·전역 삭제의 남은 범위를 함께 기록한다.

## 제품 기준

[방송 중 마이크 인식 복구](MICROPHONE-RECOVERY.md)는 로컬 인식기 종료·준비/인식 기한 초과 후 전체 앱을 다시 시작해야 하던 흐름을 개선한다. 별도 실제 프로세스와 HTTP 복구, 취소·늦은 장치 응답을 검증하며 물리 장치·Whisper 모델·장기 방송 검증과 구분한다.

[관객 부재와 복귀의 청취 경계](AUDIENCE-RETURN-CONTINUITY.md)는 부재중 호명·복귀 시각·대기 반응·늦은 음성 전사와 개인 기억의 경계를 연결한다. 합성 상태와 실제 모델 결과를 구분하며 물리 장치·장기 사용 합격은 별도로 남긴다.

[관객 첫 만남의 개성 분산](AUDIENCE-INDIVIDUALITY.md)은 기존 실제 생성 결과의 취향 중복을 근거로 도착 시점의 창작 방향과 닉네임 중복 회피를 개선한다. 새 인물과 보존된 합성 인물의 대화를 비교하며, 작은 표본의 통과를 장기 관계·말투 다양성 합격으로 대체하지 않는다.

[클립 유입의 개인 기억](CLIP-ARRIVAL-MEMORY.md)은 생성 영수증과 소개를 접한 경험을 같은 저장으로 확정해 다음 방송의 대화까지 연결한다. 실제 미디어 시청, 일반 커뮤니티 자발적 읽기, 전역 의미 삭제와 장기 성향 발전은 별도 남은 범위다.

[연속 장면 인식](TEMPORAL-VIEWING.md)은 모델 대기 중에도 최근 화면을 모으고 시간순 이미지·소리·발언을 전달한다. 중간 동작과 늦은 반응을 합성 장면으로 검사하며, 실제 게임의 연속 시청 품질과 물리 장치 성능 합격은 별도로 남긴다.

대화 기억의 원문 출처, 최종 실제 모델 재실행, 용량 시험은 [CONVERSATION-MEMORY.md](CONVERSATION-MEMORY.md)에 있다. 설치는 전체 1.6 GB 앱의 격리 TEST 설치·실행·제거까지 확인했지만 최초 저널 이전 중단과 늦은 제거 실패 등 잔여 조건 때문에 production 활성화를 차단한다. [INSTALLER.md](INSTALLER.md)의 해제 조건을 먼저 해결한다. 실제 게임 연결 중 발견한 최근 결함과 수정 전후 증거는 [LIVE-CAPTURE-ACCEPTANCE.md](LIVE-CAPTURE-ACCEPTANCE.md)에 있다.

## 외부 서비스와 Steam

공식 문서는 Codex의 ChatGPT 구독 로그인과 API 키 로그인을 구분한다. 현재 개발 앱은 사용자가 직접 로그인한 공식 CLI를 호출하며 인증 토큰을 직접 읽지 않는다. 이것만으로 모든 구매자의 요금제 접근성이나 제3자 상용 앱의 제공 조건이 확정되는 것은 아니다. 배포 경로에 대한 조건 확인과 사용자별 연결 시험을 별도로 마쳐야 한다. [OpenAI 인증 문서](https://learn.chatgpt.com/docs/auth)

성능 대안으로 App Server를 조사했으나 공식 문서가 현재 App Server와 WebSocket 전송을 실험적이며 프로덕션 지원 대상이 아니라고 설명한다. 이를 출시용 기본 연결로 교체하지 않았다. [App Server 문서](https://learn.chatgpt.com/docs/app-server)

현재 적용한 최적화는 공식 `model_instructions_file`을 **요청별 임시 파일**로 지정하여 코딩용 기본 지침 대신 관객용 지침을 주는 것이다. 사용자 전역 설정·모델·추론 수준을 바꾸지 않는다. 2개 사례의 비교에서 입력 토큰이 16,832→12,723, 17,656→13,548로 감소했으나 요청 시간은 한 사례에서 증가하고 한 사례에서 감소했다. 실험 원본은 `artifacts/instructions-benchmark.json`. [공식 설정 항목](https://learn.chatgpt.com/docs/config-file/config-reference)

Steam의 실시간 생성 AI 항목에는 실행 중 생성되는 콘텐츠의 설명과 불법 콘텐츠 생성 방지 장치를 기입해야 한다. 출시 전에는 현재 프롬프트·검증·차단어·사용자 제어가 실제로 처리하는 범위와 한계를 포함한 설명 및 테스트 자료를 준비한다. 외부 AI 서비스의 비용·접근과 Steam 결제 방식에 대한 문서도 확인해야 한다. 가상 관객 포인트는 현금 구매·교환이 없으며, 앱 구매 및 외부 AI 사용 계약과 분리된 내부 연출이다. [Steam 콘텐츠 설문](https://partner.steamgames.com/doc/gettingstarted/contentsurvey)

상점 페이지에는 출시 시 실제 제공하는 기능만 표시하고, 스크린샷과 설명이 현재 빌드와 일치해야 한다. Valve의 상점 및 빌드 검토를 통과해야 출시할 수 있다. 개발 테스트 통과나 설치 파일 생성은 이 승인과 동등하지 않다. [Steam 검토 과정](https://partner.steamgames.com/doc/store/review_process)

## 완료라고 부르지 않을 조건

미검증 장르까지 지원이 입증됐다고 표현하지 않는다. 캐릭터의 창작 속마음을 모델의 숨은 추론 또는 사람의 실제 심리라고 판매하지 않는다. 기능이 코드에만 존재하거나 합성 입력만 통과했을 때 실제 플레이 수용 기준이 충족됐다고 표시하지 않는다. 서명·설치·정책·장기 자연스러움·지원 운영이 남아 있는 동안 판매 준비 목표를 완료 처리하지 않는다.
