# 판매 준비 기준

2026-09-13. 이 문서는 현재 제품을 판매 가능하다고 선언하는 문서가 아니다. 목표는 기능 수를 늘리는 데 그치지 않고 설치·운영·복구·몰입을 실제로 검증하는 것이다.

## 제품 기준

| 영역 | 출시 전 확인할 결과 | 현재 증거/남은 작업 |
|---|---|---|
| 첫 실행 | 개발 환경이 없는 Windows에서 설치하고 계정·음성·화면 연결까지 완료 | 독립 배포본과 음성 런타임, 개발 PATH를 제외한 실제 실행 검증. 신규 온보딩/계정 UI 및 첫 방송 전환 구현·검증. 새 Windows·설치 프로그램·새 계정 인증 완료 필요 |
| 게임/잡담 | 여러 장르와 Just Chatting에서 일관된 대화 | Steam 2종의 제한된 화면 테스트, 합성 음성/장면 검증. 장기 실사용 필요 |
| 시스템 소리 | 배경음악·효과음·게임 대사를 마이크와 구분하고 실제 출력으로 인식 | Windows loopback/로컬 YAMNet·Whisper/청취자 문맥/소리 전용 잡담 구현. 실제 출력과 440/880 Hz 혼합 녹화 검증. 게임별 효과음 정확도·장치 변경·장기 혼합 음원 필요 |
| 관객 개성 | 다수 관객이 구별되며 모르는 사실·입장 전 사건을 함부로 회상하지 않음 | 개인 목격자·시청 시간·입장 이후 대화, 공개 원문 기억 검색 구현. 실제 Astra의 개인 코너 회상 실패를 수정하고 시각별 원문 재실행으로 확인. 어휘 검색·단일 모델 공유 입력의 한계와 장기 생성 대화 정량 평가 필요 |
| 방송 욕구 | 기념·주인공·관계·상상·연습 경험이 다음 방송으로 이어짐 | 10종 기획 방송, 14종 연습, 3종 분기 시즌·출처가 있는 관객 초대장·기념품 구현. 실제 Astra 10회와 재시작 UI 검증. 선택을 다시 묻는 문제의 지침 수정과 실제 3쌍 비교. 장기 몰입·반복률·자율 기획의 다양성 평가 필요 |
| 반응 지연 | 첫 반응·발언 응답·전사 지연을 각각 측정하고 목표치 충족 | 발화 끝 기준 전사·직렬 대기·취소와 입력 보존 구현. 합성 한국어 첫 구절 4.2초에 관객 요청 도달. 모델은 약 8~15초이며 문맥 40.6% 절감이 지연 개선을 보장하지 않음 |
| 기억 보존 | 손상·강제 종료·저장 실패 때 복구 근거를 남기고 초기화하지 않음 | JSON 세대 백업/검증/복구, 공개 대화 4,000개/고정100개와 불변 조각·원자 인덱스 구현. 기억 전용19검사·Electron8흐름 통과. 여러 저장소의 통합 트랜잭션·보관량 이후 의미 기억은 별도 과제 |
| 녹화 | 실제 선택 화면·시스템 출력·마이크·재생·동시 캡처·중지의 일관성 | 합성 영상/오디오 WebM 녹화·업로드·디코딩 검증. 여러 GPU·DPI·독점 전체화면 필요 |
| 보안 | 로컬 요청의 신뢰 경계, 모델 도구 차단, 키 노출 방지 | 실행별 세션 인증·루프백/Origin 검증·모델 도구 비활성화·ASAR/fuses 적용. 종합 보안 검토 필요 |
| 운영 | 오류 설명, 진단 내보내기, 저장 용량 안내, 업데이트 복구 | 기본 오류·일부 내보내기 있음. 통합 지원 흐름·이전 버전 복구 필요 |

설정·화면 선택 다이얼로그의 이름, 키보드 순환, Escape, 포커스 복귀, 배경 비활성화와 저장 오류 중 초안 보존을 Electron에서 검증했다. `docs/DIALOG-ACCESSIBILITY.md`, `docs/SPEECH-RESPONSE.md`에 이 단계의 근거와 한계가 있다.

대화 기억의 원문 출처, 최종 실제 모델 재실행, 용량 시험은 [CONVERSATION-MEMORY.md](CONVERSATION-MEMORY.md)에 있다. 설치 생성기는 만들었으나 실행 중 제거·소유권·게시 실패 복구 결함으로 시작을 차단했다. 컴파일 성공을 설치 합격으로 취급하지 않는다. [INSTALLER.md](INSTALLER.md)의 실제 결함과 해제 조건을 먼저 해결한다.

## 외부 서비스와 Steam

공식 문서는 Codex의 ChatGPT 구독 로그인과 API 키 로그인을 구분한다. 현재 개발 앱은 사용자가 직접 로그인한 공식 CLI를 호출하며 인증 토큰을 직접 읽지 않는다. 이것만으로 모든 구매자의 요금제 접근성이나 제3자 상용 앱의 제공 조건이 확정되는 것은 아니다. 배포 경로에 대한 조건 확인과 사용자별 연결 시험을 별도로 마쳐야 한다. [OpenAI 인증 문서](https://learn.chatgpt.com/docs/auth)

성능 대안으로 App Server를 조사했으나 공식 문서가 현재 App Server와 WebSocket 전송을 실험적이며 프로덕션 지원 대상이 아니라고 설명한다. 이를 출시용 기본 연결로 교체하지 않았다. [App Server 문서](https://learn.chatgpt.com/docs/app-server)

현재 적용한 최적화는 공식 `model_instructions_file`을 **요청별 임시 파일**로 지정하여 코딩용 기본 지침 대신 관객용 지침을 주는 것이다. 사용자 전역 설정·모델·추론 수준을 바꾸지 않는다. 2개 사례의 비교에서 입력 토큰이 16,832→12,723, 17,656→13,548로 감소했으나 요청 시간은 한 사례에서 증가하고 한 사례에서 감소했다. 실험 원본은 `artifacts/instructions-benchmark.json`. [공식 설정 항목](https://learn.chatgpt.com/docs/config-file/config-reference)

Steam의 실시간 생성 AI 항목에는 실행 중 생성되는 콘텐츠의 설명과 불법 콘텐츠 생성 방지 장치를 기입해야 한다. 출시 전에는 현재 프롬프트·검증·차단어·사용자 제어가 실제로 처리하는 범위와 한계를 포함한 설명 및 테스트 자료를 준비한다. 외부 AI 서비스의 비용·접근과 Steam 결제 방식에 대한 문서도 확인해야 한다. 가상 관객 포인트는 현금 구매·교환이 없으며, 앱 구매 및 외부 AI 사용 계약과 분리된 내부 연출이다. [Steam 콘텐츠 설문](https://partner.steamgames.com/doc/gettingstarted/contentsurvey)

상점 페이지에는 출시 시 실제 제공하는 기능만 표시하고, 스크린샷과 설명이 현재 빌드와 일치해야 한다. Valve의 상점 및 빌드 검토를 통과해야 출시할 수 있다. 개발 테스트 통과나 설치 파일 생성은 이 승인과 동등하지 않다. [Steam 검토 과정](https://partner.steamgames.com/doc/store/review_process)

## 완료라고 부르지 않을 조건

미검증 장르까지 지원이 입증됐다고 표현하지 않는다. 캐릭터의 창작 속마음을 모델의 숨은 추론 또는 사람의 실제 심리라고 판매하지 않는다. 기능이 코드에만 존재하거나 합성 입력만 통과했을 때 실제 플레이 수용 기준이 충족됐다고 표시하지 않는다. 서명·설치·정책·장기 자연스러움·지원 운영이 남아 있는 동안 판매 준비 목표를 완료 처리하지 않는다.
