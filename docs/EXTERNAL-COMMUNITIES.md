# 바깥 커뮤니티와 내 이야기 찾기

`방송 밖 이야기` 안에서 `방송 커뮤니티`와 `바깥 커뮤니티`를 선택한다. 기존 방송 커뮤니티의 글·관계·기억은 그대로 유지된다.

바깥 커뮤니티는 공략연구소, 클립정류장, 인디산책, 심야라운지의 가상 주민 공간이다. 현실 사이트에 접속하거나 글을 게시하는 기능이 아니다. 주민은 독립적인 일상 글을 쓰며, 방송을 실제 목격한 관객만 해당 공개 발언을 근거로 방송 이야기를 올릴 수 있다. 글을 읽은 다른 주민이 관심을 보이면 다음 실제 방송부터 같은 인물로 방문할 수 있다. 자연 방문은 0P이며 기존 50P 수동 유입과 첫 관객 튜토리얼은 유지된다.

주민 자동활동과 자연 방문의 새 기본값은 ON이다. 저장된 OFF, AI 대시보드의 전체 일시정지·기능 차단·방송 밖 호출 차단은 존중한다. 리허설이나 계정 미연결 상태에서는 실제 생성하지 않고 이유를 표시한다. 신규 프로필은 방송 밖 활동을 허용하지만 별도 문화 수집 기능은 자동으로 켜지지 않는다. 기존 커뮤니티 활동과 하나의 요청 슬롯 및 시간당 최대 6회 시도 한도를 공유한다. 방송 요청이 우선하며 앱을 종료하면 작업을 취소한다.

`내 이야기 찾기`는 방송인 이름으로 저장된 글을 검색한다. 검색·목록·상세 열람은 모델 호출, 생성, 주민의 읽음 기록이나 방문을 유발하지 않는다. 검색·커뮤니티 필터·북마크·페이지 이동을 함께 사용할 수 있다. 글 숨기기는 표시 설정이며 복원 가능하다. `글 잊기`는 해당 글을 논리적으로 삭제하여 파생 기억과 방문 근거에서도 제외한다. 커뮤니티나 주제를 끄면 관련 자동활동과 해당 글을 근거로 한 새 방문도 차단된다.

주민의 게시글 읽기는 전달한 본문과 게시글 해시를 보존한다. 방송을 보지 않은 주민에게는 간접 기억만 전달하며 직접 목격 기록을 만들지 않는다. 설정 OFF, 방송 중지, 글 삭제 또는 원본 수정 중 완료된 늦은 응답은 수용하지 않는다. 모델이 침묵하거나 관심을 보이지 않는 것은 정상 결과다. 앱을 처음 켠 즉시 네 공간에 글이 모두 채워지는 방식은 아니다.

## 저장 호환성과 복귀

0.1.7은 world.json을 v2로 저장한다. v1 원본은 변환 전에 migration-backups에 SHA-256 검증 사본을 만들고 파일 내용을 동기화한 후 변환한다. 기존 관객·포인트·설정과 명시적인 OFF를 보존한다. 기존 실험 사회 데이터는 검증되지 않은 이력으로 보존하며 읽기·목격 증거로 승격하지 않는다.

동일 프로필은 한 서버만 쓸 수 있다. v2 기본 파일이 없거나 손상되면 삭제한 기억이 복구되지 않도록 자동 백업 복귀를 거절하고 원본을 보존한다. 방송 대화 또는 클립 저장소가 백업에서 복구되면 사회 기능을 격리한다. 오류가 발생하면 원본과 백업을 별도로 보존한 상태에서 복구해야 한다.

고정 실행기와 설치기는 profile-format.json의 최소 앱 버전을 검사한다. 구버전으로 복귀하려면 업데이트 전 백업을 별도 프로필로 복사하여 구버전을 연결한다. 현재 v2 프로필을 과거 EXE에 직접 연결하거나 과거 백업으로 덮어쓰지 않는다.

## 검증 도구

- `npm run check`: 형식 검사, 전체 테스트, TypeScript/Vite 빌드.
- `scripts/verify-social-runtime.cjs`: 격리 Electron에서 합성 공급자와 실제 HTTP/렌더러를 연결해 내부 구획, 검색 순수성, 북마크, OFF 반영과 좁은 화면을 검증한다.
- `scripts/verify-social-live.mjs`: 검증용 입력과 실제 Codex 계정으로 주민·글·읽기·방문 경로를 확인한다. 실행 시 구독 사용량이 소비된다. 설정한 모델/effort를 확인한 후 명시적으로 실행하며 사용자 프로필을 수정하지 않는다.
- `test/social-runtime.test.js`: 늦은 응답, 삭제 실패, 저장 실패, 공유 예산, 프로필 배타성, 복구 격리, 튜토리얼 및 자연 유입 회귀.

합성 검사는 실제 콘텐츠의 품질 또는 물리 장치 검증을 뜻하지 않는다. 실제 모델의 침묵·관심 없음과 런타임 오류를 구분한다.
