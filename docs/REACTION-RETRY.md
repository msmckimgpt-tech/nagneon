# 관객 반응 재시도

모델 요청이 실패하면 다음 시도까지 6, 12, 24, 48, 최대 60초를 기다린다. 성공과 실패가 번갈아 발생할 때 한 번의 성공만으로 실패 단계를 초기화하지 않는다. 성공한 요청 이후에는 대기 시각을 해제하므로 정상 요청을 추가로 지연하지 않는다.

현재 방송 세대에서 응답을 정상 처리한 요청이 연속 3회가 되면 실패 단계를 초기화한다. 동일 화면이라 모델 요청을 생략한 경우, 취소·이전 방송의 늦은 응답은 회복으로 세지 않는다. 실패 단계는 최대 5로 제한한다. 재시도 횟수나 방송 시간 제한을 추가하지 않으며 실패한 시도도 사용량 기록에 남긴다.

`test/reaction-retry.test.js`는 가짜 시계와 합성 제공처로 다음을 검증한다.

- 성공·실패가 교차해도 대기 간격이 늘어나고 60초에서 유지된다.
- 대기 중에는 제공처를 호출하지 않는다.
- 연속 두 번의 성공 뒤 실패하면 누적 단계를 유지하고, 세 번 성공한 뒤 실패하면 6초로 돌아온다.
- 동일 화면 생략은 제공처 성공으로 세지 않는다.

수정 전에는 교차 실패와 회복 검사 2개가 실패했다. 실제 외부 서비스의 장애를 유발하거나 계정·장치 데이터를 사용한 검사는 아니다. 다른 기능의 별도 재시도 정책까지 변경하지 않는다.
