# 구독 음성 후속 작업 기록

기준: 2026-09-28, 0.1.10 실제 사용 결과. 구현된 동작, 검증 범위와 남은 작업을 구분한다. 개인 음성·전사·화면·프로필 원본은 공개하지 않는다.

## 유지할 동작

- 나그네온의 방송 시작으로 마이크와 Windows 시스템 소리를 연결한다. ChatGPT Desktop을 직접 조작하는 절차는 필요하지 않다.
- 방송 중 시스템 소리는 항상 공유하며 별도의 끄기 전환을 제공하지 않는다. 시스템 전체 출력이 포함될 수 있다.
- 마이크와 시스템 대사를 구분해 전달하고 선택한 게임 화면을 함께 사용한다. GPT 답변 음성은 재생하지 않으며 관객은 텍스트로 반응한다.
- 구독 기반 연결과 선택된 관객 모델을 유지한다. 별도 유료 API나 다른 모델로 자동 전환하지 않는다.
- 저장된 마이크 선택, 녹화 설정, 기존 관객·대화·기록을 업데이트 후에도 보존한다. 입력 단절과 종료를 상태에 반영한다.

| 항목 | 결과와 범위 |
| --- | --- |
| 연속 발언·게임 화면 | Baba Is You 실제 조작에서 첫 발언 이후에도 채팅이 이어지고 화면에 맞게 반응함을 확인했다. |
| 시스템 대사 | 로스트아크 실제 조작에서 NPC 대사를 인식했다. 효과음·배경음 이해 성공을 뜻하지 않는다. |

| GPT 답변 소리 | 여러 실제 시험에서 답변 소리가 없고 게임 소리는 유지됨을 확인했다. |
| G Hub 시작 지연 | 초기 설치본에서 약 1분 지연이 보고됐다. 클립 녹화를 유지한 보완 패키지의 3분 재시험에서는 직접 매크로를 사용했고 지연이 재현되지 않았다. 원인 확정이나 모든 환경에서의 해결을 주장하지 않는다. |
| 최근 3분 회귀 | 클립 녹화 ON, 실제 게임·마이크 입력으로 180초 수행. 마이크 17건, 시스템 대사 7건, 관객 채팅 7건을 관측했다. 입력 시계 단절·재연결과 HTTP 오류는 관측되지 않았고 캡처 트랙과 앱이 정상 종료됐다. |
| 설치·기록 | 0.1.10 업데이트 전후 데이터 해시, 정상 종료와 고정 실행기 재시작을 확인했다. 설치 확인은 합성 UI 검사와 별도로 수행했다. |
| 관객 말투 | 개선 반응은 있으나 일반 시청자 같은 자연스러움은 사용자 판단 보류 상태다. |

## 남은 작업과 완료 기준

1. **효과음·배경음 등 비언어 소리 이해 — 미해결.** 현재 입증한 구독 경로는 음성 대사 전사다. 크기·피크·클리핑 측정만으로 총성·충돌·음악·감정을 이해했다고 표시하지 않는다. 추가 비용과 로컬 고부하를 늘리지 않는 공식 지원 경로를 먼저 확인한다. 가능하면 효과음·배경음·대사·혼합음·무음을 별도로 검증하고 화면 추론을 음향 인식 성공으로 세지 않는다. 경로가 없으면 한계를 유지하고 유료 호출로 자동 대체하지 않는다.
2. **시작 구간의 조작 지연 — 추가 관측.** 클립 녹화를 유지하며 반복 시작과 장시간 실제 플레이에서 G Hub 사용을 관측한다. 시험 중 빌드·패키징·다른 진단 부하를 섞지 않는다. 재현 시 캡처·인코더·연결 준비 시점과 입력 지연을 함께 기록한다. 현재 3분 비재현을 장시간 성능 보장으로 확대하지 않는다.
3. **관객 말투 — 평가와 개선.** 분석 보고·요청 사항 나열보다 장면과 발언에 맞는 짧은 반응, 다른 성격과 자연스러운 침묵을 평가한다. 사용자가 실제 시청자처럼 느끼는지 확인한다. 재미·말투 평가는 앱 실행 안정성의 릴리즈 판정과 구분한다.
4. **장시간 연속 입력·복구 — 범위 확대.** 마이크 재연결, 시스템 출력 장치 변경, 절전·재개, 장시간 발언 적체를 격리 환경에서 검증한다. 순서·중복·누락·화면 시점·메모리·정상 중지를 확인하며 합성 결과와 물리 장치 결과를 별도로 남긴다.
5. **버전과 실행 경로 — 0.1.11 수정 대상.** 하단의 고정 `0.1`을 패키지 버전으로 바꾸고 렌더러 검사에서 일치를 강제한다. 설치 도구는 바탕 화면과 시작 메뉴 바로가기를 같은 고정 실행기로 등록한다. 공개 버전·패키지·설치 실행 파일·표시 버전의 일치와 실제 Windows 시작 메뉴 실행을 릴리즈마다 확인한다. 기존 고정 항목이 갱신되지 않으면 갱신된 Nagneon 항목을 다시 고정한다.

완료 기록에는 대상 버전·코드 SHA, 실제 시험 환경·시간, PASS/FAIL/NOT_TESTED, 실패 이력, 비공개 원본의 보존 위치와 다음 조치를 남긴다. 문서 작성이나 빌드 성공만으로 실제 사용 검증을 완료 처리하지 않는다.
