## 남은 수용 절차

1. **완료:** 전체 NSIS 컴파일과 TEST 설치 → 설치된 앱 실행/정상 종료 → 제거·사용자 파일 보존 통과. `artifacts/installer-full-test-2026-09-14T14-21-45-763Z`의 단계별 JSON을 확인했다. 대상 패키지의 기능 소스는 `dd51e97`이며 이후 로컬 스키마 변경까지 포함한 최신 배포본이라고 주장하지 않는다. [설치 기록](INSTALLER.md).
2. 사용자가 준비한 치지직 앱 승인과 YouTube 키/진행 중 방송으로 실제 원문 수신·세션 전환·해제 확인. 비밀 값은 앱에 직접 입력. [설정 안내](EXTERNAL-CHAT-SETUP.md).
3. 사용자 플레이·물리 마이크와 게임 전환을 포함한 연속 사용 검증. 현재 합성 입력을 물리 장치 수용으로 확대하지 않는다.
4. 로컬 모델의 실제 관객 품질을 확보하거나, 시험 결과를 근거로 지원 수준에 대한 사용자 결정을 받는다. 기본 Codex는 그대로 유지한다. [로컬 실측](OLLAMA-SETUP.md).

실행 중인 작업은 해당 프로세스/세션의 생존을 확인한 뒤 기다린다. 테스트 통과나 문서의 체크 표시만으로 위 미완료 항목을 완료 처리하지 않는다.
