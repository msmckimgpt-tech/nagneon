# Nagneon 0.1.14

후원 직후 같은 관객이 비슷한 축하를 일반 채팅으로 다시 보내는 경우를 줄였다. 한 응답에서 실제 후원 문구가 공개되면 그 관객의 자발적인 감상은 한 번으로 마친다. 모델이 ‘추가 내용’이라고 표시해도 그 표시만으로 두 번째 채팅을 허용하지 않는다.

실제로 목격한 질문에 대한 답은 후원 뒤에도 전달할 수 있다. 질문의 출처와 기존 문자열 중복 검사를 함께 적용한다. 무언 후원·실패한 후원과 다른 관객의 채팅은 영향을 받지 않으며 익명 후원의 공개 범위를 유지한다. [후원 뒤 추가 채팅](DONATION-FOLLOWUPS.md)

0.1.13의 현재 방송 채팅 더보기와 문화 자료·진단 개선을 포함한다. 데이터 저장 형식, 선택한 AI 모델, 마이크·게임 소리 연결 방식은 변경하지 않는다. 업데이트는 [고정 설치 절차](STABLE-INSTALLATION.md)를 사용하며 이전 실행본과 백업을 보존한다. 복귀할 때 현재 대화 기록을 과거 백업으로 덮어쓰지 않는다.
