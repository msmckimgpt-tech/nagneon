# 직접 질문의 늦은 답변

화면 표본 시각과 대화 문맥 시각을 분리한다. 현재 질문이 화면보다 조금 늦게 기록돼도 관객이 들은 대화에 포함되며, 화면의 시각·목격 범위·20초 반응 만료는 유지된다.

모델이 `intent: reply`와 빈 `replyTo`를 반환하면 서버가 현재 요청에서 직접 호명된 관객에게 전달한 단일 질문 ID를 확인한다. 실제로 목격한 질문이고 현재 입력과 원문이 같으며 요청 때 20초 이내에 기록된 경우에만 연결한다. 임의 ID, 오래된 질문, 호명되지 않은 질문과 일반 감상에는 이 보완을 적용하지 않는다.

이렇게 연결한 답변은 질문 기록 시각부터 최대 90초 동안 유효하다. 새 질문, 명시적 취소, 원문 삭제, 장면 연결 종료, 방송 종료·새 세션, 관객 이탈·재입장·제거에 따른 차단을 유지한다. 한 관객의 같은 질문에 대한 응답은 대기열과 전달 기록에서 중복을 막는다. 이 연결은 답변의 사실성을 증명하거나 응답을 강제하지 않는다.

`test/direct-question-reply.test.js`는 합성 질문과 비민감 합성 응답의 투영을 사용해 20.84초 응답, 빠른 응답, 일반 영상 만료와 경계 조건을 검사한다. `scripts/verify-direct-question-reply-ui.cjs`는 가상 시계로 같은 지연을 재생해 실제 로컬 API·필터·대기열·숨김 Electron UI의 표시를 확인한다. 실제 모델 호출, 설치 EXE 및 물리 장치 검증과 구분한다.
