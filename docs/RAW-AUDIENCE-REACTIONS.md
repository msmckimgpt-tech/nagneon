# 라이브 관객의 짧은 반응

일반 라이브의 순간 반응은 웃음·감탄·단답·말 조각만으로 끝날 수 있다. 이를 완결된 감상문이나 새로운 비유로 늘리도록 요구하지 않는다. 존댓말을 쓰는 관객도 짧은 감탄이나 웃음만 남길 수 있다. 함께 본 사건에 여러 관객이 비슷하게 웃는 것은 기존 짧은 공동 반응 허용 범위를 따른다.

생성 지침은 관객의 새 채팅과 후원 문구에 쉼표를 쓰지 않도록 한다. 일반 채팅 본문을 만드는 응답 형식에도 같은 표현 기준을 붙인다. 문자열을 잘라내거나 다른 대사로 교체하는 후처리는 하지 않는다. 일반 구어·초성·웃음 자체는 외부에서 배운 특정 유행어와 구분한다. 특정 밈의 출처·사용 가능 여부·재사용 간격은 기존 문화 기능이 계속 관리한다.

직접 받은 질문·계산·회상·설명 요청에는 필요한 내용을 답한다. 모든 채팅에 같은 글자 수나 웃음 비율을 할당하지 않으며 관객의 저장된 성향·말높임을 덮어쓰지 않는다. 명확한 중단 요청에는 해당 행동을 멈추되 장문의 사과나 이행 약속을 기본 응답으로 만들지 않는다.

이 변경은 일반 라이브 생성 지침에 적용한다. 스트리머 원문과 기존 대화 기록은 수정하지 않는다. 인터뷰·합의한 특수 대화·게시판 글과 사용자가 교체한 디버그 지침에는 일반 채팅용 표현 기준을 붙이지 않는다. 매니저의 발언 자격·목격 범위·후원 중복 방지·차단어·훈수 범위·오래된 반응 거절은 바꾸지 않는다.

문구가 짧아졌다는 사실만으로 자연스러움이나 실제 방송 문화를 재현했다고 판정하지 않는다. 같은 제공처·모델·effort의 합성 장면에서 생성 원문과 실제 공개 결과를 대조하고 질문·정정·중단 반응을 함께 확인한다. 사용자 평가와 실제 방송 검증은 별도로 기록한다.
