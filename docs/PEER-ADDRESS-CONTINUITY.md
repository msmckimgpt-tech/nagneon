# 관객 간 호칭과 방송 입력의 연속성

화면이 잠시 그대로여도, 실제 입장한 관객이 다른 관객이나 매니저에게 말을 걸면 새로운 대화 입력으로 처리한다. 현재 닉네임과 기록된 이전 닉네임을 같은 관객 ID로 해석하며, 영문 대소문자와 전각 표기도 기존 호칭 해석 규칙을 따른다.

전체 명단을 먼저 확인한다. 자리를 비웠거나 비활성화된 관객의 현재 이름도 소유권을 유지하며, 여러 관객에게 겹치는 이전 이름은 임의로 배정하지 않는다. 긴 이름 안의 짧은 이름이나 영문 단어의 일부를 다른 관객으로 오인하지 않는다.

호칭은 관심을 받을 수 있는 단서다. 발화자와 상대의 현재 입장 상태, 상대의 입장 시각, 60초 이내의 실제 채팅인지 여부를 확인하며 자기 호칭, 가상 채팅, 채팅 반응으로 생성된 메시지를 새 반응의 원인으로 반복 사용하지 않는다. 늦게 들어온 관객에게 이전 대화를 들은 것으로 취급하지 않는다. 이름을 부른 것만으로 대답이나 친밀도 변경을 강제하지 않는다.

`test/peer-address-continuity.test.js`는 실제 Studio의 합성 채팅 게시와 요청 준비 경로로 이전·현재 이름, 이름 소유권, 입장 경계, 매니저 참여, 한 번만 처리되는 입력과 개인 메모 비공개를 확인한다. 실제 마이크·화면 인식이나 생성된 대화의 자연스러움은 이 검사 범위에 포함되지 않는다.
