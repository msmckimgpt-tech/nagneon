## 방송 밖 이야기

디시인사이드의 공개 [인디게임 마이너 갤러리](https://gall.dcinside.com/mgallery/board/lists/?id=indiegame)에서 전체글·개념글·공지·말머리, 글쓰기와 번호/제목/글쓴이/작성일/추천 중심 목록을 확인했다. 실제 게시물이나 이용자 신원을 복제하지 않고 **가상 방송의 로컬 갤러리**에 목록·분류·추천 구조를 적용했다. 실제 조회를 세지 않는 조회수나 외부 유입 수치는 표시하지 않는다.

- 전체글/추천글/공지/후기/질문/자유 탭, 제목·내용·작성자 검색과 20개 단위 페이지.
- 제목·본문·말머리로 글쓰기, 글 상세와 삭제, 댓글·한 단계 답글·댓글 삭제.
- 관객/스트리머별 글 추천 1회, 스트리머 추천 취소. 추천 수는 실제 로컬 추천 기록으로 계산하며 포인트를 소모하지 않는다.
- 방송이 끝난 뒤 이미 만난 활성 관객 중 최대 세 명이 글·댓글을 읽고 선택적으로 반응한다. 관객은 자기 추천 여부를 별도로 반환한다. 모르는 관객을 추가하거나 실제 방송을 봤다고 가정하지 않는다.
- 이전 제목 없는 게시글은 첫 줄을 제목으로 보여준다. 대화 기억은 갤러리 아래 접을 수 있는 영역으로 옮기고 기존 내부 농담 등록도 보존한다.

서버는 글 200개, 글당 댓글 150개 보관 한도를 명시하며 오래된 글을 몰래 버리지 않는다. 삭제 댓글은 답글 연결을 보존하는 삭제 표시로 남는다. 저장 실패 때 메모리의 게시판 상태를 먼저 바꾸지 않는다. AI 요청 도중 게시글이 수정·삭제되면 오래된 결과를 저장하지 않으며 비활성화된 관객도 재확인한다. 웹으로 게시하거나 외부 커뮤니티 계정에 접속하지 않는다.

현재 관객의 게시판 읽기는 사용자가 방송 밖에서 요청하는 흐름이다. 모든 관객의 자발적 방문 예약·개별 장기 열람 영수증·갤러리 추천 기반 유입까지 완성한 것으로 해석하지 않는다. 기존 방송 후기 생성과 클립 유입 기능은 유지한다.

## 핫클립 영상과 스트리머 음성

관객이 고른 장면에 기존 녹화 버퍼의 실제 WebM을 연결한다. 화면이 없으면 음성 클립, 기록할 버퍼가 없으면 기존 장면 기록으로 남는다. 예전 이미지에서 가짜 동영상을 생성하지 않으며 스트리머가 직접 클립을 만드는 버튼도 추가하지 않는다.

방송 전 **방송 설정 → 미디어·기록**에서 **방송 중 영상·음성 클립 버퍼 사용**과 **관객의 장면 기록 허용**을 켠다. 기존 설정을 자동으로 켜거나 꺼서 사용자의 기록 선택을 바꾸지 않는다. 화면과 마이크를 연결해 방송하면 관객이 고른 새 구간에 영상과 분리 음성이 붙는다.

새 녹화는 **화면/게임 소리를 기본 WebM에, 마이크를 별도 `voice.webm`에 저장**한다. 마이크만 연결된 경우에는 음성 클립 하나를 저장한다. 핫클립 재생의 **스트리머 음성 켜짐/꺼짐**은 분리된 마이크 트랙만 제어하며, 주 영상의 재생·일시정지·탐색·배속·볼륨에 맞춰 음성을 동기화한다. 두 녹화의 시작 시각 차이를 반영하고 음성 범위 밖에서는 재생하지 않는다. 자동 재생은 하지 않는다.

설정에서 클립 녹화가 허용되고, 현재 방송에서 관객이 고른 클립이어야 업로드된다. 기본 영상 저장 이후 음성을 저장하고, 음성 응답 유실 시 기본 영상의 존재만으로 성공 처리하지 않는다. 시간·용량·형식·실제 디코딩과 선택 장면 포함 여부를 검증하며 손상 음성 때문에 이미 저장한 영상이 지워지지 않는다. 클립 삭제는 두 파일에 적용한다. 기존 2분 버퍼와 500 MiB 미디어 보관 한도도 적용한다.

**이미 마이크와 게임 소리가 혼합된 옛 클립은 스트리머 음성만 끌 수 없다.** 화면에 이 제한을 표시한다. 이는 캡처 입력별 분리이며 게임 출력 자체에 다시 섞인 스트리머 음성을 AI로 제거하는 기능이 아니다. 물리 입력 지연과 실제 Electron의 두 플레이어 장기 동기화는 다음 사용자 테스트가 필요하다.
