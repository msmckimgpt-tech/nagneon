# Nagneon 0.1.4 배포 후보

상태: 검증 준비 중. 정식 게시·사용자 설치 적용 전이다.

## 변경

- 방송 체험·연습과 AI 관객 관계에 맞춰 온보딩을 정리하고, 의도하지 않은 방송 놀이터·기획 시즌·전용 훈련 기능을 제거했다. 예전 기록 파일과 내보내기는 보존한다.
- 새 프로필 시작 포인트는 200P다. 기존 잔액은 유지한다.
- 시간·요청 횟수로 방송을 제한하지 않는다. 사용량 참고는 필요할 때 펼쳐 볼 수 있다.
- 관객 수 상한을 제거하고 많은 관객의 목격·시청 기록도 보존한다. 컴퓨터 사양별 운영 제안은 README에 있다.
- 공통 기억은 자동 만료하거나 개수 초과로 삭제하지 않는다. 대화에 관련된 기억을 선별하고 사용자가 직접 삭제할 수 있다.
- 공개 오버레이에 AI 관객·가상 포인트를 표시한다. 외부 채팅 연결 전 전송 내용을 안내하며 닉네임은 기본적으로 익명화한다.
- 의도하지 않은 전역 긴급 정지 기능을 제거했다. 일반 방송 종료 버튼은 마이크·화면을 함께 종료한다.
- 마이크 준비 전 음성 워커 기동을 줄이고, 상태 전송의 중복 직렬화를 줄였다. 코드 책임과 서식·개발 안내를 정리했다.

## 데이터 호환성

기존 기록을 새 버전으로 읽는 것과 새 기록을 옛 버전으로 읽는 것은 다르다. 40명 초과 관객·목격자 및 상한이 제거된 설정은 이전 버전의 스키마와 맞지 않을 수 있다. 원본과 업데이트 백업을 보존하며 새 기록을 옛 백업으로 덮어쓰지 않는다. 구버전 복귀 검증과 안내는 배포 전 확정한다.

## 남은 배포 검증

- 통합 SHA의 필수 검사와 패키지 소스/파일 해시 일치
- 실제 패키지 시작·종료·재시작 및 설치/업데이트
- 기존 데이터 복사본의 업데이트·복귀와 새 기록 보존
- 공개 오버레이·외부 채팅 및 음성 지연 기동의 영향 검증
- 압축 배포물 크기, 원격 게시와 사용자 앱 적용

리뷰 전체 원장과 원본 증거는 [CRITICAL-REVIEW-REMEDIATION.md](CRITICAL-REVIEW-REMEDIATION.md)에 기록한다. 합성 검사 결과는 실제 계정·장치 검증과 구분한다.
