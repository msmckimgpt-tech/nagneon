# 토큰 부담 개선: 중복 문맥과 모델 역할

## 결정 — 2026-09-15

사용자 기준은 기존 ChatGPT 구독 + 로컬 우선이며 추가 유료 API는 사용하지 않는다.
참고 의견은 관객 선별, 여러 관객의 배치 생성, 경량/상위 모델의 역할 분리다.
현재 BACKSEAT은 이미 `Audience.context`에서 발언 후보를 선별하고 한 요청에서 여러
관객을 생성한다. 모델을 관객마다 실행하는 방식으로 바꾸지 않는다.

우선 확인된 낭비는 같은 공개 대화와 장면이 관객별 패킷에 반복되는 입력이다.
`prompt-context.js`는 완전히 같은 chatHistory, previous, heardSounds,
externalChat, streamerExpression만 viewerIds와 함께 한 번 전달한다.
모델은 자기 ID가 포함된 항목만 자기 문맥에 합친다. 신규 관객의 비어 있는 이력,
개인 recollections/clipMemories, 입장 시각, 정정 원문, 발언 순서, 훈수 정책은 보존한다.
원본 저장소와 Studio의 문맥은 수정하지 않는다. 패킷들은 기존처럼 한 모델 요청에
존재하므로 이 기능도 비밀 격리를 제공하지 않는다.

값별 비용과 추가 설명을 포함한 전체 UTF-8 크기를 비교하여 충분히 줄어들 때만 적용한다.
바이트는 토큰 추정값이 아니다. 짧은 문맥, 한 관객, 디버그 지침 전체 교체는 기존 입력을 쓴다.
실측한 Codex 경로는 기본 적용한다. `BACKSEAT_SHARED_VIEWER_CONTEXT=0`으로 복귀 가능하다.
OpenAI API 경로는 1을 명시해야 사용한다. Ollama는 기존 문맥을 유지한다.

## 실제 구독 모델 비교

`node scripts/verify-shared-context.mjs`로 동일한 합성 한국어 대화 두 사례를
압축 전/후로 호출했다. 사례별 순서는 전→후, 후→전이다.
실제 gpt-6-astra / low 호출 4회이며 화면·마이크·자연스러운 장시간 방송 검증은 아니다.

| 사례 | 입력 토큰 전 → 후 | 출력 토큰 전 → 후 | 응답 시간 전 → 후 |
|---|---:|---:|---:|
| 기존 관객/새 관객의 기억 구분 | 39,645 → 23,629 | 258 → 270 | 13.124 → 16.786초 |
| 공략 없이 잡담 | 39,623 → 23,605 | 335 → 326 | 15.819 → 16.115초 |

입력 합계는 79,268 → 47,234로 **40.4% 감소**했다. 두 입력의 캐시 읽기는 모두 0이다.
전체 토큰은 79,861 → 47,830이다. 응답 속도 개선은 관측되지 않았다.
구독 한도 차감 방식과 API 금전 비용 효과는 **미측정**이며 동일한 감소율로 환산하지 않는다.
반복 대화가 많은 합성 입력의 결과이므로 일반 방송의 절감률을 보장하지 않는다.

응답 원문 검토: 전/후 모두 세 기존 관객이 정원 이름을 정확히 기억했고 새 관객은 직접
듣지 못했다고 답했다. 잡담은 서로 다른 취향으로 응답했고 게임 조작/공략을 제안하지 않았다.
모든 응답은 기존 Observation 검증을 통과했다. 원문과 usage는 다음 로컬 파일에 보존한다.

## 로컬 혼합 구성의 다음 조건

이 PC에서 RTX 2070 8GB를 확인했다. 현재 PATH의 Ollama 실행 파일과 11434 수신 서버는
확인되지 않았다. 로컬 모델 설치·한국어 품질·게임/STT 동시 부하는 검증되지 않았다.
현재 큰 프롬프트와 구조화 응답 전체를 초소형 모델에 그대로 맡기는 것은 검증 근거가 없다.

후속 구성은 규칙 기반 후보 선별 → 간단한 텍스트 반응용 로컬 모델 → 화면/복잡한 대화용
기존 구독 모델이 적합하다. 단골을 무조건 높은 모델, 새 관객을 낮은 모델에 고정하지 않고
현재 요청의 난도에 따라 역할을 정한다. 개인별 목격 범위는 모든 경로에서 유지한다.
로컬 실패마다 두 모델을 연속 호출하면 지연·토큰이 증가하므로 실패율과 승격률도 측정한다.

후보 모델의 공식 정보: [Qwen3.5-0.8B](https://huggingface.co/Qwen/Qwen3.5-0.8B),
[Gemma 3](https://ai.google.dev/gemma/docs/core/model_card_3).
이 정보는 BACKSEAT 한국어 품질 순위나 실사용 합격 증거가 아니다.
추가 API 결제나 제공처 자동 변경은 구현하지 않았다.

`web-development` 보조 검토는 17841 웹 브리지 미실행과 브라우저 시간 초과로 진행되지
않았다. 로컬 검사를 웹 검토로 표시하지 않는다. 네이티브 앱/패키지 검증을 거치기 전에는
이 결과만으로 새 정식 배포본의 실사용 승격을 주장하지 않는다.
