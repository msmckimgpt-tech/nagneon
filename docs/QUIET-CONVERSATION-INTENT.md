# 대화 중단과 재개 요청

`Ambient.context`는 관객에게 조용히 봐 달라는 직접 요청을 받으면 새 화제와 놀이를 멈추고 기존 10분 휴식을 유지한다. 휴식 중에도 직접 호명한 질문에는 기존 관객 참여 규칙에 따라 짧게 답할 수 있다.

“조용히 하지 말고 같이 얘기해”, “말 걸지 말라는 게 아니라 같이 얘기하자는 거야”, “그만 해달라는 뜻이 아니라 다시 얘기하자”는 대화 재개 요청으로 처리한다. 부정된 표현·인용·과거 발언 보고·감사·조용한 게임에 대한 설명은 그 단어만으로 휴식을 시작하거나 늘리지 않는다. 같은 발언에 서로 다른 직접 요청이 있으면 마지막 현재 시점의 요청을 따른다. “지금은 조용히 보고, 끝나면 다시 얘기하자”처럼 미래나 조건을 붙인 요청은 즉시 적용하거나 예약하지 않는다.

이 판정은 한정된 한국어 표현을 처리하는 로컬 규칙이다. 모든 간접 표현이나 억양의 의도를 이해하는 것은 아니며, 불명확한 표현은 현재 휴식 상태를 유지한다. 음성 전사 원문·관객의 목격 범위·질문 우선순위·응답 횟수 제한은 바꾸지 않고 추가 모델 호출도 하지 않는다.

`test/ambient-intent.test.js`는 요청·부정·인용·보고·순서·휴식 만료를 확인한다. `test/quiet-viewing-company.test.js`는 실제 Studio 요청에서 재개 발언을 들은 관객만 후보에 들어가며 뒤늦게 온 관객은 제외되는지 확인한다. 합성 입력 검증이며 실제 음성 인식이나 모델의 자연스러운 대화 품질 합격을 뜻하지 않는다.
