# 핫클립 영상·소리를 감상하는 관객

2026-09-14. 자동 커뮤니티 방문에 실제 저장된 WebM의 장면과 소리 인식을 연결했다. 스트리머가 감상자나 댓글 생성 버튼을 선택하지 않는다. 기존의 앱 실행 중 방문·방송 응답 우선·시간당 최대 6회 제한을 유지한다. 사용자 앱, 화면, 마이크, 게임은 조작하지 않았고 아래 검증은 합성 파일과 독립 프로필을 사용했다.

## 감상과 개인 기억

`ClipPerception`은 녹화 원본을 검증한 뒤 별도 Python 프로세스에서 시간순 장면을 추출한다. 최대 45초·파일당 20MB의 영상에서 균등한 8개 시점과 관객이 고른 순간 주변 4개 시점을 대상으로 최대 12장을 제공한다. 실제 프레임 시각을 보존하고 최대 640×480으로 변환한다. 프레임 사이의 동작을 모두 보았다고 주장하지 않도록 모델 지침에 명시한다. PyAV의 [프레임 변환 API](https://github.com/PyAV-Org/PyAV/blob/main/av/video/frame.py)와 [코덱 API](https://pyav.org/docs/stable/api/codec.html)를 참고했으며 호환성의 근거는 번들 런타임의 실제 디코딩·JPEG 인코딩 실행이다.

출력 소리와 별도 마이크 녹음을 각각 디코딩하고, 시각의 간격을 무음으로 유지한다. 로컬 YAMNet으로 소리 종류를 읽고 Whisper로 대사를 전사한다. 게임/영상 대사는 언어를 자동 감지하고 마이크는 기존 한국어 인식기를 사용한다. 마이크에는 음량·말하는 방식의 단서를 덧붙인다. 음성 전사, 소리 분류, 채널 크기, 말투 단서는 불확실한 관측이며 화자의 감정이나 사건의 원인을 확정하지 않는다. 기존 혼합 녹음은 `mixed-audio`로 남겨 화자를 추정해서 붙이지 않는다. 무음에서는 발언을 생성하지 않는다.

GPT에는 실제 이미지들과 시간·출처가 있는 로컬 소리 인식 결과를 보낸다. 원시 오디오를 GPT에 직접 입력하거나 영상 전체를 연속 재생하는 구조는 아니다. 캡션과 파일 근거가 충돌하면 파일 근거를 우선하며, 녹화가 없는 클립은 기존 글·채팅 열람을 유지한다. 다른 관객의 감상이나 아직 전달되지 않은 댓글은 보았다고 처리하지 않는다.

성공한 관객별 감상에는 파일 해시·프레임 시각·소리 인식·모델 장면 설명을 저장한다. 댓글·추천·무작성 선택과 같은 저장에서 확정하므로 저장 실패 시 기억만 남지 않는다. 공개 상태와 클립 API에는 내부 감상 기록을 노출하지 않는다. 다음 방송의 개인 기억에는 `clip-media-samples`라는 출처와 불확실한 전사/장면 설명이 전달되며, 캡션 열람인 `clip-text`와 구분한다. 재시작 후에도 감상한 관객에게만 연결되고 클립 삭제 시 회상에서 사라진다.

## 방송 우선과 실패 처리

감상 프로세스는 기존 라이브 음성·소리 작업자와 별개이며 CPU 스레드를 제한한다. 설치된 모델만 사용하고 다운로드나 장치 접근을 하지 않는다. 입력·출력 크기와 75초 처리 기한을 제한한다. 새로운 방송 입력·설정 변경·종료 요청이 오면 소유한 감상 프로세스를 취소하고 종료가 확인된 뒤 다음 모델 요청을 시작한다. 앱을 닫으면 감상 작업도 종료한다.

영상 읽기에 실패하면 모델 호출을 사용하지 않으며 열람·댓글·추천을 남기지 않는다. 재시도 시도 자체는 먼저 기록해 실패를 반복하며 무한 호출하지 않게 한다. 모델 응답 뒤 원본 파일의 해시를 다시 확인하고, 관객 삭제·취소·클립 또는 댓글 변경이 발견되면 응답 전체를 버린다. 파일 감상 실패를 캡션만 읽은 성공으로 조용히 바꾸지 않는다. 한국어 전사가 프로세스 출력 조각의 UTF-8 경계에서 깨지는 문제도 방지한다.

## 남은 범위

실제 여러 게임·복잡한 혼합 음원·긴 클립·다양한 GPU/CPU에서의 인식 정확도와 장기 몰입은 아직 별도 수용 조건이다. 장면은 최대 12장 표본이므로 짧은 효과나 그 사이의 행동을 놓칠 수 있다. 원문 기억 검색은 제한된 어휘 기반이며 다른 관객과 나눈 커뮤니티 대화의 장기 관계 변화는 다음 작업이다. 설치기의 최초 저널 임시 파일 부분 쓰기 복구와 신규 Windows 설치·장치 사용·서명·Steam 판매 조건은 [판매 준비 기준](RELEASE-GATES.md)에 남긴다.
