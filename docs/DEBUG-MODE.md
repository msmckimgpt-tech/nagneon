# 디버그 모드

방송 설정 → **디버그** → **디버그 모드 사용**을 켠다. 기본은 꺼짐이다. 방송·연습·모델 요청을 마친 뒤 변경할 수 있다.

## 프롬프트 편집

- **기본 프롬프트에 추가**: 자동 생성되는 지침 뒤에 사용자 문장을 붙인다.
- **시스템 프롬프트 전체 대체**: 자동 생성되는 지침을 입력한 문장으로 바꾼다. 빈 문장도 허용한다.
- **기본 프롬프트를 편집창에 불러오기**: 현재 저장된 설정의 일반 라이브 프롬프트를 복사해 수정할 수 있다. 복사본은 정적인 문장이므로 이후 관객/설정 변경을 자동 반영하지 않는다.
- **프롬프트 적용**으로 저장한다. **프롬프트 기본값 복원**은 사용자 지침을 비우고 자동 생성으로 돌아간다. 모드를 끄면 저장된 사용자 프롬프트를 적용하지 않는다.

Codex, OpenAI API, Ollama의 공통 프롬프트 생성 단계에 적용된다. 관객 생성·라이브·방송 밖 대화·연결 시험처럼 서버가 제공처에 보내는 요청이 대상이다. 원문 입력 데이터와 출력 JSON 스키마, 제공처의 실행 권한 및 앱의 데이터 검사는 변경하지 않는다. Codex 실행기의 JSON 출력/파일 미열람 안내는 별도 실행 규칙으로 유지된다. 일반 모델의 응답 품질이나 제공자 정책까지 바꾸는 기능은 아니다.

프롬프트는 `debug.json`에 별도 저장되며 기본값은 `{enabled:false, mode:"append", prompt:""}`이다. 저장된 프롬프트는 활성화된 동안 선택한 AI 제공처로 전송된다. 일반 SSE 상태에는 활성 여부만 포함하며 프롬프트와 숨긴 관객 정보는 인증된 디버그 조회에서만 가져온다. 디버그를 끄면 조회에도 고급 설정을 포함하지 않는다.

## 잠긴 설정 편집

**잠긴 설정 편집 · 관객 성향과 고급 설정 JSON**에서 기존 관객의 이름·성격(personality)·가치관(values)·사교성(sociability)·숙련도(expertise), 유입(discovery) 등 지원되는 전체 설정을 수정할 수 있다. JSON 형식과 각 필드의 값 범위를 검사한다. 기억과 기록을 연결하는 관객 ID 목록은 유지해야 한다.

**고급 설정 적용**은 World 저장소에 원자적으로 저장한 뒤 창을 닫는다. 일반 설정의 이전 초안이 다시 덮어쓰는 것을 막기 위한 동작이다. 다른 작업이 설정을 바꿨다면 오래된 JSON 초안을 거절하므로 탭을 다시 열고 최신 값으로 수정한다. **편집 취소 · 불러온 값**은 아직 저장하지 않은 JSON을 되돌린다. 저장한 관객/게임 설정은 디버그 모드를 꺼도 유지된다. 프롬프트 복원은 관객 설정을 초기화하지 않는다.

## 검증

- `artifacts/debug-check-final.log`: 647개 테스트 및 TypeScript/Vite 통과.
- `test/debug-mode.test.js`: 프롬프트 추가/전체 대체/기본값, 인증, 비활성 상태, 잠긴 필드 수정, 식별자/오래된 초안 거절, 재시작 후 저장값과 제공처 전달 검사.
- `artifacts/debug-ui-1789391814578/result.json`: 별도 실제 Electron에서 편집 → 저장 → 실제 프롬프트 빌더 요청 확인, 관객 이름/성격 변경, 기본값 복원/해제 통과. 응답은 fixture이다.
- `artifacts/debug-account-device.log`, `debug-account-runtime.log`: 공식 CLI 격리 기기 코드 발급/취소와 실제 데스크톱 계정 UI 회귀 통과.

최종 폼 배치 정리 후 같은 디버그 흐름을 다시 통과했다. `artifacts/service-benchmark-ui-1789391816817/result.json`의 기존 9개 제품 흐름 회귀도 통과했다.
