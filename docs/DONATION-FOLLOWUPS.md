# 후원 뒤 추가 채팅

한 번의 AI 응답에서 관객의 후원 문구가 실제로 공개됐다면, 그 관객의 자발적인 감상은 후원 문구 한 번으로 마친다. 같은 축하를 다른 표현으로 다시 쓰거나 별도의 감상을 곧바로 덧붙이지 않는다.

그 관객이 실제로 목격한 질문·요청에 답할 내용은 추가 채팅으로 보낼 수 있다. 서버는 관객에게 제공한 대화에서 질문의 식별자와 본문을 확인하며, 모델이 ‘추가 내용’이라고 표시한 것만으로 두 번째 채팅을 허용하지 않는다. 유효한 질문에 연결됐더라도 후원 문구와 문자열이 중복되면 기존 중복 검사를 적용한다.

무언 후원이나 지급되지 않은 후원은 일반 채팅을 소모하지 않는다. 다른 관객의 반응과 익명 후원의 공개 범위도 유지한다. 동일 응답의 후원·채팅 수용 규칙이며 서로 다른 요청에 걸친 모든 의미적 반복을 판별하는 기능은 아니다.

`test/broadcast-response-policy.test.js`는 잘못된 추가 내용 표시, 익명 후원, 존재하지 않거나 목격하지 않은 질문, 질문이 아닌 발언, 직접 질문의 답변과 다른 관객의 발언을 검사한다. 사용자 방송 원문을 시험 자료로 사용하지 않는다.
