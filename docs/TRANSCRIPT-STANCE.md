# 음성 교정의 감정·자칭 표현 보존

음성의 맥락 교정은 원래 전사에 붙는 주석이다. 원문을 유지하며, 가까운 발음과 높은 신뢰도가 감정이나 말투를 바꾸는 근거가 되지는 않는다.

- `답답하네` → `담담하네`, `지루하네` → `지랄하네`, `실망했어` → `실명했어`처럼 인식된 감정 표현을 다른 말로 바꾸는 교정을 거절한다. 반대 방향도 같은 검사로 거절한다.
- `난` → `전`, `나는` → `저는`, `내가` → `제가`처럼 자칭 표현을 바꾸거나 `내가` → `내게`처럼 인식된 조사 역할을 바꾸는 교정을 거절한다. 이름 속 글자를 자칭으로 분류하지 않는다.
- 같은 감정과 자칭을 유지한 `답답하네` ↔ `답답 하네`, `나 는` ↔ `나는`, `나 한테` ↔ `나한테` 같은 띄어쓰기 교정과 `자바서` → `잡아서` 같은 가까운 철자 교정은 나머지 검사도 통과하면 허용한다.
- 거절한 교정을 전제로 만든 관객 답변은 기존 처리에 따라 게시하지 않는다. 원문은 기록에 남고 잘못된 교정 주석은 저장하지 않는다. 다음의 안전한 교정과 관객 응답은 계속 처리한다.

이 검사는 정해진 한국어 표현과 단어 경계를 비교하는 보수적인 수용 검사다. 음성에서 감정을 판별하는 기능이나 모든 문장·조사·띄어쓰기 오류의 의미를 이해하는 기능은 아니다. 실제 발언을 확정하지 않으며, 모르는 표현의 의미 변경까지 모두 차단한다고 설명하지 않는다. [부정 의미 보존](TRANSCRIPT-POLARITY.md)의 기존 신뢰도·숫자·훈수 의도·물음표·음운 거리 검사도 유지한다.

`test/transcript-stance.test.js`는 양방향 감정·자칭 변경, 긴 공통 문맥 속 변경, 정상 띄어쓰기·철자 교정, 실제 Studio의 대기열 차단과 다음 안전한 응답, 저널 저장 후 재로드에서 원문과 주석의 구분을 검사한다. 입력과 제공처는 합성이며 물리 마이크의 인식 정확도·실제 모델의 자연스러움·실사용 감정이나 억양 인식의 합격 근거는 아니다. 별도 모델·재시도·저장 형식·UI 흐름을 추가하지 않는다.
