# 포인트 부탁의 방송 수명

관객에게 행동을 부탁하는 협상은 시작한 방송에 속한다. 방송을 종료하거나 앱을 다시 열면 아직 실행하지 않은 협상은 취소로 표시되며, 새 방송에서는 같은 관객에게 다시 부탁할 수 있다. 방송 중이라도 부탁한 일반 관객이 자리를 비우거나 참여를 중단하면 가격을 제안할 수 없다.

협상과 합의의 유효 시간은 생성 후 10분이다. 아직 실행하지 않은 협상은 시간이 끝나면 만료로 표시된다. 종료·만료된 협상은 포인트를 차감하거나 관객에게 합의한 행동을 수행하게 하지 않는다.

가격 합의만으로 포인트가 차감되지는 않는다. 합의한 행동을 실행할 때 해당 금액을 보관하고, 응답을 완성하면 관객 지갑으로 전달한다. 실행 도중 방송이 종료되거나 응답이 실패하면 보관한 포인트를 반환한다. 늦게 도착한 응답은 다음 방송에 게시되지 않는다. 아직 정산하지 않은 실행은 같은 관객과의 새 협상을 막아 중복 실행을 방지한다.

완료된 행동·환불·관객 수첩의 해금과 기존 잔액은 재시작 후에도 보존한다. 상태 조회는 미실행 협상의 취소·만료를 화면에 투영하며, 저장된 과거 협상과 가격 기록을 덮어쓰지 않는다. 새 프로필의 첫 방송 응원은 공유 가격표의 200P이며 이전 프로필의 포인트를 다시 지급하지 않는다.

검증은 `test/point-negotiation-lifetime.test.js`의 시간·방송 세대·정산 회귀와 `scripts/verify-point-negotiation-ui.cjs`의 격리 Electron 화면/인증 API/저장·재실행으로 수행한다. 후자는 합성 관객 응답을 사용하며 실제 AI 계정, 화면·마이크·스피커 장치, 사용자 설치본을 검증하지 않는다.
