# Nagneon 0.1.15

관객이 순간 반응마다 설명·공감·응원을 덧붙이던 경향을 줄이도록 라이브 채팅의 생성 기준을 조정했다. 웃음·감탄·단답·말 조각만으로도 반응을 마칠 수 있고 쉼표를 쓰지 않도록 한다. 존댓말 관객도 짧은 웃음만 남길 수 있으며 같은 순간에 여러 관객이 함께 웃는 반응을 허용한다.

직접 받은 질문·회상·설명 요청에는 필요한 내용을 유지한다. 명확한 중단 요청은 행동으로 따르며 장문의 사과나 이행 약속을 기본 응답으로 만들지 않는다. 인터뷰·게시판 글·사용자가 교체한 디버그 지침의 응답 형식은 유지한다. [라이브 관객의 짧은 반응](RAW-AUDIENCE-REACTIONS.md)

저장된 관객 성격·대화 원문·AI 모델 선택·음성 연결 방식과 데이터 저장 형식은 변경하지 않는다. 이전 버전의 채팅 더보기와 후원 중복 방지를 포함한다. 업데이트와 복귀는 [고정 설치 절차](STABLE-INSTALLATION.md)를 따르며 현재 기록을 과거 백업으로 덮어쓰지 않는다.
