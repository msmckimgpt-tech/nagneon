# Claude Code 검토와 조치

2026-09-13, 사용자 위임에 따라 WSL `/usr/local/bin/claude`의 읽기 전용 검토를 실행했다. 원문: `artifacts/claude-review.txt`. 외부 검토의 주장 자체를 통과 증거로 사용하지 않고 소스·실행 결과와 대조했다.

| 지적 | 판단과 조치 |
|---|---|
| 마이크 중복 취득 및 스트림 유실 | 채택. 취득 중 진입 방지와 세대 검사를 추가. 종료 후 늦게 도착한 스트림 즉시 해제. Electron 합성 미디어 테스트 통과 |
| 실패한 모델 요청도 한도 차감 | 의도된 제한 정책. 재시도 비용을 무제한 허용하지 않기 위해 유지. README에 시도 횟수임을 명시. `test/studio.test.js`의 한도 테스트 통과 |
| 음성이 화면 주기를 앞당김 | 대화 지연을 줄이기 위한 의도된 동작. 화면 관찰 주기와 발언 최소 2초 간격의 차이를 README에 명시 |
| Codex 종료 전에 임시 파일 삭제 시도 | 채택. child close 후 취소 완료, 종료 실패 시 5초 마감, 삭제 재시도. 정리 실패가 모델 결과를 덮어쓰지 않게 함. 전용 취소 테스트 통과 |
| 음성 worker stdin 오류 처리 없음 | 채택. stdin 오류에서 준비 상태 해제·요청 거부·재시작 안내 추가 |
| 동일 PC의 다른 프로세스가 GET 가능 | 현재 로컬 단일 사용자 앱의 경계로 명시. 브라우저 SOP/Origin/Host 검사와 루프백 바인딩은 유지. 사용자별 IPC 인증은 후속 범위 |
| 테스트 파일이 없다는 검토자의 설명 | 사실과 다름. 실제 디렉터리는 `test/`이며 검토자는 `tests/`를 언급했다. 실제 테스트 실행 로그를 근거로 판단 |

추가로 방송실 탭 전환 시 화면 캡처가 끊기지 않도록 별도 비디오를 유지하고, 외부 중지 및 지연된 화면 선택에 따른 장치 해제를 검사했다. 투명 오버레이의 HTML 배경과 숨김 실행 후 창 표시도 수정했다.
