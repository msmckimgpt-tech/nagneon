# Nagneon 0.1.7 릴리즈 기록

## 변경 이유

관객의 방문·관계·말투·커뮤니티 활동을 확장하고 방송 중 음성 및 핫클립의 지속성을 개선했다.

- 관객은 눈팅, 휴식, 퇴장, 재방문을 구분한다. 별명·관계·기억·포인트는 같은 인물에 남고 이전 방문의 늦은 반응은 새 방문에 섞이지 않는다.
- 관객별 말투는 목격한 관계와 반복된 실제 대화에 따라 점진적으로 바뀐다. 괴롭힘·불쾌 표현 중단 같은 경계 요청은 즉시 적용한다.
- 설치된 음성·시스템 소리·GPU 구성 요소를 앱 재실행 시 읽기 전용으로 확인해 연결 화면의 준비 상태를 복원한다.
- GPT-6 Sol(경량)과 GPT-6 Luna(초경량)를 관객 모델 설정에 추가했다. 실제 이용 가능 여부는 연결된 계정과 제공처에 따른다.
- 마이크 원음을 로컬 프로필에 순서대로 기록한 후 인식한다. 원음은 24시간 후 삭제하며 복구 UI는 제공하지 않는다. 저장 장치 고장과 갑작스러운 종료 직전의 미저장 부분까지 무손실을 보장하지 않는다.
- 핫클립의 시스템/게임 소리 연결과 마이크 분리를 개선했다. 커뮤니티의 스트리머 주민 게시글 파일 첨부를 UI/API에서 막고 설정 화면을 간결하게 정리했다.
- 앞선 0.1.7 후보의 경량 배포 구성, 바깥 커뮤니티, AI 활동 대시보드, 화면 처리와 재시도 개선도 포함한다.

사용법과 호환성은 [배포 구성](DISTRIBUTION.md), [고정 설치·복귀](STABLE-INSTALLATION.md), [AI 대시보드](AI-DASHBOARD.md), [문화 학습](CULTURE-LEARNING.md)을 따른다.

## 데이터 보존·복귀와 알려진 제한

설치 전 백업은 설치 도구가 기록한 백업 위치에 보존했다. 기존 프로필의 기록·포인트를 초기화하지 않는다. 새 프로필만 200P로 시작한다. World v2로 변환한 현재 기록을 0.1.6 이하에 직접 연결하면 설치·실행 도구가 거절한다. 복귀 시 업데이트 전 백업을 별도 프로필에 복사하고 현재 data를 덮어쓰지 않는다. [고정 설치·복귀 안내](STABLE-INSTALLATION.md)를 따른다.

원음은 로컬 파일로만 복구할 수 있으며 24시간이 지나면 삭제된다. 저장 실패 후 누적 가능한 미저장 원음은 64MiB로 제한되며, 상한에 도달하면 오류를 표시하고 녹음을 중지한다. 시스템 소리 검사는 Windows 루프백 장치와 격리 영상 입력을 사용했으며 특정 게임 화면/실제 방송 송출 품질까지 증명하지 않는다. OBS가 마지막 공개 프레임을 유지할 수 있으므로 개인용 오버레이로 전환할 때 즉시 가리려면 OBS 소스를 숨긴다.

공개 태그·첨부 파일과 원격 해시 확인은 별도의 게시 단계에서 기록한다.
