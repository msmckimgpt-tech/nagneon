# 0.1.7 배포 후보

**아직 공개 릴리즈가 아니다.** 새 패키지의 수용 검증과 게시가 완료되기 전에는 설치 완료나 정식 출시로 표시하지 않는다.

## 주요 변경

- Windows 기본 빌드는 선택 음성·GPU 구성 요소를 별도 설치하는 경량 구성이다. 사용하지 않는 언어 파일을 줄이고, 한국어·영어를 포함한다. 전체 동봉 빌드는 명시적으로 선택한다.
- 관객·반응 설정의 설명을 보완하고, 주요 강조색과 색상 토큰을 정리했다. AI 채팅 제목을 관객 채팅으로 표시한다.
- 화면 JPEG 변환을 비동기로 처리하고 중지·소스 교체 후 늦게 도착한 결과를 제외한다. 경제 상태의 불필요한 전체 복사와 음성 상태의 중복 발행을 줄였다.
- 연속 발화에서 녹음 구간 전달을 복구하고, 폐기한 녹음기의 늦은 이벤트를 현재 녹음과 분리한다. 발언 시점의 화면 첨부를 보존한다.
- 간헐적 모델 실패에는 재시도 대기 단계를 유지하고 연속 3회 정상 응답 후 초기화한다. 방송 시간·관객 수의 상한을 추가하지 않는다.
- 기존 AI 연결을 사용하는 문화 참고자료 분석과 AI 활동·사용량 대시보드를 포함한다. 방송 밖 자동 활동은 기본 차단이며, 문화 참고 도메인은 사용자가 지정한다.
- AI 대시보드의 일일 호출·토큰·비용 상한과 기존 저장 상한을 제거했다. 사용 기록과 비용 추정은 참고 정보로 제공한다.

각 기능의 범위는 [배포 구성](DISTRIBUTION.md), [재시도](REACTION-RETRY.md), [AI 대시보드](AI-DASHBOARD.md), [문화 학습](CULTURE-LEARNING.md), [OBS 검증](OBS-OVERLAY-ACCEPTANCE.md)을 따른다.

## 보존 및 제한

기존 기록·잔액을 초기화하지 않는다. 새 프로필만 200P로 시작한다. 사용자 데이터와 AI 인증은 패키지에 포함하지 않는다. 앱은 무료이며 MIT 라이선스를 유지한다.

개인용 오버레이로 전환해도 OBS가 마지막 공개 프레임을 유지할 수 있다. 즉시 가리려면 OBS에서 소스를 숨긴다. 모델 응답 지연의 전반적 개선이나 실제 플랫폼 송출의 검증을 주장하지 않는다.

구버전은 새 AI 대시보드의 차단 정책을 시행하지 않는다. 복귀 전 구버전의 자동 활동 설정을 확인한다. 업데이트·복귀는 [고정 설치 절차](STABLE-INSTALLATION.md)를 따르며, 현재 기록을 과거 백업으로 덮어쓰지 않는다.

## 후보 검증 상태

- 버전 변경 후 `npm ci`와 `npm run check`의 778개 검사·TypeScript/Vite 빌드 통과.
- 기존 계정 연결 및 빈 격리 환경의 기기 코드 발급·취소 확인. 계정 로그인 교체·실제 모델 요청은 하지 않았다.
- 경량 패키지 34개 파일·795,635,842바이트, 배포 원본 112개 일치 및 전체 파일 해시·보안 퓨즈 검사 통과. 선택 구성 3,911,526,614바이트를 기본 빌드에 복사하지 않았다.
- 새 패키지의 실제 창에서 합성 제목·공통 기억 저장, 리허설 시작/중지, 정상 종료와 재시작 후 기록 보존을 확인했다. 계정·물리 장치를 사용하는 방송 시험은 아니다.
- 공개 0.1.6 원본 ZIP의 SHA-256을 확인하고 격리 설치 후 0.1.7로 업데이트했다. 설치 전후 데이터와 백업 해시가 일치했으며, 실제 설치된 앱에서 제목·공통 기억 보존, 리허설 시작/중지 및 정상 종료를 확인했다. 사용자 설치 등록은 변경하지 않았다.
- 공개 0.1.6으로 복귀한 경우에도 설치 데이터·백업 해시와 제목·공통 기억, 리허설 중지는 확인했다. 다만 정상 종료가 검증 제한 15초 안에 완료되지 않아 **복귀 수용 검증은 미완료**다. 이후 프로세스가 사라졌다는 사실만으로 종료 검증을 통과 처리하지 않았다.
- 종료 요청·프로세스 종료·출력 파이프 종료 시각을 기록한 추가 복귀 시험은 정상 종료 코드 0을 확인했다. 종료 요청부터 프로세스 종료까지 1.233초였으며 파이프도 같은 시각에 닫혔다. 앞선 일회성 지연의 원인은 미확인으로 남기며, 재검증 통과를 원인 해결로 해석하지 않는다.
- 패키지 UI 검증은 안내 문구 대신 실제 활성 버튼을 기다리고 서버의 방송 중지 완료를 확인한다. 공개 0.1.6의 초기 시험에서 발견한 대기 조건 오류를 보완했다.
- 변경된 마이크 경로의 물리 장치 검증과 일반 Windows 고정 실행기의 저장 위치 확인은 아직 완료되지 않았다.
- 태그·릴리즈 첨부 파일·사용자 설치본 전환은 미실행이다.

위 설치 시험의 초기 후보 ASAR SHA-256: `08e0677f74fc3b0c30f709b216cca667b051dbb45c0ea24a6f16d9f11b7946d7`. 이 후보에는 후속 일일 사용량 상한 제거가 포함되지 않아 최신 코드로 패키지를 다시 검증한다. 이 해시는 다운로드 ZIP의 해시와 다르다.
