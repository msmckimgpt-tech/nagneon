# 중요한 화면 전환 두 구간의 보존

연속 화면을 최대 8장으로 추릴 때 첫 장과 최신 장을 남기고, 기존 픽셀 변화 점수가 큰 두 경계의 직전·직후 이미지를 먼저 확보한다. 남은 자리는 기존 방식으로 시간 간격을 채운다. 두 전환이 겹치거나 끝점에 닿으면 이미지는 중복하지 않는다.

이전에는 첫 장과 최신 장을 전환용 자리로 함께 세어 첫 전환을 확보한 뒤 멈출 수 있었다. 500ms 간격의 33개 합성 화면 중 변화가 큰 두 경계가 떨어져 있는 사례에서 두 번째 경계의 전후 이미지가 모두 빠졌다. 전환 경계를 두 개 고르는 것으로 수정하며 500ms 수집, 16초 창, 최대 8장, 프레임·본문 용량, 오래된 화면의 기한과 방송·화면 식별자는 유지한다.

관객 입장 전의 이미지는 기존 서버 처리에서 계속 제외한다. 전환을 잇기 위해 목격 범위 밖의 이미지를 다시 포함하지 않는다. 픽셀 변화는 성취나 실패, 중요한 게임 사건의 판정이 아니다. 모든 동작을 보거나 모델 반응 속도가 빨라진다는 보장은 없다. [연속 장면 인식](TEMPORAL-VIEWING.md)의 한계와 기존 동일 화면·취소·확인 처리를 유지한다.

`test/temporal-transition-pairs.test.js`는 누락 사례, 서로 다른 우선 경계의 992개 위치 조합, 겹침·끝점·동점·낮은 변화, 순서·중복·8장 상한, 실제 Studio와 모델 입력 준비의 이미지 순서, 중간 입장자의 목격 경계를 검사한다. 화면과 제공처는 합성이며 실제 모델 호출이나 물리 게임 캡처·FPS·인지 품질의 합격 근거는 아니다. 추가 모델 호출·제공처·과금 경로는 도입하지 않는다.
