# 관객별 커뮤니티 감상 기록

핫클립의 감상 기록·추천과 갤러리의 방문 기록은 관객 수에 따라 보존한다. 151번째 관객이 방문해도 이전 관객의 기록을 밀어내거나 새 감상을 저장하지 못하는 제한이 없다. 닉네임이 바뀌어도 같은 관객 ID의 기록을 이어서 갱신한다.

감상은 댓글 작성과 별개다. 조용히 읽은 관객도 자신이 실제로 전달받은 내용만 기억하며, 추천 여부는 별도로 판단한다. 갤러리의 방문 기록과 클립의 개인 감상 기록은 공개 게시글·클립·방송 상태 응답에 포함되지 않는다. 공개 추천은 기존과 같은 형식이다.

관객 수 제한을 없애도 한 클립·게시글의 댓글 150개, 모델에 제공하는 클립 댓글 최근 30개와 답글 연결, 메시지 25개, 댓글 내용·깊이 검증은 유지한다. 감상하지 않은 관객에게 경험을 부여하거나 이전에 전달되지 않은 댓글을 기억하게 만들지 않는다. 자동 감상은 기존의 방송 우선순위·시간 간격·재시도 제한·취소 규칙을 그대로 따른다.

## 저장과 이전 버전 복귀

이 확장 기록을 지원하는 최소 앱 버전은 **0.1.18**, 프로필 읽기 능력은 **3**이다. 사회 기록 `world.json` 자체의 버전은 2를 유지한다. 앱 버전, 프로필 읽기 능력, 사회 기록 버전은 서로 다른 값이다.

기존 프로필이 읽기 능력 2로 표현 가능한 동안에는 최소 버전을 올리지 않는다. 클립 감상·추천·방문 기록 또는 갤러리 방문 기록이 150명을 넘는 데이터를 처음 저장하기 전에 `profile-format.json`의 최소 읽기 능력과 앱 버전을 올린다. 이미 더 높은 최소 버전이 있다면 낮추지 않는다. 갤러리만 있는 프로필도 이 시점에 검증된 빈 클립 기본 파일을 저장하여 재시작할 수 있다.

호환성 표시를 저장하지 못하면 새 댓글·추천·감상 기록 전체를 저장하지 않는다. 표시를 올린 뒤 본문 저장에 실패하면 메모리와 본문은 이전의 완전한 기록을 유지하고, 호환성 표시는 보수적으로 높은 값을 유지한다. 두 파일을 함께 되돌리는 작업으로 설명하지 않는다.

읽기 능력 3인 프로필의 사회 기록·클립 기본 파일이 없거나 손상되면 과거 백업을 자동 채택하지 않고 실행을 중단한다. 원본과 백업을 보존하여 원인을 확인해야 한다. 이전 읽기 능력 2인 앱은 새 프로필을 불러오기 전에 거부한다. 이전 앱으로 복귀하려면 업데이트 전에 별도로 보관한 프로필 사본을 연결한다. 현재 프로필의 표시를 지우거나 최소 버전을 수동으로 낮추지 않는다.

## 회귀 검증

- 300명의 조용한 클립 감상·추천과 갤러리 방문·추천을 실제 JSON 저장 후 다시 불러와 첫 관객부터 모두 보존한다.
- 151번째 자동 감상에서 실제 전달되는 댓글 범위, 개인 기억, 인증된 공개 응답, 재시작 후 재방문 방지를 확인한다.
- 중복 ID·잘못된 시각·해시·원문 연결과 댓글 상한을 계속 거부한다.
- 호환성 표시와 본문 저장 실패, 더 오래된 백업, 잘못된 다른 저장 파일, 지원하지 않는 최소 버전에서 기록 보존과 실행 중단을 확인한다.

검사는 합성 기록과 격리 프로필로 수행한다. 실제 사용자의 관객 말투·몰입 평가나 설치 환경의 업데이트 검증과는 구분한다.
